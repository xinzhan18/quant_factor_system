# QuantFactor 系统设计规范

## 1. 因子命名规范

### 格式: `factor_<类别>_<参数>`
```
因子表命名:   factor_{因子类型}_{参数}
因子注册名:   {因子类型}_{参数}
```

### 示例
| 类型 | 参数 | 注册名 | 表名 |
|------|------|--------|------|
| 收益率 | 1日 | `return_1d` | `factor_return_1d` |
| 动量 | 20日 | `momentum_20` | `factor_momentum_20` |
| 均线偏离 | 10日 | `dist_ma10` | `factor_dist_ma10` |
| 波动率 | 20日 | `volatility_20` | `factor_volatility_20` |

## 2. 数据库表结构

### 因子值表 (每因子一张表)
```sql
CREATE TABLE factor_{name} (
    time TIMESTAMP,      -- 交易日期
    symbol TEXT,         -- 股票代码
    value DOUBLE PRECISION,  -- 因子值
    PRIMARY KEY (time, symbol)
);
```

### 价格数据表
```sql
CREATE TABLE price_daily (
    time TIMESTAMP,
    symbol TEXT,
    open DOUBLE PRECISION,
    high DOUBLE PRECISION,
    low DOUBLE PRECISION,
    close DOUBLE PRECISION,
    volume DOUBLE PRECISION,
    PRIMARY KEY (time, symbol)
);
```

## 3. 因子评估流程

```
┌─────────────────────────────────────────────────────────────┐
│                    因子评估工作流                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 计算因子值                                               │
│     ├── 读取价格数据 (price_daily)                          │
│     ├── 应用因子算法                                        │
│     └── 保存到因子表 (factor_xxx)                           │
│                                                             │
│  2. 计算IC (信息系数)                                        │
│     ├── 合并因子值与收益率                                   │
│     ├── 计算相关系数                                         │
│     └── IC = corr(factor_value, next_return)               │
│                                                             │
│  3. 展示结果                                                │
│     ├── IC均值、IC时间序列                                   │
│     ├── 分组收益分析                                         │
│     └── 因子值分布                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. 因子计算频率

| 因子类型 | 计算频率 | 存储方式 |
|---------|---------|---------|
| 日线因子 (return_1d) | 每日收盘后 | 增量更新 |
| 短期因子 (5-20日) | 每日 | 增量更新 |
| 中期因子 (60日+) | 每周 | 批量计算 |
| 高频因子 (分钟级) | 实时 | 流式写入 |

---

## 5. 数据时间范围要求

### 最低要求
- **训练集**: 至少1年 (252交易日)
- **测试集**: 至少6个月
- **因子计算**: 需要足够历史数据 (因子周期 × 2)

### 示例
| 因子周期 | 最小回看期 | 推荐数据量 |
|---------|-----------|-----------|
| 5日 | 10日 | 60日 |
| 20日 | 40日 | 252日 |
| 60日 | 120日 | 504日 |

---

## 6. IC解读标准

| |IC| 值 | 解读 |
|---|---|---|---|
| **强** | |IC| > 0.03 | 因子预测能力较好 |
| **中等** | 0.02 < |IC| < 0.03 | 有一定预测能力 |
| **弱** | |IC| < 0.02 | 预测能力有限 |

### IC方向
- **负IC** = 反转效应 (短期跌 → 涨)
- **正IC** = 动量效应 (强者恒强)

- 组合分析
