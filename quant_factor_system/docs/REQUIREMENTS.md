# 本地因子平台 - 需求文档 (v2.0)

## 📋 需求概述

### 核心目标
构建一个**本地因子存储与研究平台**，支持：
1. 分钟/Tick级数据获取（米筐）
2. 分钟聚合到日频因子计算
3. 日频因子落库（只增不改）
4. 日频交易调仓
5. 完整交易回测（信号生成+仓位管理+止盈止损）
6. Dashboard展示（因子表现 + 回测表现）

### 2. 因子计算层 ✅ 部分实现

#### 2.1 因子计算引擎
```
输入: 分钟级价格数据
输出: 日频因子值 (每天1个值/股票)

计算方式:
├── 最新值 (last): 使用当日最后一根K线
├── 均值 (mean): 当日分钟数据的均值
├── 最大值 (max): 当日最大值
├── 最小值 (min): 当日最小值
└── 波动率 (std): 当日分钟数据的标准差
```

### 4. 选股策略层 ✅ 待设计

#### 4.1 单因子选股
```
流程:
1. 因子值排序 (降序)
2. 买入 Top N 股票
3. 等权分配仓位

参数:
├── top_n: 选股数量 (默认10-20只)
├── ascendding: 升序/降序
└── weights: 等权/按因子值加权
```

#### 4.2 多因子组合 (待设计)
```
方案A: 交集筛选
├── 因子1筛选出的股票
├── 因子2筛选出的股票
└── 取交集

方案B: 权重加权
├── 因子1权重 w1
├── 因子2权重 w2
└── 综合得分 = w1*f1 + w2*f2 + ...

权重来源 (由其他模块提供):
├── IC加权 (ICIR作为权重)
├── 优化器最优权重 (均值方差优化)
├── 机器学习权重 (Lasso/Ridge/深度学习)
└── 动态权重 (时间序列模型)
```

#### 4.3 待开发模块

### 5. 仓位管理层 ✅ 待设计

#### 5.1 仓位管理接口
```python
class PositionManager(ABC):
    """
    仓位管理抽象基类
    
    功能:
    - 根据现金计算可买数量
    - 分配买入仓位
    - 管理持仓
    """
    
    @abstractmethod
    def calculate_position(
        self,
        signal: pd.Series,  # 选股信号 (symbol -> factor_value)
        cash: float,        # 可用现金
        current_positions: Dict[str, float] = None  # 当前持仓
    ) -> Dict[str, float]:  # symbol -> weight
        """
        计算每个股票的仓位权重
        
        Returns:
            {symbol: weight}
        """
        pass
```

#### 5.2 仓位管理实现
```
├── EqualWeight (等权分配)
│   └── 每个股票分配相同权重
│
├── FactorWeighted (因子值加权)
│   └── 按因子值大小分配权重
│
├── MarketValueProportional (按市值比例)
│   └── 按当前市值比例分配
│
└── KellyOptimal (凯利公式)
    └── 基于收益率和胜率计算最优仓位
```

#### 5.3 开仓逻辑
```
买入规则:
├── 现金 -> 可买数量 = cash / (price * multiplier)
├── 最小交易单位: 100股 (A股)
├── 最大仓位: 单只股票不超过总资产X%
└── 分批建仓: 每次买入1/N，逐步完成
```

### 6. 止盈止损层 ✅ 待设计

#### 6.1 止盈止损接口
```python
class StopLoss(ABC):
    """
    止盈止损抽象基类
    
    功能:
    - 判断是否触发止盈
    - 判断是否触发止损
    - 生成平仓信号
    """
    
    @abstractmethod
    def check(
        self,
        position: Dict,  # 持仓信息
        current_price: float,  # 当前价格
        entry_price: float,  # 开仓价格
        current_date: str,  # 当前日期
        **kwargs
    ) -> Tuple[bool, str]:  # (是否平仓, 平仓原因)
        """
        检查是否需要平仓
        
        Returns:
            (should_close, reason)
        """
        pass
```

#### 6.2 止盈止损实现
```
├── NoStopLoss (无止盈止损)
│   └── 只在调仓日平仓
│
├── FixedStopLoss (固定比例止盈止损)
│   ├── 止盈: 盈利超过 X%
│   ├── 止损: 亏损超过 Y%
│   └── 参数: stop_profit=0.1, stop_loss=0.05
│
├── TrailingStopLoss (移动止盈止损)
│   ├── 追踪最高点
│   ├── 距离最高点下跌 X% 止盈
│   └── 参数: trailing_stop=0.1
│
├── ATRStopLoss (ATR动态止盈止损)
│   ├── 根据ATR计算动态止损位
│   ├── 止损: 当前价 - X*ATR
│   └── 参数: atr_multiplier=2.0
│
└── TimeStopLoss (时间止盈止损)
    ├── 持有超过 N 天强制平仓
    └── 参数: max_hold_days=5
```

```python
class BacktestEngine(ABC):

        end_date: str,
        initial_capital: float = 1000000
    ) -> BacktestResult:
        """
        执行回测
        
        Returns:

        """

```
