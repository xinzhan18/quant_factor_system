# 记忆回顾

回顾经验记忆的当前状态并建议调整。

## 步骤

1. 读取所有记忆文件
2. 总结当前状态
3. 识别可改进之处
4. 修改前征求用户意见

读取以下文件：
- `mining/memory/mining-lessons.md`
- `mining/memory/state.yaml`
- `mining/memory/patterns.yaml`
- `mining/memory/insights.yaml`

列出 `mining/memory/history/` 中的最近批次历史。

向用户展示摘要，包含：
- 因子库规模和目标
- 各类别领域饱和度
- 推荐方向数 vs 禁区数
- 挖掘录取率趋势
- 关键洞察

询问用户是否需要：
- 添加/移除推荐方向
- 添加/移除禁区
- 更新洞察
- 调整领域饱和度评估
