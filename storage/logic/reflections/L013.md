# L013 Reflection — Range-Amount Correlation

## Genesis (2026-04-10)

**Rationale**: The entire pv_corr family (F003-F016, 14 factors) uses close vs amount/volume as the two correlated dimensions. The RANGE (high-low)/close as first argument in Corr has never been tried. This is a genuinely new mechanism class.

**Economic hypothesis**: When large institutions aggressively trade a stock, they:
1. Submit large orders → push price to extremes → wide intraday range
2. High transaction monetary flow → high $amount

The correlation of range and amount captures this "institutional aggression" signal. It's different from pv_corr which captures directional co-movement (does price go up when lots of money flows?).

**Risk assessment**:
- Primary risk: (high-low)/close is correlated with realized volatility (vol_20d Barra factor). If Corr with amount is dominated by vol_20d, signal collapses.
- Mitigation: PE conditioning may filter to "institutional activity in cheap names" — same mechanism that worked for L009.
- Secondary risk: Corr(expr, $amount, N) where first arg is a complex expression — need to verify Qlib handles this correctly. Probe will validate.

**Orthogonality expectation**: Range-amount should have different max_lib vs F003-F016 (all use close, not range). If max_lib < 0.75 with clean Barra_residual, this is a new mechanism worth pursuing.
