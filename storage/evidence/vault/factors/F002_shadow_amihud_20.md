### 表达式解析

```
Mul(
  Mean(
    Div(
      Sub(Less($open,$close), $low),   ← K 线形态指标：(收盘<开盘 ? 1 : 0) - 最低价
      Sub($high, $low)                  ← 当日振幅
    ),
    20                                   ← 20 日移动平均
  ),
  Div($amount, Mean($volume,20))         ← 量价混合：成交金额 / 平均成交量
)
```

**直觉解读**：该因子度量的是"下跌 K 线 + 高流动性"的叠加效应。分子捕捉价格下行强度（阴线实体占比），分母乘以相对换手率。数值越高，表示股票在下跌时伴随异常高的流动性——这是典型的"主力出货"或"流动性黑洞"特征，未来预期跑输。

## 经济学解读

### 为何 shadow_amihud_20 有效？

**Amihud 流动性指标**是金融学中最经典的非流动性代理指标之一，定义为：

```
ILLIQ = |r| / V
```

其中 `r` 为收益率，`V` 为成交金额。Amihud (2002) 证明股票的非流动性与未来收益正相关——流动性越差的股票，要求更高的风险补偿。

**F002 的变体设计**将 Amihud 思想做了两项改造：

1. **分子用"阴线强度"替代"|r|"**：传统 Amihud 用收益率绝对值，F002 用 `(Less($open,$close) - $low) / ($high-$low)` 捕捉"带下影线的阴线"——这不仅是下跌，更是一种特定的下影线形态，往往出现在主力打压出货的末端

2. **叠加换手率增强**：乘以 `Div($amount, Mean($volume,20))` 捕捉"量价齐跌"的异常高换手——这是典型的流动性黑洞特征

**经济逻辑**：

```
阴影线下影线越长 + 下跌时换手率越高
→ 主力资金快速出逃、流动性被抽干
→ 股价在未来 1-5 日内继续跑输
```

**为何 2016-2017 年因子最强**（ICIR=-0.72/-0.69）？这与 A 股市场特征吻合——2015-2016 年是 A 股历史上流动性泡沫最严重的时期，"杠杆牛"崩溃期间高换手率股票跌幅最深，正好是 shadow_amihud_20 捕捉的最佳环境。

## 综合评估

### 优势
- **完美的单调性**（验证期 Page Test p=1.48e-97），Q1→Q5 严格递减
- **极强的多空收益**（L/S Sharpe=4.13，Grade A 水平）
- **IC 衰减抗性**：60 日 IC 是 1 日 IC 的 2 倍，适合中期头寸
- **OOS 稳健**：2024 年 IC=-0.051，与历史表现一致
- **独特经济学机制**：融合 Amihud 流动性思想与 K 线形态学

### 劣势
- **与 F024 高度冗余**（corr=0.698），独特性评分仅 0.3
- **持有期单调性崩溃**（OOS=-0.3），因子收益主要来自做空最差股票而非选优
- **风格暴露集中于 turnover_20d**，行业中性 IC=-0.052 后预测能力尚存
- **37.7% alpha survival ratio**，意味着约 2/3 时间月度 IC 为正（因子短期失效）
- **最大回撤 16%**（L/S），空头端回撤管理需关注

### 使用建议
1. **组合构建**：由于与 F024 高相关，两因子不宜同时使用。F002 更适合作为空头端 alpha 源，F024 可作为风险控制参考
2. **头寸方向**：因子主要通过做空 Q5 贡献收益，建议结合多头组合使用，不建议单独做多 F002
3. **换手率**：月均换手率 9.2%，属于中等偏低换手，适合中长期量化组合
4. **风险警示**：2020 年和 2018 年因子结构曾出现阶段性失效，需配置其他正交因子分散
