## 10. 研究脉络与经济机制

> [!note]- 研究脉络与经济机制

### 市场假说

[[directions/overnight_intraday_split]] 方向 hypothesis 把日 return 分解为 overnight (open-prev_close)/prev_close 与 intraday (close-open)/open 两段——驱动因子不同：overnight 段是隔夜消息 + 机构 pre-market order flow；intraday 段是散户 + 算法 + 日内 arbitrage。早期 batch_025 用 **magnitude 聚合 (spread/persistence mean)** 打下 F009/F010/F011 三 slot，其后 batch_027 的 intraday 镜像测试 3/3 reject 证明 "F009 spread 已隐式吸收 intraday 分量"。

hypothesis 明列 3 条"复活条件"：
1. 新字段：minute-bar session 分解（超出现数据粒度）
2. 更长 horizon：20d+ overnight persistence
3. **正交 aggregation：overnight sign frequency（方向而非 magnitude）、overnight × intraday 非线性交互**

F018 正是条件 3 第一句的文字级兑现。

### 经济机制

**第一，overnight 方向一致性来自机构 pre-market 持续 accumulation。** 当机构在 pre-market order book 持续挂 bid，overnight 就频繁收正；散户看不到这个连续性（散户的 observation horizon 基本是日内 K 线）。Sign() 聚合把 magnitude 信息（机构每次 push 的强度差异）完全擦除，只保留 **"方向重复了几次"** 这个更稳健的 meta-signal。

**第二，amount RHS 基准是为了规避"小盘股 sign streak 天然更长"的 size bias。** 如果只用 sign_freq 单维度，小盘股会机械居高——rank-diff 构造里 `Sub(sign_freq_rank, amount_rank)` 的作用是"**在同一流动性层级内**比较 sign_freq 分布"——真正筛出"流动性被低估 + 方向持续"的错位目标。

**第三，信号持续性来自 anchoring + short-sale constraint 的双侧摩擦。** A 股不允许自由做空 + 散户有处置效应 (不愿卖出亏损股)——这两个摩擦造成"**即使 overnight 方向信号清晰，市场定价的调整需要数日到数周**"，因此 20d sign_freq 到 20d future return 的 IC 在长 horizon 反而增强 (1d→20d 翻 2.5 倍)。

**第四，失效场景。** (a) 极端 regime (熊市末期全市场 sign 同向收敛) — 此时 sign_freq cross-section variance 塌缩；(b) 国家队 overnight intervention 使大盘股 sign 被人为扭曲；(c) 注册制后小盘新股大量涌入初期 sign_freq 样本不足。

### 实验设计

本因子在 **batch_049** 作为 C006 出现，与另外 5 个 rank-diff 候选（C001-C005）同批竞争。batch_049 的 cockpit 硬约束是"每个候选 LHS 必须不同"，6 LHS 覆盖 L1 vol (AmihudIlliq) / pb_ratio / turnover_cv / volume HHI / L2 RealizedVol / sign_freq——前 5 个全 reject（C001/C002/C004/C005 共 RHS=overnight_5 被 F010/F017 RHS 共享吸收；C003 hard_gate ic_oos=-0.007<0.008 塌缩到 noise）。**只有 C006 用 RHS=amount 绕开 overnight_5 饱和带 + LHS=sign_freq 几何正交 overnight magnitude 聚合，双重 escape 两个吸收律。**

这给出系统级决策要点：rank-diff 候选设计必须同时满足 (a) LHS 与库 dominant signal 几何正交 (b) RHS 与已入库 rank-diff factors 端点不重叠。两者缺一就被吸收。
