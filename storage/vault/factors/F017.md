## 10 · 研究脉络与经济机制

> [!note]- 研究脉络与经济机制

### 市场假说

[[directions/overnight_intraday_split#Hypothesis]] 核心假设是"overnight ((open-prev_close)/prev_close) 与 intraday ((close-open)/open) 是**驱动因子不同**的两段"：overnight = 隔夜消息 + 机构 pre-market 行为；intraday = 日内散户 + 算法博弈。方向原本通过 F009/F010/F011 三因子验证"overnight aggregation（spread / persistence）携带独立 alpha" 后达 **saturated**。本因子（F017）通过 **rank-diff 跨 direction 泛化** 激活方向的"复活条件 (c)：overnight × 其它 signal 非线性交互"，打破 saturated 回归 productive。

### 经济机制

**第一，Overnight informed buying premium**。机构在收盘后拿到信息 → pre-market 限价买入 → 次日 open 跳空。散户无 pre-market 权限只能 open 后跟进。因此 overnight return 是"机构 information advantage" 的直接 proxy。F010 用 5d mean 捕捉 persistence，本因子 LHS 用其 rank 版本——保留信息本质。

**第二，Turnover as "crowd-following" signal**。turnover_rate 是日内换手率（volume / shares outstanding），高 turnover = 散户 + 算法在日内已充分交易，低 turnover = 交易活动少。rank-diff 设计的 RHS 把 turnover rank 从 LHS 减去——剥离"overnight 涨 + 散户跟风"共现时的信号混杂，留下"overnight 涨但散户**没**跟进"的纯机构 accumulation 分位。

**第三，为什么 rank-diff 结构成立**。alpha 来自 cross-section 相对位置的"不协调"——若 overnight rank 和 turnover rank 完全一致（都高 or 都低）说明散户跟风，alpha 信息被噪声冲淡；若 rank 显著不一致说明两个信息源背离，结构性信号存在。这是"rank-diff = signal-family 组合的几何性质"升格教训在 overnight × turnover 上的精确实例。

**失效场景**：
- **熊市 panic overnight**：集体 gap down + 日内恐慌换手，overnight 和 turnover rank 都偏低 → rank-diff 失去判别力（但 OOS 2022 加息年 IC=0.054 仍最强，说明该失效尚未发生）
- **小盘涨停板**：turnover 被物理截断，turnover rank 失真
- **重大事件日**（财报 / 政策）：overnight 和 turnover 都被异常驱动，rank-diff 偏离正常分位

### 实验设计

本因子在 batch_048 中是 **6 候选里唯一 admit**——其它 5 个在 rank-diff 设计空间的不同约束下全部失败：
- C001 `Sub(CsRank(overnight_5), CsRank(intraday_5))` → near_duplicate 0.925@F009（同-direction 被 raw-diff F_parent=Mean(A-B,N) 吸收）
- C002 共 numerator `$open-Ref($close,1)` → ic_oos=0.004 noise（shared-numerator 抵消律）
- C004 `Div(overnight_5, |intraday_5|)` → incr_ic=0.002 + max_corr=0.898@F010（T004 ratio 形式证伪）
- C005 同字段跨窗口 rank-diff → ic_oos=-0.0014 noise（same-field cross-window 抵消律）
- C006 同批 anchor 让位 C003（LHS 共享 overnight_rank）

本因子的成功机制 = 两端**完全独立 direction + 完全独立 raw field + 都 scale-free**——是 rank-diff 几何性质的精确模板。
