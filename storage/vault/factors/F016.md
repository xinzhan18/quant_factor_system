### 市场假说

**Amihud (2002) illiquidity premium**: 高 Amihud `|return|/amount` 的股票承担更高流动性风险，横截面上应获得 return premium 补偿。但 naive Amihud（F012 = 0.443 alpha_surv）被 Barra 7 style（主要是 vol_20d）吸收 56%——说明 raw Amihud 混入了 volatility-magnitude 维度，无法纯粹捕捉 illiquidity 独立载体。

**batch_046 升格教训**: rank-diff symmetric interaction 用 `CsRank(X) - CsRank(Y)` 的 scale-free 差结构，绕开 DSL 层 Div residualize / CsZscore 保序陷阱，把 illiquidity rank 相对 dispersion rank 的"相对位置"提取为新 alpha 载体。F015 兑现了 Amihud vs amount_CV 对；**T007 提出范式泛化问题**——换分母字段（amount → turnover）是否仍 work？

### 经济机制

**第一，高 illiquidity rank + 低 turnover_CV rank 对应"冷门但换手稳定"股票**。这类股票（典型 csi1000 中段蓝筹）日成交额不高（Amihud 高 rank）但换手率分布稳定（turnover_CV 低 rank → 排位更低 → 负号化合并后更高 F016）——兑现 illiquidity premium 但避开 turnover-driven noise trading 的回调风险。

**第二，机制持续性来自 scale-free 几何性质**。rank-diff 两端都是 cross-section rank，对绝对 level 不敏感；即使市场整体放量（amount 和 turnover 同步上升），只要 rank order 相对稳定，F016 信号保留。这是 "signal_half_life=10d + signal_autocorr=0.97"的源头。

**第三，失效场景**：全市场流动性危机（如 2020 Q1 疫情极值期）时 amount 和 turnover rank 会**同步挤压到极值**，rank-diff 两端分辨率压缩——图表中 2020 Q1 20d 滚动 IC 从 0.04+ 降到 0.01-0.02 是这一机制的验证。但恢复后信号立刻回位，不是永久失效。
