## 表达式解读

`Div($pb_ratio, Mean($amount, 20))` 两层构造：

- **分子 `$pb_ratio`**：price-to-book 市净率，静态估值倍数。PB 越高 → 市场赋予账面每一元净资产的溢价越高（增长预期 / 品牌 / 泡沫任选其一）；
- **分母 `Mean($amount, 20)`**：20 日成交额均值，流动性水平度量，单位=元。跨股票差 3–4 个数量级（小盘日均成交几百万，大盘几十亿）；
- **比值语义**：数值**高** = 高 PB **且** 低 amount（小而贵 / 被忽略的贵股），数值**低** = 低 PB **或** 高 amount（热门股 / 大盘便宜股混杂）；
- **经济叙事（与 T001 反号）**：T001 原假设"低 PE/PB × 高换手 = 价值实现"预期 IC 为负；本因子**OOS IC 为正（高值股票后续跑赢）**，反向于 value trap 叙事。真实驱动更像"小盘 × 被忽略 = illiquidity premium"或"边缘股补涨"机制。

**关键语义分裂**：rank 层面（9 年稳定正 IC、完美单调）+ Barra 层面（70% vol_20d）共同指向——**信号存在但机制命名与方向 hypothesis 有偏**，真实驱动不是 value × liquidity 交互，而是 size × illiquidity × residual book-to-price。

## 10 研究脉络与经济机制

> [!note]- 研究脉络与经济机制

### 市场假说

方向 [[directions/value_liquidity_interaction]] 源自 A 股 value × liquidity 交互文献：对"低估值 × 高流动性 = 价值实现 / 低估值 × 低流动性 = 价值陷阱"的二维空间 hypothesis。T001 thread 预期本体构造应产出**负 IC**。

本候选 `Div($pb_ratio, Mean($amount, 20))` 构造上是 T001 的镜像（数值高 = 高 PB × 低 amount，而非原 hypothesis 的低 PB × 高 amount），但 OOS IC **为正** —— 这意味真实市场机制与假设反号：**高估值 × 低流动性的股票后续跑赢**，方向 hypothesis 的"value trap"叙事在 A 股不成立，或被更强的"illiquidity premium + 小盘补涨"机制覆盖。

### 经济机制

**第一，illiquidity premium（首要）**。分母 `Mean($amount, 20)` 截面低 = 流动性差的小盘边缘股。学界长期承认 illiquidity premium（Amihud 2002, Pástor-Stambaugh 2003）——投资者持有低流动性资产要求溢价补偿，在中国 A 股这一机制在散户主导的小盘空间尤其强。

**第二，散户配错 + 机构补仓（次要）**。高 PB 股在散户眼里"太贵不买"，但基本面成长股（高 PB 常对应 ROE 高、增长预期强）会随机构资金挖掘逐步兑现。"被忽略的贵股"这一描述恰好对应机构资金挖掘的阶段性机会。

**第三，Barra 残余 alpha 证据**。即使剥离 vol_20d + log_circ_cap + turnover_20d 等所有"size/vol 代理"后，残余 IC = 0.0094、ICIR = 0.145、alpha_survival_ratio = 0.296，**底层确有 ~30% 的独立 alpha**。若能脱离 $amount 分母的 vol_20d 耦合，真实的 value × illiquidity edge 或可被清洁提取。

**失效场景**：（a）小盘流动性危机（2018 去杠杆 / 2015 Q3 千股跌停）—— 低 amount 股被踩踏；（b）退市新规 / ST 风险集中暴露；（c）大盘蓝筹单边行情（如 2017）—— 小盘因子全面跑输。但 `worst_quarter_ic=-0.004` 表明 9 年历史中没有任何季度出现系统性反向——样本期内这些情景未到 killing 级别。

### 实验设计

本因子位于 batch_005 五候选（C001–C005）中唯一 **IC 为正** 的信号，C001–C004 全部 IC 负 / mono_oos 负，且最终被 reject 或 reserve。C005 作为方向首个 positive 边撑起 T001 thread 的 "positive edge exists but vol_20d-masked" 发现。决策要点：

1. **初判 REJECT（2026-04-18）**：因 direction-level "alpha_survival<0.60 + dominant_style=vol_20d 双触"硬规则。
2. **Retroactive ADMIT（2026-04-19）**：放宽规则后重审，判放行的三大支撑——（i）max_corr=0.029 + incremental_ic=+0.027 的 F001 正交 + 库增量；（ii）符号互补构建 market-neutral 组合可能性；（iii）cum_dd=-2.17 的全库最浅 IC 回撤 + 20d horizon ICIR=+0.786 接近满分的月频信号。
3. **下轮必做复跑**：`Div($pb_ratio, Mean($turnover_rate, 20))` 替换分母为已去除市值的 $turnover_rate，测试是否 alpha_survival > 0.60。
