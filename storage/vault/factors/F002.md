# F002 影线乘积

> [!abstract] 核心洞察
> 上影线 × 下影线直接量化 K 线的"十字星"程度。乘积越大，说明日内多空双方都进行了剧烈试探后回撤——这种==犹豫不决的微观结构==预示着短期负收益。不依赖换手率，是本批次最纯粹的微观结构信号。

## 表达式

```
Mul(
  Sub($high, If(Gt($close, $open), $close, $open)),   -- 上影线
  Sub(If(Lt($close, $open), $close, $open), $low)      -- 下影线
)
```

> 上影线绝对长度 × 下影线绝对长度。当两根影线都长（类似十字星）时值最大。

## 经济机制

> [!note] 为什么影线乘积 = 市场犹豫 = 负收益？

1. **上影线长**：日内有人把价格推高后==卖压回落==
2. **下影线长**：日内有人把价格打低后==买盘反弹==
3. **两者同时长**（十字星）：==多空都在试探，但都无法突破==
4. 不确定性上升 → A 股散户观望 → 短期负漂移

> [!tip] 毒舌点评
> F002 是"市场犹豫"的最简数学表达。alpha_survival=0.44 偏低说明有接近一半的信息量在 Barra vol 里——但 style_r2=0.21 远优于其他候选（0.35~0.61），这是你能买到的最干净的 K 线信号了。coverage=99% 也是优势：几乎每只股票每天都能算出来。
