### 10. 研究脉络与经济机制

> [!note]- 研究脉络与经济机制

### 市场假说

本因子是 [[directions/microstructure_illiquidity]] 方向 T001 线索 1 的首发落子。Direction hypothesis 明确：29 批历史**从未探索 Amihud illiquidity 维度**，而 Amihud (2002) 的 `|return| / $amount` 是流动性风险溢价研究中跨 30+ 年跨市场最稳健的 cross-sectional anomaly——基于"投资者承担流动性风险需要额外 return 补偿"的长期机会成本假说。

### 经济机制

**第一，机制根基是 price impact per dollar。** `|daily_return| / $amount` 直接衡量"每 1 元成交额拉动多少幅度价格"——流动性差的股票需要很少成交量就能走出大行情，即 Amihud 值高；流动性好的股票需要大量成交才能动价，Amihud 值低。20 日均值平滑掉日度噪声，保留截面相对排序。

**第二，为什么持续？A 股散户/机构分层未消失。** Amihud premium 的持续性依赖"市场存在流动性分层+投资者偏好高流动性"这两个前提。A 股机构化进程虽在加速，但散户仍占相当交易比重，且公募/私募对"可投标的"的流动性筛选普遍存在——这就持续制造了"低流动性股票被 systematic 冷落、需要更高预期回报才有人买"的均衡。9 年 IC 全同号 + 2021-2023 回暖说明机制依然运作。

**第三，什么时候失效？流动性极度宽松 + 小盘风格主导。** 2017-2020 IC 最弱的三年，共同特征是"央行宽松+大盘蓝筹/核心资产风格主导"——在这种环境下，流动性充裕使所有股票都"容易交易"，Amihud 的截面差异被压缩；同时资金向大盘聚集，小盘 illiquidity premium 被抽离。2015 股灾、2016 熔断、2023 流动性溢价回归三个"紧缩+风格分化"时段，才是本因子的主场。

### 实验设计

本候选是 batch_030 第一个候选（C001），direction hypothesis 明确声明是方向 T001 线索 1（20d, $amount 分母）的直接落子。Batch 内对比候选包括 C002（其它 window / 分母变体）与 C006（同分母家族），判决时已做 anchor rule 跨候选反思。关键决策点：CP05 max_lib_corr=0.754 > 0.70 (high 档)，但 incremental_ic=0.034 = 阈值 6.7× 触发条件性救援 → admit。Direction 自设硬规则 `max_corr<0.3 + alpha_surv>0.5` 未达标（实为 0.75 / 0.44），但 hypothesis 明确是"方向级愿景"而非单候选硬闸，judge 裁定可 admit 但需在下轮探索 Amihud 正交化变体。

## 批判性审查

> [!danger]- 批判性审查

> [!danger] 一句话毒舌
> 看起来完美单调的 Amihud，其实一半方差是 turnover_20d + vol_20d 的合体，真正独立的那点 alpha，只能靠 incremental_ic 硬证明——独立性不是靠低 corr，是靠 hope。

### 致命弱点

1. **双风格巨柱（turnover_20d=7.78, vol_20d=5.90）。** 表达式结构上 `1/$amount` ≈ 1/turnover，`|return|` ≈ vol；这不是"Barra 碰巧解释"，而是"因子构造本身就是双风格合成"。style_r²=0.47 poor 档是机械必然。
2. **alpha_survival=0.443 仅比阈值 0.40 高 0.04。** 任何一次 Barra 版本升级（新增 style 或重估 IC 标准化方法）都可能让 alpha_survival 跌破阈值。这是"borderline 下沿"的脆弱立足。
3. **与 F002 相关 0.754，admit 完全依赖 incremental_ic=0.034 的 live 兑现。** 若 live 环境中 F002 的组合权重调整或 F002 本身退化，incremental_ic 可能塌缩——此时本因子就变成 F002 的噪音副本。
4. **liquidity_coverage=0.566，样本仅覆盖 56.6% 可投标的。** 这意味着实盘组合若采用较严格的流动性过滤（如日成交额>5000 万），Amihud 的绝大部分 alpha 来源股票会被剔除在可投宇宙之外。
5. **extreme_ratio=0.027 borderline + skew=1.56 右偏。** 右尾极值股票（多为低价新股 / 小盘）主导 Q5；实盘若不 winsorize，少数股票的净值跳跃会主导组合 PnL；若做 winsorize 则可能砍掉真正的 illiquidity premium 来源——两难。
6. **small_cap_concentration=0.351 + log_circ_cap exposure=0.59 = 隐性小盘 beta。** Alpha waterfall 显示 log_circ_cap 是最大 alpha killer（delta_ic=0.0035）。换言之，本因子相当一部分"超额收益"其实是 size premium 的换皮。

### 改进方向

1. **下轮必做：turnover_20d 正交化 + log_circ_cap 中性化的 Amihud 变体。** 若 orthogonalized alpha_survival 能从 0.44 抬升到 0.60+，则本方向"真正独立的 illiquidity premium"才算兑现。
2. **探索"Amihud on F002 residual"。** 在 F002 的残差空间里构造 Amihud 变体，若 IC 还能保持 0.02+，证明 Amihud 有完全独立于 F002 的 alpha 来源；若塌缩，说明本因子确实是 F002 的共线副本。
3. **测试分位数分组 winsorize。** 对 Q5（最极端流动性差的组）单独做 winsorize，看 ls_mean 是否仍保持——这能区分"alpha 来自极值少数股票"还是"来自整组稳健贡献"。
4. **分 regime 测试流动性环境依赖。** 用 M2 增速 / 10 年期国债利率作为 regime 标识，分组计算 IC——如果在宽松期 IC 确实显著弱化，则实盘中需要 regime overlay。

> 实盘部署前必须：(a) 明确可投子集（至少覆盖 50%+ 日均成交额>3000 万的股票）；(b) 对 Q5 极值股做手工检查（剔除新股前 60 天、ST、停牌复牌首 5 日）；(c) 与 F002 仓位错开或做纯 alpha 中性化；(d) 监控月度 IC，若连续 3 个月 < 0 考虑暂停（历史 9 年未出现过）。
