## 10. 研究脉络与经济机制

> [!note]- 研究脉络与经济机制

### 市场假说

**假说**：跨 session 的"接受度"信号——gap 方向（隔夜信息）与 body 方向（日内确认/拒绝）是否同号——携带 pre-market 信息定价偏差的持续性。信息论层面，放量日的接受/拒绝信号信息量更高（市场参与者多 → 共识强），缩量日则信号信息量低。`Log(Div($amount, Mean($amount, 20)))` 提供了"信息量非线性映射"：放量日（ratio >> 1）权重被抬高但被 log 抑制极端尾部，缩量日（ratio < 1）真正变成负权。

该假说在 [[directions/gap_acceptance_structure]] 中迭代到 thread T002。batch_035 已证伪 pure sign interaction 在 csi1000 regime 翻号（Hypothesis 部分证伪），batch_036 T002 的五个"线性 ratio 加权"候选（amount/volume/turnover rate，TS-norm 或 CsRank，20d/40d 窗口）全部被 ic_oos_too_low / oos_decay 拦下——唯一生路正是 log 压缩。

### 经济机制

**第一，放量日的"接受/拒绝"二元信号信息量更高。** 放量日说明专业机构参与度高 → gap 被日内确认/否定的概率更接近 Bayes 信号而非噪声。log 权重保证"异常放量 + 同号接受"的强信号不会被单日极端尾部主导，同时"缩量 + 接受"变成负权贡献（低信息量样本扣分），是"信息量正相关"的数学实现。

**第二，A 股小盘股（csi1000）pre-market 信息扩散周期是 1-2 周。** 隔夜美盘、政策、公告等 pre-market 信息源在小盘股上的扩散期被 T+1 交易规则和散户信息不对称拉长——20 日均值聚合恰好跨越 1 个完整的扩散周期，捕捉"接受度累积偏差"。h=20 OOS IC=0.0224 是该扩散周期假说的最直接实证。

**第三，失效场景有四：**（1）极端流动性事件（2015 股灾日）log_abnormal_amount 同时极大但 gap×body 符号极不稳定 → 2015 IC=-0.0053 唯一负年；（2）全市场涨停/跌停日 body_sign 退化（close = open，sign = 0）；（3）个股停牌恢复首日 gap 反映停牌期累积信息，与连续交易日 gap 性质不同；（4）行业事件型同向波动会让 sign 同号率系统性升高，稀释 cross-section 区分度。

### 实验设计

本因子在 batch_036 为 C004，与 C001/C002/C003/C005/C006 共同探索 gap_acceptance_structure T002 量能加权变体：
- C001/C002/C003：`Div($amount, Mean($amount, 20))` / `Div($volume, Mean($volume, 20))` / `Div($turnover_rate, Mean($turnover_rate, 20))` 三种线性 ratio 加权 → 全部被 ic_oos_too_low 拦下
- **C004（本因子 F013）：** `Log(Div($amount, Mean($amount, 20)))` log 非线性压缩 → admit
- C005/C006：40 日窗口 + CsRank 变体 → oos_decay / ic_oos_too_low

**决策要点**：batch_036 五个线性变体的同时失败 + log 变体的单点突围，证明"log 非线性压缩"是 csi1000 上这个方向的**必要结构**，而非可替换细节。这是 batch_036 最重要的 direction-level 洞察——mono_OOS 0.30 → 0.60 翻倍是 log 权重修好 rank-order 的硬证据。paper QuantaAlpha (arXiv 2602.07085v2) §5 给出 CSI 300 大盘 Rank IC 0.0744，我们 csi1000 实测 0.0094，约 8× 衰减，印证 small-cap regime 下衰减规律；direction 因使命完成建议转 saturated。

## 批判性审查

> [!danger]- 批判性审查

> [!danger] 一句话毒舌
> **F013 的 IC_OOS=0.0094 仅在 weak 档下界，ICIR=0.253 moderate，admit 过关靠的是 mono_OOS 从 batch_035 的 0.30 翻倍到 0.60 + 反衰减签名 + 库独立性——一个"综合分刚好及格"的 borderline admit，且 Log 分母依赖使其在实盘部署前必须加 clip 保护。**

### 致命弱点

1. **IC_OOS 仅 0.0094，只在 weak 档下界（阈值 0.008）。** 任何下一批样本的微幅劣化（比如再一次极端流动性年份）都可能跌破 hard gate；单 h=1 信号力度不足以支撑独立因子，下游必须与其他因子组合使用或转长持有期（h=10/h=20）。

2. **Log 分母依赖是结构性脆弱点，extreme_ratio=0.011 borderline。** `Log(Div($amount, Mean($amount, 20)))` 在极小 amount 日（停牌恢复首日、流动性枯竭日）产生 -∞ 发散；Phase 2 Python 实现已观察到 divide-by-zero warning；实盘必须 clip。extreme_ratio 0.0109 离 poor 阈值 0.03 尚远，但"离 clean 阈值 0.01 仅差 0.001"说明分布尾部已被 log 拉伸到边界。

3. **cum_ic_max_drawdown=-2.31，2015 股灾年主导。** 虽然 2016-2023 8 年正向，但 2015 单年的深回撤说明极端市场环境下因子会系统性反向——实盘组合需设置 vol regime filter 或 conditional 调仓。worst_quarter_ic=-0.029 ≈ 3× \|ic_oos\| 也佐证"依赖某季度反向 outlier"。

4. **Q5 接近零的顶端回落——非完美单调。** OOS Q5 年化仅 0.66%，Q3 反而 3.07% 是最高正档，形状是"avoid worst + 中段正峰 + 顶端轻度回落"，L/S t=3.23 主要由 Q1 空头端（-8.25%）贡献。**信号是"识别垃圾" >> "识别明星"**——在纯多头策略中的适用性有限。

5. **方向已 saturated，ROI 下降。** mt_bucket=high (raw 0.7119) 反映 gap_acceptance_structure 方向已用过 6 candidates、family 已饱和——下批同方向探索 ROI 进一步下降；admit 后 [[directions/gap_acceptance_structure]] 建议转 saturated，Phase 5 consolidation 时清理线程。

### 改进方向

1. **实盘部署前加 clip 保护**：`amount_ratio = clip(amount / mean_amount, 0.05, 20)` 再取 log，防止极小 ratio 发散。该实现细节应在 python_factors/F013 archived 实现中同步。
2. **优先 orthogonalize by str_1m 而非 vol_20d**：alpha killer 归因显示 str_1m (21.6%) > turnover_20d (14.6%) > vol_20d (2.3%)——vol_20d 虽 exposure 最高但 delta_ic 可忽略，orthogonalization 的正确目标是 str_1m。
3. **切换至 h=5 或 h=10 持有期**：ic_by_horizon 显示 OOS ICIR 从 h=1 的 0.253 升至 h=10 的 0.502、h=20 的 0.564——下游组合构建应以中频（1-2 周调仓）为主。
4. **组合层加 vol regime filter**：2015 股灾的反向驱动了 cum_ic_dd 的大部分；若能在高 vix / 系统性恐慌期段停用本因子，IC 稳定性可大幅改善。
5. **探索非对称 log 权重**：当前 log 对称压缩放量和缩量，但缩量日信号信息量本就低，可试 `Log(max(amount/mean_amount, 1))` 只保留放量端权重——下一方向候选。

> [!warning] 使用警告
> 实盘部署前必须：(a) 对 `amount/mean_amount` clip 至 [0.05, 20] 再取 log；(b) 设置 2025 Q1 IC 监控线，若 3 月累计 IC < 0 则冻结；(c) 优先构建为 h=5/h=10 中频信号而非 h=1 日频信号；(d) 在极端市场环境（股灾/熔断）启用 regime filter 暂停信号使用。

## 系统意义

> [!tip]- 系统意义

### 验证了什么

1. **Log 非线性压缩是 csi1000 "跨 session 接受度"方向的必要结构**——batch_036 五个线性变体同时失败 + log 变体单点突围，证明"log 权重"不是可替换细节而是机制核心。这是 direction-level 的决定性证据。
2. **anti-decay 签名在行为微结构类因子上可以出现**——与近邻 F010（5d overnight return）一起，证明 csi1000 上某些机制根源稳固的因子确实可以 OOS > IS。下游 CP06 rubric 可据此增加"anti-decay 加分项"。
3. **h=1 weak 但 h=20 strong 的多持有期分化**——OOS ICIR 从 0.253 升至 0.564，揭示因子适用的持有期不是 h=1 而是 h=10-20；为后续 factor library 的 "natural holding period" 元数据字段提供新 case。
4. **Python escape hatch 的边界案例**——本因子虽可用纯 DSL 表达，但 `Log(Div(...))` 的极端值处理是 DSL 不擅长的；Phase 2 的 divide-by-zero warning 指向 R8 下 DSL + Python clip wrapper 的混合实现模式可能是下一阶段的标准做法。

### 后续方向

1. **gap_acceptance_structure 方向转 saturated**：mt_bucket=high + 本因子使命完成（mono_OOS 0.60 证伪"线性 ratio 路径"+ 证明"log 压缩路径"），Phase 5 consolidation 评估方向休眠。
2. **探索非对称 log 权重**：如上所述，仅保留放量端权重的变体可能进一步抑制缩量日噪声。
3. **跨持有期 family**：batch_037+ 可尝试 `Mean(..., 40)` / `Mean(..., 60)` 长窗口变体，对齐 h=20 的 strong ICIR 证据。
4. **行为微结构家族扩展**：本因子是第一个通过"跨 session 接受度"机制 admit 的因子，后续可探索 `gap × next_day_body`（滞后接受度）、`body × next_day_gap`（反馈循环）等变体构建 family。
