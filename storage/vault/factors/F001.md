# F001 下影线 × 换手率

> [!abstract] 核心洞察
> 高换手率环境下的长下影线（"放量探底"）并非买入信号——恰恰相反，它预示着短期负收益。这揭示了一个行为偏差：散户把下影线解读为"有人在接盘"，但在高换手的 A 股市场里，这往往是"主力试探出货后撤退"的痕迹。

## 表达式

```
Mul(
  Div(
    Sub(If(Lt($close, $open), $close, $open), $low),
    Sub($high, $low)
  ),
  $turnover_rate
)
```

> 下影线比例 × 换手率。下影线比例 = (阴线收盘价或阳线开盘价 - 最低价) / (最高价 - 最低价)。

## 经济机制

> [!note] 为什么下影线 × 高换手 = 负收益？

1. 长下影线 + 高换手率 = 盘中出现了==大幅下探后反弹==的走势
2. 在高换手的背景下，这种"探底"往往不是散户恐慌性抛售，而是**机构在试探下方支撑的深度**
3. 试探后价格虽回到收盘价附近，但==卖方的意图已经暴露==
4. 次日起，卖压继续释放 → 短期 1-5 天负收益

> [!tip] 毒舌点评
> 这个因子本质上说的是："放量探底不是抄底机会，而是出货预告。" 散户在这里赔钱的核心原因是把机构的试探性出货误读为支撑买盘。但 style_r2=0.36 说明有相当部分只是在重复波动率因子——后续需要 CsRank 正交化验证。

## 逐图解读

### 分组收益

![[F001/quintile_returns.png]]

Q1（因子值最低 = 低下影线×低换手）日均正收益，Q5（因子值最高 = "放量长下影"）日均负收益。==完美单调==（mono=-1.0），收益差异在 Q4→Q5 处出现断崖。

> [!warning] 负方向因子
> 实际使用时取反：做多 Q1，回避 Q5。

### Barra 风格暴露

![[F001/barra_exposure.png]]
