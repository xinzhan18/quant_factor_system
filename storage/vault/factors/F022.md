## 研究脉络与经济机制

### 市场假说

[[directions/overnight_intraday_split]] 把 daily return 分解为 overnight (open vs prev_close) 与 intraday (close vs open) 两段，假设两段被不同主导因子驱动：overnight = 隔夜消息 + 机构 pre-market、intraday = 日内散户 + 算法。前 7 个 admit 都是 overnight 维度（F009–F011 magnitude / F017–F018 rank-diff），本因子是该方向首个**纯 intraday LHS** 的 admit——验证了 "intraday 段在 cross-section 上仍存在独立 alpha" 的子假说，且这条 alpha 通过 close-position-in-range 这个 normalized atom 表达。

### 经济机制

**第一，close-position 是 marginal buyer/seller 强度的微结构 footprint。** 一只股票如果连续 20 个交易日的收盘价都接近日内最高（C 接近 H），意味着每天日终 buy-side pressure > sell-side pressure；反之收盘接近最低反映 sell-side 主导。这种"日终 bid-ask 不平衡"在散户主导的 csi1000 上比 csi300 更持续——机构盘在大盘股上会做日终对冲压平 footprint，散户盘则放任。

**第二，amount 5/60 加速比是 attention proxy 而非流动性 proxy。** RHS=amount_5/amount_60 = 1.0 时表示成交活跃度持平、>>1 表示突然爆量、<<1 表示成交萎缩。"低 close-position + 高 amount-accel" 组合是"放量下跌"——散户恐慌出货；"高 close-position + 低 amount-accel" 是"无量上涨"——机构悄然吸筹。rank-diff 几何把这个组合 cross-section 化，捕捉两端 spread。

**第三，因子失效场景集中在三类。** (a) 极端单边市（全市场涨跌停连板）下 close-position 触顶 1 或触底 0 失去 cross-section 区分度；(b) 停牌恢复初期 5d amount 与 60d 量级失衡导致 RHS 噪声；(c) 极端 sentiment shock（如 2018 大跌）下"日终 footprint"被全市场 risk-off 完全淹没——这也是 IS 段 2018 年 mono 翻号的根源。

### 实验设计

batch_058 是按 cockpit "vol_20d 正交 atom + long-window scale-free RHS" 强约束设计的 6 候选 batch，T012 thread 测 close-position-in-range LHS。同批 C006 是本因子的 60d 长窗版本（reject）—— **C004 (20d) alpha_surv=0.43 vs C006 (60d) alpha_surv=0.19** 是同方向同 atom 不同窗口的对照实验，结论是"close-position LHS 短窗版本是 vol_20d 正交 atom 兑现，长窗放大 vol 吞噬"。
