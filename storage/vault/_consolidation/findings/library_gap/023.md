## 阈值 sensitivity 律 (round 99 升格 candidate)

同一信号底层 `(C-L)/(H-L)` 在不同阈值方向, Barra 同构性 sign-dependent:
- **Lt(.,0.2) 弱端 tail**: ⊥ vol_20d (F029 admit)
- **Gt(.,0.5) 上半段**: 部分 // vol_20d (b098/C001 alpha=0.50)
- **Gt(.,0.8) 强端 tail**: 深 // vol_20d (b099/C003 sign_flip ×3)

机理 (round 99 升格): csi1000 daily close-position 分布 left-skewed, Lt(low_threshold) 选 left-tail thick event ⊥ vol regime; Gt(high_threshold) 选 right-tail event 与涨停日 (close=high) 共振 vol regime sensitivity.

## 建议探索

**suggested direction tag**: `binarize_geometry_barra_orthogonal`

### Phase 1 — middle-body 主导日 family
不是 close-position, 不是 shadow, 第三种 candle 几何子轴:
1. `Mean(Lt(Div(Abs(Sub($close, Mul(Add($high,$low), 0.5))), Sub($high,$low)), 0.3), 20)` — close 靠近中点日 rate
2. `Mean(Gt(Div(Abs(Sub($close, $open)), Sub($high,$low)), 0.7), 20)` — 大实体日 rate

### Phase 2 — 弱端 binarize 跨 candle 字段
对偶 F029 把 numerator 切换:
1. `Mean(Lt(Div(Sub($high, $close), Sub($high,$low)), 0.2), 20)` — 弱上影日 rate (= 上影微小 = 强 close 反向几何)
2. `Mean(Lt(Div(Sub($high, $open), Sub($high,$low)), 0.2), 20)` — 弱 open 高位 rate

### Phase 3 — 跨日 inside-bar family
`Mean(Mul(Lt($high, Ref($high,1)), Gt($low, Ref($low,1))), 20)` — daily range narrower than prior day rate. 不同于 b098/C006 跨日 body-sign pattern (regime-dependent), inside-bar 是 pure range geometry.

### Phase 4 — 弱端 binarize × Std/Skew 包装
对 F029 outer wrap (b099 next probe (a)):
1. `Std(Lt((C-L)/(H-L), 0.2), 60) / Mean(Lt(...), 60)` — 弱收盘日 rate 的 CV
2. b099/C003 实证 `Std-of-binarize 60d ≈ Mean-of-binarize 60d` 数学等价 (Var(Bernoulli)=p(1-p)) — 这条**Std/Skew wrap 在长窗 dead**, 但 **20d 窗 + 短 binarize event-rate** 可能保留 variance dispersion 不与 Mean 共线
