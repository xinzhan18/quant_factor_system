# library_gap/005 · Residual paradigm 仅有 cross-sectional Barra 单一形态，时序回归残差完全未试

## Observation

库内 residual-based admit 仅 2 个：
- F004 `barra_residual_return`：cross-sectional Barra style residual
- F005 `barra_residual_alpha_60d`：F004 的 60d 累积版

两者的 residualization 方法**完全相同**：cross-sectional Barra OLS（每日横截面回归）。batch_054 6/6 hard_gate fail 揭示的 4 条机制中，第 1 条是结构性的："residual + rolling 在 csi1000 系统性 coverage ≈ 0.71 < 0.80 hard_gate"——**这条死锁的是 Barra-cross-section + DSL-rolling 的组合**，不是 residual paradigm 本身。

**完全未尝试的 residual 形态**：
1. **Time-series rolling regression residual**: `Resi($close, $market_index, 60)` —— 个股对市场指数的 60d 回归残差 = 时序 alpha
2. **Pair / sector residual**: 对行业基准 (e.g., `Mean($close_in_sector, N)`) 的 cross-sectional residual
3. **Multi-factor library residual**: 对**库内已 admit 因子线性组合**的残差（admit 完一个 F021 后，新候选可计算 `signal − projection_onto_F021`）—— 这是 b051 升格律 "Barra-clean ≠ library-clean" 的天然解药
4. **Nonparametric residual** (kernel / quantile)：batch_054 thread T014 "复活路径" 第 (b) 条明确列出 "nonparametric residualization" 仍未尝试

## 结构性缺口

- **Residualization 方法族整片空白**：所有 residual admit 都来自单一方法 (cross-sectional Barra OLS)。
- batch_054 thread T014 退出 DISPROVEN 时，judge 自己列出 "复活路径再次缩窄：(a) 非 Barra style basis / (b) nonparametric residualization / (c) 与库非线性 ensemble 三条仍未尝试"—— 这是 judge 已识别但未执行的 gap。
- batch_059 反复出现的 "library reducer" 陷阱（5 次复现：strong-but-negative-incr）—— 暗示 **library-residual** 路径（直接对已 admit 因子线性投影后取残差作 LHS）可以系统性绕开 reducer 陷阱。
