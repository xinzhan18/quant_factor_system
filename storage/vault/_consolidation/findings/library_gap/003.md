# library_gap/003 · 单窗口（5d / 20d / 60d 之一）独占库——multi-horizon blend / horizon-spread 结构未尝试

## Observation

20 admitted 因子的窗口分布扫描：

| factor | 主窗口 | 是否 multi-horizon |
|---|---|---|
| F001 amount_cv | 10d (内嵌) | 单窗口 |
| F002 pb_amount_ratio | 20d | 单窗口 |
| F003 overnight_gap_normalized | 1d | 单窗口 |
| F006/F008 upper_shadow_persistence | 5d / 3d | 单窗口 |
| F007 open_position_persistence | 5d | 单窗口 |
| F009/F010/F011 overnight 系 | 5d / 3d | 单窗口 |
| F012/F015/F016 amihud 系 | 20d (rank-diff 内嵌 10d for amount_cv) | 单主窗口 |
| F013 log_amount_weighted_acceptance | 20d | 单窗口 |
| F014 vwap_overnight_spread | 1d | 单窗口 |
| F017/F018 overnight rank-diff | 5d / 20d | 单窗口 |
| F019/F020 OHLC/gap higher-moment | 20d | 单窗口 |

**20/20 是单窗口因子**。F015 / F016 内嵌不同窗口 (Amihud 20d × amount_cv 10d / turnover_cv 20d) 但**这是 LHS/RHS 不同 atom 各自带各自窗口**——不是同一信号在多窗口上的 blend。

库里完全没有：
- **同 atom 跨窗口 blend** —— 如 `(Mean(X,5) + Mean(X,20) + Mean(X,60)) / 3` 的"horizon-averaged" 形态
- **Horizon-spread / cross-horizon ratio** —— 如 `Mean(X,5) / Mean(X,60)` 的"短期 vs 长期"比值（注意 b048 C005 同字段跨窗口 rank-diff 是退化 noise，但 ratio/blend 不同）
- **EWMA decay-weighted 多窗口** —— 如 `EMA(X, span=5) - EMA(X, span=20)` 的 MACD-style spread
- **Horizon-conditional weighting** —— 如"高 vol regime 下用短窗，低 vol regime 下用长窗"

batch_048 C005 已证伪 "**rank-diff** 同字段跨窗口"（CsRank(20d) − CsRank(5d) → noise，因 rank 高度共线）—— 但 **ratio / EMA-spread / weighted-blend 路径不同**：ratio 保留 magnitude 信息（rank-diff 抹掉），EMA spread 是 ifference of smoothing kernels（rank-diff 是 Sub of ranks）。

## Reserve 证据

无直接 multi-horizon reserve（因为根本未设计）。但：
- batch_045 reflection 显式提："Kurt 长窗变体 (90d/120d)" 待测——这是单窗口 sweep，不是 blend
- batch_047 T005 thread "≤5d 短窗 vs 20d 窗口" 对偶探索——证明短/长窗口 trade-off 是真实研究问题，但 admit 仍是单窗口 (F015/F016 都 20d)
- batch_054 C005 `EMA(res,5) − EMA(res,20)` 是首次 EMA-spread 设计——但因 residual coverage hard_gate fail，EMA spread 几何本身没被测试到 metric 层

## 建议探索

1. **Cross-horizon ratio of admitted atoms** — 取 admitted F-list 里的 atom 做不同窗口的比值。例如：
   - `Div(Mean(amount_cv, 5), Mean(amount_cv, 60))` — F001 atom 的短/长比
   - `Div(Std(body_ratio, 5), Std(body_ratio, 20))` — F019 atom 的短/长 vol-of-vol

2. **EMA-spread (MACD-style) on raw OHLCV atoms** — 在 OHLCV 空间用 `Sub(EMA($close, 5), EMA($close, 20))` 等结构。EMA 与 Mean 不等价（指数衰减权重）→ 与 F009-F011 不重复。

3. **Horizon-blended rank-diff** — `Sub(CsRank(Mean(X, 5)), CsRank(Mean(X, 60)))` 不同窗口的同字段 rank-diff。b048 C005 已证 rank-diff 该形态 noise，**但需检验在 magnitude/level differential 路径上是否同病**——`Sub(Mean(X, 5), Mean(X, 60))` 的 level spread 还未测。

4. **Adaptive horizon (regime-conditional)** — `IfElse(Gt(Std($close,20), Mean(Std($close,20),60)), Mean(X, 5), Mean(X, 20))`。需 IfElse 算子（与 finding F100 第 4 条交叉）。

## severity 判据

**medium**：(1) 20/20 单窗口确实是结构性空白；(2) 但 batch_048 C005 的 rank-diff 同字段跨窗口 disproven 警示——blend 几何不一定 productive；(3) 缺 reserve 证据，属"推测性缺口"；(4) 但 cross-horizon ratio 是 zero-cost 测试且与库相关性预期低，值得排进未来 batch；(5) 适合开新 direction `multi_horizon_blend`（不绑定具体 atom，而是绑定结构）作为系统性 sweep。
