# library_gap/003 · 所有 admitted 都是单一窗口，multi-horizon blend 完全未尝试

## Observation

23 个 admitted factor 全部基于**单一时间窗口** (1d / 3d / 5d / 10d / 20d / 60d 之一) 或单一窗口分子/分母组合：

- 单窗一阶聚合：F001 (Std/Mean@10), F006-F011 (5d/3d), F012/F013 (20d), F022 (20d × 5d/60d) ...
- F022 是**唯一**含 short/long 比例 RHS：`Div(Mean($amount,5), Mean($amount,60))` —— 短窗/长窗 amount accel
- F021 是**唯一**含 long-window scale-free 60d RHS

**0 个 admit** 包含 multi-horizon blend in LHS（如 `Mean(X, 5) - Mean(X, 60)` 或 `Mean(X, 20) / Mean(X, 60)` 作为 LHS atom）。所有 LHS atom 都是**单一窗口的**。

batch_058 thread T011/T012 揭示：close-position 20d alpha_surv=0.43 (admit) vs 60d alpha_surv=0.19 (reject) —— **同 atom 不同窗口行为完全不同**；sign-product 20d mono=0.4 (reject) vs 60d mono=0.9 (reserve) —— **窗口长度对 vol_20d 吞噬有非线性响应**。这意味着 multi-horizon blend (e.g., `Mean(close_pos_20d) - Mean(close_pos_60d)`) 可能是**结构上独立**的 axis：在 short window 信号活、long window 失活的 LHS 上，差值本身是 "alpha decay rate" 信号，与单窗信号正交。

## 结构性缺口

- **窗口家族缺口**：只有 F022 RHS 含短/长窗 ratio，**0 个 admit 在 LHS 做 multi-horizon blend**。
- **EMA(short) - EMA(long) MACD 类 LHS** 全库 0 admit。
- **Mean(X, 5) - Mean(X, 60)**（动量加速）作为 LHS atom 0 admit。
- **Std(X, 5) / Std(X, 60)**（vol-of-vol ratio）0 admit。

batch_054 C005 (`EMA(res, 5) − EMA(res, 20)` 残差多周期 decay 差) 是**最接近 multi-horizon blend** 的候选，被 coverage hard_gate KO（**信号本身良好** ICIR_oos=-0.169 + alpha_surv=1.57 + style_r²=0.024 极清洁）—— 证据：multi-horizon blend 在 DSL 层尚未真实进入 admit 漏斗。
