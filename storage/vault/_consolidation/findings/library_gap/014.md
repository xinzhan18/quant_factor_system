# library_gap/014 · Qlib Corr/Cov cross-field 数据契约缺陷阻断 valuation × liquidity 整片设计空间

## Observation

b079 设计阶段意图覆盖 PIT valuation × liquidity × num_trades 全 frontier，**5 个候选
直接 broadcast crash**。Judge 直接陈述 P019 升格 candidate (数据契约层):

> "Qlib 二进制 [start_index:f32][data:f32×N] 格式中, PIT valuation 字段 / TTM ratio 字段 /
> $turnover_rate 字段 与核心 OHLCV start_index 不一致 (因为 RiceQuant 同步时, valuation/turnover
> 数据从 sec 元年 ≠ price 数据起始点). 当 Corr(safe_field, broken_field, N) 在多股票 universe
> 评估时, 内部 series_left.rolling.std() 与 series_right.rolling.std() shape 不匹配
> (e.g. 2620 vs 2674) → np.isclose broadcast crash, 整批 compute 终止"

**实证 Corr-unsafe 字段集** (整批 crash):
- 全部 PIT valuation: `$pe_ratio, $pb_ratio, $ps_ratio, $pcf_ratio`
- 全部 TTM ratio: `$peg_ratio_ttm, $pcf_ratio_total_ttm, $dividend_yield_ttm` (推论扩展所有 TTM)
- `$turnover_rate`

**Corr-safe 字段集**: `{$close, $open, $high, $low, $volume, $amount, $num_trades}` — 仅 7 字段

这意味着 DSL 层 `Corr(A, B, N)` / `Cov(A, B, N)` 只能在 7-字段 OHLCV 子族内做 35 个
有序对组合 (`C(7,2)=21` 对 + 自相关) — 大部分已被 b075/b079 测试且全部 reject (alpha 真饱和)。
**整片 valuation × liquidity 时序协动 frontier 因数据契约 bug 不可达**。

## 结构性缺口

- **数据契约 bug 阻断设计空间**: 不是 alpha 不存在而是计算路径 broken
- **未饱和 frontier**:
  - `Corr($turnover_rate, $pe_ratio, 60)` — turnover × value 时序协动 (vs b075 raw Cov 已死)
  - `Corr($num_trades, $dividend_yield_ttm, 60)` — institutional flow × yield 协动
    (b075 C006 用 raw Cov 是 alpha_surv=1.94 risk-clean 火种, Corr 形态是其 normalized 版)
  - `Corr($amount, $peg_ratio_ttm, 60)` — amount × growth-adjusted value
- **lessons.md macro 已 codify "csi1000 daily fundamental + institutional flow 真饱和"**
  但其证据基础是 raw Cov / level / TsRank — Corr 形态因 bug 未充分证伪
- **修复成本不高**: Python wrapper 用 NaN-aware rolling cov / std 包裹两 series，
  避开 Qlib `np.isclose` broadcast assertion

## 建议探索

**两条互补路径**:

**路径 A — 数据 loader 修复 (上游)**:
- `scripts/sync_financials.py` / `scripts/resync_qlib.py` 端，把 valuation/turnover 字段
  start_index 与 OHLCV 对齐 (向前 ffill 或截断至共同 start)
- 一次修复，DSL `Corr` 直接可用，整片设计空间打开
- 修复成本: 1 次脚本 patch + 数据重同步 (~30min)

**路径 B — Python wrapper Corr_safe (下游)**:
- 新 Python operator `corr_safe(A, B, N)` = `Mean((A−Mean(A,N))(B−Mean(B,N)), N) / Std_safe`
  内部用 `np.where(isfinite, ..., NaN)` 容错 broadcast shape mismatch
- 注册到 `Operators._ops`, DSL 层用 `CorrSafe` 调用
- 不改数据，只改算子

**首批 6 候选** (走路径 B, 验证缺口确实有 alpha):

1. `CorrSafe($turnover_rate, $pe_ratio, 60)` × CsRank
2. `CorrSafe($num_trades, $dividend_yield_ttm, 60)` × CsRank (b075 C006 normalized 版)
3. `CorrSafe($amount, $pcf_ratio, 60)` × CsRank
4. `TsRank(CorrSafe($turnover_rate, $pb_ratio, 60), 60)` (TsRank wrap, P008 escape 路径)
5. `Sub(CsRank(CorrSafe($num_trades, $dividend_yield_ttm, 60)), CsRank(F012))` rank-diff
6. `CorrSafe($volume, $pe_ratio, 120)` × CsRank — 长窗 valuation 协动
