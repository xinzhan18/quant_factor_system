# F100 · rank-diff `Sub(CsRank(A), CsRank(B))` 单一结构占据 30% 库 slot — 替代复合算子族（Add / Mul-rank / IfElse / 三元 rank composition）系统空白

## Observation

20 个 admitted 因子中 **6 个 (F015-F020) 是 `Sub(CsRank(A), CsRank(B))` 严格同结构**，集中分布在 batch_046-051 连续 6 批；占库 30%、占近 6 批 admit 的 100%。

`Sub(CsRank, CsRank)` 是**二元 rank-diff**——CsRank 在算子族里属"cross-section rank-transform"，Sub 是"二元 rank composition"。但库里完全没有：
- **Add(CsRank, CsRank)** — rank 求和形态（共动同向 signal 而非 spread）
- **Mul(CsRank, CsRank)** — rank 乘积（rank-product 经典 multi-signal aggregation）
- **三元/N 元 rank composition** — `Sub(CsRank(A), Add(CsRank(B), CsRank(C))/2)` 等
- **CsRank 嵌套在 Mul/Div 之外的混合结构** — 如 `Mul(CsRank(A), Sign(B))`、`Mul(CsRank(A), Mean(B,N))`
- **IfElse / Gt / Mask 条件 rank** — 如"高 turnover 子样本上的 rank vs 低 turnover 子样本上的 rank"
- **CsRank-based residual** — `Sub(CsRank(A), Mean(CsRank(A), N))` 或 cross-sectional zscore

batch_047 C001/C004 anchor rule 已升格教训"Sub(A,B) = -Sub(B,A) 对偶 dedup"——但此教训只覆盖了**Sub 一种二元 composition**。Add/Mul rank composition 的对偶性 / 信息几何 / library 占位行为完全未测。

batch_049 揭示"RHS 共振饱和律"+ batch_052/053 揭示"factor-anchored cluster 动态律"——这些都是 **Sub 几何下的现象**，无法判断 Add/Mul/IfElse rank composition 是否同病。

## Reserve 证据

无直接 Add/Mul rank reserve（因为根本没设计过该结构的候选），属"未尝试"而非"尝试后失败"。
但 batch_050 T012 thread 已显式标 "moment 选择是 rank-diff LHS 设计的独立轴"——同等地，**rank composition 算子（Sub vs Add vs Mul）是 rank-diff 几何的另一个未探索独立轴**。

## 建议探索

按风险递增顺序：

1. **`Add(CsRank(A), CsRank(B)) / 2`** — rank 共动 (vs Sub 是 rank 分歧)。同样满足 scale-free × scale-free 设计原则；与已 admit 的 F015-F020 几何上互补 (corr 应近 0)。
   - 候选示例：`Add(CsRank(Mean(Std(close,5),20)), CsRank(Mean(amount,20))) / 2`

2. **`Mul(CsRank(A), Sign(B))`** — rank × 方向门 (替代 `Sub(CsRank, CsRank)` 让方向信号成为 sign 而非 rank)。  
   - 候选示例：`Mul(CsRank(Std(gap_ret,20)), Sign(Mean(overnight,5)))`

3. **三元 rank composition** — 如 `Sub(CsRank(A), Mean(Add(CsRank(B), CsRank(C))/2, 1))` 把 RHS 由单 atom 改为 rank-pool。可能突破"RHS 共振饱和律"（因为 RHS 不再是单 atom 而是 atom-pool）。

4. **IfElse / Mask 条件 rank** — `IfElse(Gt($turnover_rate, Mean($turnover_rate, 60)), CsRank(Std(body_ratio,20)), 0)` 等。把 cross-section rank 限制在条件子样本上，可能产生 regime-conditional 子空间。

## severity 判据

**high**：(1) 单一 composition 算子占 30% 库 slot 是结构性集中风险——若 rank-diff 范式整体 regime sensitivity 翻号（b052/b053/b054 已揭示 higher-moment LHS 跨 regime 翻号倾向），库 30% 同时 degrade；(2) Add/Mul rank composition 是 zero-cost 测试（DSL 已支持，无需新算子），不测属于直接 leave-money-on-table；(3) 与 batch_050 T012 "moment 独立轴" 升格教训形成双轴结构性论证。
