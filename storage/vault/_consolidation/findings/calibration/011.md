# calibration/011 · Phase 1 self-check: Cov(X, Y, N) ≈ Mean(X*Y, N) for zero-mean stationary fields 等价律

## 证据

### Trigger 来源 (b087/C005 narrative 显化)

batch_087 candidate C005:

```
expr: Cov(Div(Sub($open, Ref($close,1)), Ref($close,1)),
          Div(Sub($close, $open), $open),
          20)
```

verdict: **hard_gate near_dup**. cross-section corr=0.927@F023 (库内 admit
factor F023 = `Mean(Mul(Div(Sub($open,Ref($close,1)),Ref($close,1)),
Div(Sub($close,$open),$open)), 20)`).

**机理 (b087 narrative L 段已升格 P028 候选)**:

csi1000 daily 个股 overnight return + intraday return 的 N-day (N=20-120)
Mean 数值 ≈ 0 (zero-mean stationary). 故:

`Cov(X, Y, N) = E[XY] - E[X]E[Y] ≈ E[XY] - 0 ≈ Mean(X*Y, N)`

cross-section ranking 上 Cov 与 Mean(X*Y) 等价度 ≥ 0.92 (实测 0.927). F023
已 admit (b059 入库 Mean of product 形式), 后续所有同 X-Y pair 的 Cov(X,Y,N)
candidate 都 cross-section near_dup, hard_gate 在 Phase 3 拦下.

### 与 P024 同律不同 layer

P024 (lessons.md#In-batch denominator family equivalence) 处理同一 batch 内
denominator 不同但分子相同的 candidates (e.g. `Div(X, $volume)` vs
`Div(X, $amount)` 在 csi1000 cross-section 高度共线). P024 已 codify Phase 1
generator self-check.

P028 (本 finding 升格候选) 处理 cross-batch zero-mean Cov vs 同期 Mean of
product 等价. 同性质 (数学等价 → cross-section 高度共线) 但不同表达式形态,
应作为 Phase 1 self-check 第 9 条独立条目.

### 同源 historical evidence

reserve pool 全量扫:
- b003/C005 `Corr($amount, Sign(Delta($close, 1)), 20)` — `Sign(Delta)` 是
  zero-mean ({-1, 0, +1} 三值 stationary, mean 接近 0) 但 $amount 是
  level field (mean ≈ 1e8 大量级), 故 Cov ≠ Mean(X*Y) 等价 — **不在本
  律适用范围**, 留 reserve pool

- b087/C005 是首例完整命中: zero-mean (overnight) × zero-mean (intraday)
  × 短窗 20d → 直接命中

未来 overnight_intraday_split / signed_money_flow_oscillator / barra_residual_alpha
方向若再设计 `Cov(return_A, return_B, N)` 形式都会重复触发. 启用 self-check
节省 candidate slot.

## 实现建议

### Phase 1 generator AST self-check 第 9 条

`src/research/checkpoints/generator.py` 或 `src/research/phases/phase1_start.py`
self_check 函数加规则:

```python
ZERO_MEAN_RETURN_FIELDS_PATTERNS = [
    # daily return forms
    r'Div\(Sub\(\$close, Ref\(\$close, 1\)\), Ref\(\$close, 1\)\)',
    # overnight return forms
    r'Div\(Sub\(\$open, Ref\(\$close, 1\)\), Ref\(\$close, 1\)\)',
    # intraday return forms
    r'Div\(Sub\(\$close, \$open\), \$open\)',
    # generic Delta/$close ratio forms (pattern match)
    r'Div\(Delta\(\$close, \d+\), Ref\(\$close, \d+\)\)',
]

def is_zero_mean_return(expr_ast):
    """检测 expression 是否数学上是 zero-mean stationary."""
    expr_str = ast_to_string(expr_ast)
    return any(re.search(p, expr_str) for p in ZERO_MEAN_RETURN_FIELDS_PATTERNS)

def cov_mean_product_equivalence_check(candidate_expr, library):
    """Phase 1 self-check: 若 Cov(X, Y, N) X+Y 都 zero-mean, 检查库内
    Mean(X*Y, M) 是否已 admit (M ∈ [N-20, N+20])."""
    if not isinstance(candidate_expr.root, CovOp):
        return PASS
    X, Y, N = candidate_expr.root.args
    if not (is_zero_mean_return(X) and is_zero_mean_return(Y)):
        return PASS
    # 检查库内
    for f in library:
        if f.expr.root.op == 'Mean':
            inner = f.expr.root.args[0]
            M = f.expr.root.args[1]
            if isinstance(inner, MulOp) and abs(M - N) <= 20:
                inner_X, inner_Y = inner.args
                if (ast_equiv(inner_X, X) and ast_equiv(inner_Y, Y)) or \
                   (ast_equiv(inner_X, Y) and ast_equiv(inner_Y, X)):
                    return REJECT(f"Cov(X,Y,{N}) ≈ Mean(X*Y,{M}) under "
                                  f"zero-mean stationary; library has F{f.id}")
    return PASS
```

```markdown
## L10. Cov(X, Y, N) ≈ Mean(X*Y, N) under zero-mean stationarity

csi1000 daily 上, 任意 zero-mean stationary 字段对 (X, Y) 的 Cov 与 Mean
of product 数学近似等价, cross-section ranking 同构 ≥ 0.92.

zero-mean 字段集 (实证): daily return / overnight return / intraday return
及其 Delta/Diff form. **非 zero-mean** 字段集 ($turnover_rate, $amount,
$volume, $pe_ratio, $pb_ratio, $high-$low range etc.) 不适用此律.

设计阶段: 候选含 `Cov(zero_mean_return_A, zero_mean_return_B, N)` 时, 必须
先检查库内是否已 admit `Mean(Mul(A, B), M)` (M ∈ [N-20, N+20]). 是 →
near_dup 必然 fail, 候选 default-skip 不进 Phase 2.

**实证**: b087/C005 `Cov(overnight, intraday, 20)` × amount_120 cross-section
corr=0.927@F023 (F023 = Mean(Mul(overnight, intraday), 20)).
```
