# calibration/002 · 升格 "raw 字段 higher-moment regime sensitivity" 为 Phase 1 generator pre-block

## 证据

**3 大 family 独立证伪 + 5 候选 retro affect**：

| Batch | C | LHS | Outcome |
|-------|---|-----|---------|
| b052 | C001 | `Std($pe_ratio, 20)` | sign_flip train -0.003 → val +0.016 + mono IS=-0.80→OOS=1.00 |
| b052 | C003 | `Std($pb_ratio*$turnover_rate, 60)` | sign_flip train -0.005 → val +0.013 |
| b053 | C001 | `Std((close-open)/(high-low), 20)` | borderline reserve（同律但 mono 未翻——signed body-pos rate 正常化部分缓解，仍命中 alpha_surv=0.37 弱） |
| b054 | C002 | `Std(residual_ret, 20)` | mono_sign_flip(-0.80→+0.70) |
| b054 | C003 | `Sum(residual_ret, 5)` | sign_flip(-0.016→+0.011) + oos_decay=-0.644 |

**机制**：raw 基本面/intraday/residual 字段的二阶矩在 csi1000 train (2015-2021 低利率成长期) → validation (2022-2023 利率上行价值回归) regime 切换中**几何反向**，不是数据噪声而是 regime-dependent factor。

**对照（successful precedent 不命中此律）**：
- F019 LHS = `Std(body_ratio, 20)` — body_ratio 是 scale-free 比率（不是 raw level），不在 block 范围
- F020 LHS = `Std(gap_ret, 20)` — gap_ret 是 raw 但**短窗 + cross-session 边界**，admit (alpha_surv=0.40 + mono=-1.0/-1.0 + 9/9yr)

→ block 范围必须**精确到** raw fundamental level (PE/PB/PS) + raw intraday price level (close, open, high, low 直接 Std) + residual_ret 三类 atom。**scale-free ratio (body_ratio, gap_ret/(H-L), etc.) 不 block**。

## 实现建议

**两层实现**：

1. **Phase 1 generator layer (pre-block, 软阻断)**：
   ```python
   REGIME_SENSITIVE_LHS_PATTERNS = [
       r"Std\(\$(pe|pb|ps|market_cap)_ratio",          # raw fundamental higher-moment
       r"Var\(\$(pe|pb|ps)_ratio",
       r"Std\(\$(close|open|high|low)\)",              # raw intraday price level Std
       r"Std\(residual",                               # residual higher-moment
       r"(Sum|Cumsum)\(residual",                      # residual cumsum
   ]
   # If LHS matches → reject at design checkpoint with reason "regime_sensitive_atom"
   ```

2. **CP01 hard_gates.regime_sensitive_higher_moment_atom (硬闸)**：作为 generator 漏网 fallback——manifest 内若 LHS 命中 pattern 直接 hard_gate fail，不消耗 IC 计算。

**注意**：本提案不放宽 `mono_flip_min_magnitude=0.5`（已在 b052 C001 + b054 C002 触发并正确 reject）；本提案是**前置拦截避免浪费 slot**，让 LLM 的 6 候选 budget 专注真正可能 admit 的设计。
