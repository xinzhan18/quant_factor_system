# calibration/004 · Codify `incr_ic_min_when_corr_borderline = 0.015` 准则

## 证据

7 个 rank-diff 候选在 max_corr ∈ [0.50, 0.74] borderline 区间的 incr_ic vs verdict 关系：

| Batch | C | max_corr | incr_ic | verdict | 满足 0.015? |
|-------|---|----------|---------|---------|------------|
| **b047** | C001 | 0.734@F015 | **0.023** | **admit** | ✓ |
| b048 | C006 | 0.722@F010 | 0.021 | reserve | ✓ (但 LHS anchor 共享) |
| b049 | C004 | 0.725@F010 | 0.004 | reject | ✗ |
| b050 | C001 | 0.50@F017 | 0.013 | reserve | ✗ (差 0.002) |
| b051 | C001 | 0.55@F018 | 0.008 | reserve | ✗ |
| b052 | C002 | 0.40@F020 | 0.006 | reject | ✗ |
| b053 | C001 | 0.694@F020 | 0.0096 | reserve | ✗ |

**模式**：
- max_corr ∈ [0.50, 0.70] borderline 区间 + incr_ic ≥ 0.015 → admit (b047 C001 唯一例)
- max_corr ∈ [0.50, 0.70] + incr_ic ∈ [0.008, 0.013] → reserve（4 例）
- max_corr ∈ [0.50, 0.70] + incr_ic < 0.008 → reject（2 例）

**机制**: 库内 cluster correlation 0.5-0.7 时, 候选与已有 admit 共享 50-70% rank-order。要让该候选真有 admission value, 它独立增量信息必须 ≥ 默认 ic_oos 阈值 (0.008) 的 ~2× = 0.015。低于此值, 入库即"近似复制 + 噪声"。

**当前规则隐式**: judge subagent 个别决策一致 (4 reserve / 2 reject 全部 incr<0.015), 但**没写在 config.yaml 里**——LLM 设计阶段不知道该 die zone, 反复设计 incr_ic 0.008-0.013 区间的"接近过线"候选 → 浪费 6 个候选 budget。

## 实现建议

```yaml
thresholds:
  incremental_ic:
    min_global: 0.003                  # CP05 既有
    min_when_corr_borderline: 0.015    # NEW: triggers when 0.30 ≤ max_lib_corr ≤ 0.70
    corr_borderline_lower: 0.30
    corr_borderline_upper: 0.70
```

CP05 logic:
```python
if max_corr_high > max_lib_corr_low:                    # > 0.30
    if max_corr_high > max_lib_corr_high:              # > 0.70 hard cluster
        verdict = reject_redundancy
    elif incremental_ic < min_when_corr_borderline:    # < 0.015 in borderline
        cp05_grade = poor (red)                         # forces reserve at best
    else:
        cp05_grade = pass
```

## 风险与限制

- **不会误杀**: b047 C001 这个 admit precedent 严格满足 (incr=0.023 > 0.015), 准则 retroactively 不影响。
- **教育收益 > strict 收益**: 主要价值是让 LLM Phase 1 设计阶段提前 self-prune 0.008-0.013 incr_ic die zone 候选, 而非更严苛 reject。MT 预算节省 ≈ 每批 1-2 候选 slot。
