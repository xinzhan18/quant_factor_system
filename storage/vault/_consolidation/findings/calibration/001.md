# calibration/001 · Codify rank-diff geometry alpha_surv floor at 0.30

## 证据

`config.yaml.thresholds.alpha_surv_min` 当前有 4 档（default 0.40 / barra_residual 1.00 / amount_volatility 0.25 / value_liquidity 0.30），但**rank-diff geometry family**（`Sub(CsRank(...), CsRank(...))`）跨方向的实际门槛 informally 是 0.30 — b057 judge.md 直接写 "alpha_surv=0.157 << 0.30 rank-diff floor"，但代码无此 key，所有 rank-diff 候选 fallback 到 default 0.40。

**机理**：rank-diff transformation 通过 CsRank 作 ordinal 映射，broadcasting 损失 magnitude 信息 → Barra OLS residual 占比天然偏低。F018/F019/F020/F021/F022/F023 这些 admit 的 rank-diff factor，alpha_surv 历史范围都在 0.30-0.55 区间。default=0.40 把许多结构上"rank-diff 干净"的候选钉在 borderline，造成 reserve 积压（本次 packet 4 个 reserve 都精确卡在 0.16-0.31 区间）。

**Retro 影响**：4 个 reserve 候选 alpha_surv<0.40 但 ≥0.157：
- b056/C001 (0.24): mono_oos=+1.0 完美 + incr_ic=+0.0085 库增值 + cum_mdd=-4.06 极浅 + 9 年同号 — alpha-side 6 项健康指标全过
- b057/C005 (0.157): mono=0.9 + cum_mdd=-2.18 整库罕见 + ic_by_year 单调强化 — rank-order 极优
- b058/C001 (0.31): ic_oos=0.055 + ICIR=0.40 + ls_t=3.73 三 strong + 9/9 年逐年加强
- b058/C005 (0.26): mono=0.9/0.9 + ls_t=1.91 + incr_ic=+0.011

调整后这 4 个 reserve 中至少 2 个（b057/C005、b058/C005）会清晰落入 admit 区（其余仍可能因 cluster co-resonance 边际）。

## 实现建议

```yaml
thresholds:
  alpha_surv_min:
    default: 0.40
    barra_residual_alpha: 1.00
    amount_volatility_signal: 0.25
    value_liquidity_interaction: 0.30
    rank_diff_geometry: 0.30   # NEW — codify b057 judge.md 引用的 informal floor
```

需要相应在 `src/research/checkpoints/` 里 dispatch 时识别 LHS pattern `Sub(CsRank,CsRank)` → 选 `rank_diff_geometry` key。
