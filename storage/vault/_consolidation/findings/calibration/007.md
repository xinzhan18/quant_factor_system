# calibration/007 · Generator hard-block: Corr/Cov cross-field start_index broadcast crash 守门

## 证据

### batch_079 实证 (b079 主要 finding)

batch_079 设计阶段意图覆盖 PIT valuation × liquidity × num_trades 全 frontier
(测 `Corr($volume, $pcf_ratio_total_ttm, 60)` 等), 但 5 候选在 Phase 2
compute 阶段全部 broadcast crash (~80% universe shape mismatch). 重设计后
退路 OHLCV-only Corr (C003-C006), 但子族 ic_oos 0.004-0.006 sub-threshold +
120d collapse — 假设无生路.

**机理 (b079 P019 升格)**: Qlib 二进制 `[start_index:f32][data:f32×N]`
格式中, PIT valuation 字段 / TTM ratio 字段 / $turnover_rate 字段与核心
OHLCV ($close/$open/$high/$low/$volume/$amount/$num_trades) **start_index
不一致** (RiceQuant 同步时 valuation/turnover 数据从 sec 元年 ≠ price
数据起始点). 当 `Corr(safe_field, broken_field, N)` 在多股票 universe
评估时, 内部 `series_left.rolling.std()` 与 `series_right.rolling.std()`
shape 不匹配 → `np.isclose` broadcast crash, **整批 compute 终止**.

### batch_075 同源证据

batch_075 C005 `Cov($amount, $pcf_ratio_total_ttm, 120)` hard_gate
sign_flip + ic_oos_too_low (|0.0012|<0.008). lessons L 段 "TTM × TTM DSL
不容错" 律扩展至 Cov(daily, TTM_sparse, long_window) 形式. C005 是 b079
crash 模式的轻量复现 (coverage=0.90 vs 同批 ≥0.999) — 长窗口 + TTM
sparse RHS + Cov 不容错 NaN → 信号塌缩.

## 实现建议

### Phase 1 generator AST check

1. **AST visitor 扫描**: phase1 freeze 阶段对所有候选 expression AST
   walk, 检测 `Corr(A, B, N)` / `Cov(A, B, N)` 节点
2. **字段对照**: 提取 A, B 的 `$<field>` 名, 与 `CORR_SAFE_FIELDS`
   set 对比
3. **不在 safe set → reject 候选**: error message
   `"Corr/Cov requires both fields in safe set; got {A_unsafe} or {B_unsafe}"`
4. **白名单可扩展**: 数据 loader 修复 unify start_index 后, safe set
   从 7 字段扩展到 ~30+ 字段 (TTM/PIT 全可用)

### lessons.md 升格

`# Data Contract Section` 加入:

```
- L9. Corr/Cov broadcast safety: $turnover_rate / 全部 PIT valuation
  ($pe_ratio, $pb_ratio, $ps_ratio, $pcf_ratio) / 全部 TTM ratio 与 OHLCV
  start_index 不齐. `Corr(safe, unsafe, N)` 在多股票 universe broadcast
  crash. 设计阶段 default-skip 跨 family Corr/Cov, 直到数据 loader 修复.
```

### config.yaml.thresholds.phase1 加入

```yaml
generator:
  corr_cov_field_safety:
    enforce: true
    safe_fields: [$close, $open, $high, $low, $volume, $amount, $num_trades]
```

## retro 影响

- batch_079/C001-C006: 5/6 设计候选会因此被提前 reject (仅 retain OHLCV-only
  C003/C004/C005/C006 OHLCV cross-pair 子集), 节省 ~3 candidate slot
- batch_075/C005 (Cov(daily, TTM, 120d)): 提前 reject 节省 1 candidate slot
- **预估 cumulative reserve cost saving**: 未来每批含 cross-family Corr/Cov
  设计意图时 1-2 候选 → 全年估计 8-12 候选 wasted slot

## 决议

**enforce phase1 generator hard-block** — 阈值校准是判据 enrichment, 不是
阈值数字调整. 这是数据契约级守门, 与 calibration/003 (ls_t IS-OOS 崩塌
hard_gate) 同性质 (新加 hard_gate 要件 vs 调阈值数字).
