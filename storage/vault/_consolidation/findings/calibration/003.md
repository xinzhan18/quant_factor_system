# calibration/003 · 加 ls_t IS-OOS 崩塌 hard_gate（第五要件）

## 证据

**b052 C006**: `Std(Mean($pb_ratio, 5), 20)` compound moment LHS — ls_t_is=**+12.18** → ls_t_oos=**-0.13**，IS 期完美 OOS 完全消失。当前 reject 理由是 ic_oos=0.0077 < 0.008 hard_gate（差 0.0003）—— **极度 fragile**，如果该 candidate ic_oos=0.0085 即可越 hard_gate 进 CP，浪费下游 5 个 checkpoint 的算力 + 候选会进 reserve 池。

**升格依据**：跨 family 3 次确认（b052 C001 PE Std + b053 C001 signed body-pos Std + b054 C002/C003 残差 Std）"higher-moment LHS regime sensitivity 律"。compound moment（嵌套 smooth-then-std）是这条律的 IS over-fit 极端形态——judge.md 直言 "史上最戏剧 IS-OOS 崩塌之一"。

**当前 hard_gates 缺口**：
- `min_oos_decay = 0.20` 控的是 IC 层 OOS/IS ratio，不抓 ls_t 层
- `mono_flip_min_magnitude = 0.5` 只看 mono，不看 ls_t
- `min_ic_oos = 0.008` 是绝对值阈值，不抓"IS 极强 vs OOS 趋零"的相对崩塌

**Retro 影响**：
- b052/C006: 当前 reject by ic_oos hard_gate（差 0.0003），加新 gate 后由 `|ls_t_oos|/|ls_t_is| = 0.011 < 0.10` 直接 reject — robustness 大幅提升；verdict 不变但路径更稳健
- b055/C001 + b055/C006 + b056/C002 都 IS→OOS 翻号但 magnitude 没那么极端 (ratio 0.16/0.30/0.64) — 不会被新 gate 多杀
- 触发条件"ratio<0.10 且 sign 反转"实际仅 b052/C006 命中——精准定向，不伤其他候选

实际翻转 verdict = 0（C006 当前已 reject），但 hard_gate 化让 archetype 识别更稳定。**严重性 medium 因仅 1 retro precision-target，但律已 3-family 确认**。
