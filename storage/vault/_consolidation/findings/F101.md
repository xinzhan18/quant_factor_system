## Reserve 证据

- batch_045 C001 **Kurt60 reserve**——shape 路径首次 partial breakthrough，mono_is=0.90 + cum_mdd=-1.42 + incr_ic=0.015，alpha_surv=0.17 阻 admit。**`range_structure` 方向 11 candidates 含 Skew/Kurt/Quantile，仅 Kurt 一个 partial 成功**。
- batch_045 C002/C003/C004 的 Quantile-based (Q90/Q90-Med/Skew120) 全 reject——但 reject 理由是 "magnitude 被 vol_20d 吸收" / "mono_is < 0.6"，**不是 Quantile 算子本身的问题**。Quantile 作为 cross-section nonlinear transform 仍未真正测试。
- batch_054 (residual_alpha) 的 C004 (lag-1 autocorr) / C006 (directional efficiency) 是 IC < 0.01 的失败——但这些是 **path-coherence statistic on residual**，不是 DSL Slope/Corr 在原始 OHLCV 上的应用。

## 建议探索

按"DSL 已支持 / 信号几何独立 / 与库相关性预期低"三条件排序：

1. **`Corr($close, $amount, N)` 系列** — batch_047 方向反思已显式提出"未测"。Corr 是 cross-field path covariance，与 Mean/Std 几何独立。同 atom 的 Corr-LHS rank-diff（如 `Sub(CsRank(Corr($close,$amount,20)), CsRank(Mean($amount,20)))`）应能脱 RHS 共振饱和律。

2. **`Slope($close, N)` / `Slope($amount, N)`** — 时序回归系数。与 Mean(return, N) 几何上不等价（Slope 对 outlier 不同）。可在 momentum / acceleration 方向测试。

3. **`TsRank(X, N)`** — 时间序列 rank-transform，与 CsRank 是正交几何（CsRank 在 cross-section, TsRank 在 time-series）。可作为 LHS atom 的"自归一化"层，避免 raw level 被 vol_20d 吸收（b052 教训"基本面 raw level 被 Barra 吞噬"可能用 TsRank 自归一化破解）。

4. **Kurt 长窗变体 (Kurt90 / Kurt120)** — b045 方向反思已显式标"未测"。Kurt60 partial 成功 + Skew 两轮失败 → Kurt 是 shape 路径唯一存活算子，长窗未尝试。

5. **Resi(A, B, N)** — DSL 时序回归残差。与 Python Barra residual (F004/F005) 不同：DSL Resi 是 per-stock time-series residualization, Python Barra 是 cross-section residualization。两个独立维度，DSL Resi 完全未试。

## severity 判据

**high**：(1) 6 个 DSL-supported 时序算子族 0 admit 是极大结构性空白；(2) 已有 reserve 证据 (Kurt60) 证明该家族至少 partial productive；(3) batch_047 方向反思已主动列 Corr 为 next-step 但未执行；(4) 时序算子族与已 admit 的 cross-section rank-diff 几何独立，几乎不可能与库 corr 高 → 库空间扩张高效路径。
