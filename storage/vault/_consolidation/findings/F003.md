# F003 · Higher-moment LHS 跨方向 regime sign-flip 律（fundamental / intraday / residual 三家族）

## Pattern

higher-moment 算子 (Std, Var, cumsum, joint vol of product) 作用在某些 LHS 字段时，cross-section IC 在
train (2018–2020 低利率成长股周期) 与 validation (2021–2023 利率上行价值回归) 之间**系统性符号翻转**——
不是噪声，是 regime-dependent 机制。三个独立 family 在连续三批 (b052/b053/b054) 各自命中一次：

- **fundamental family** (b052 C001 PE Std + C003 PB×turnover joint vol 双例)：raw 基本面字段的 second-order moment 对样本分布尾部敏感，regime 切换让"高 PE-vol" 股票 cross-section 的 forward return 符号翻转
- **intraday OHLC family** (b053 C001 signed body-pos Std + C004/C006 true_range/signed-ret Std)：intraday signed signal 的 higher-moment 在 vol regime 下被 vol_20d 主导但符号不稳
- **residual family** (b054 C002 |residual|_std + C003 residual_cumsum)：cross-sectional Barra residual 的 rolling Std/cumsum 在 regime 转折时翻号

关键区别于 F019/F020 admit (OHLC body_ratio Std + gap_ret Std)：F019/F020 LHS 是 OHLC structural (
scale-free ratio)，20d 窗口内单层 moment——满足 F003 lesson_text 列出的"安全 higher-moment"三条件。
