# F104 · 字段空白：`$pe_ratio / $ps_ratio` 在 admitted 0 出现 / `$market_cap / $circ_market_cap` 0 出现 / `$vwap` forbidden — 仅 $pb_ratio 进入库（F002 单点）

## Observation

| field | admit 出现次数 | 备注 |
|---|---|---|
| $close | ~10 | 主力价格 |
| $open | 8 | overnight/intraday 必需 |

batch_052 (value_liquidity_interaction) 已揭示"基本面字段 raw level Std/Var 在 rank-diff 几何中 regime sign_flip"——这是一条**只针对 higher-moment** 的失败教训，不是 raw level 本身的失败。但 raw $pe / $ps level 进入 rank-diff 的**单 atom CsRank 形态**（如 `Sub(CsRank($pe_ratio), CsRank(Mean(amount,20)))`）尚未独立测试——直接用 raw level 作 LHS 的 rank-diff 候选数 < 3。

更广义：**$market_cap / $circ_market_cap 在 size-adjusted 信号上 0 测试**——A 股 small-cap effect 是经典 alpha，但库内通过 Barra style basis 被吞噬而非 native admit。

## Reserve 证据

- 无直接 PE/PS/market_cap reserve（候选量本身就少 → 没有 reserve sample）
- batch_052 reflection 显式标"完全脱离 PB/PE/PS × amount/turnover 几何"是未试空间——本 finding 对应该建议
- batch_034 (mining constraints feedback) 历史指明"no market-cap proxy factors"——但该限制是针对**直接 size proxy** (如 `Inv($market_cap)`)，不是对 size-conditional / size-orthogonal 的限制

## 建议探索

按"避开已 disproven 死区 + 字段几何独立"原则：

1. **`$pe_ratio` 单 atom rank-diff (避开 higher-moment)** —
   - `Sub(CsRank(Mean($pe_ratio, 60)), CsRank(Mean(amount, 60)))` — value × liquidity raw rank-diff 长窗
   - `Sub(CsRank($pe_ratio), CsRank(Mean(turnover_rate, 20)))` — instant value × short-term liquidity
   - **不**做 Std($pe) / Var($pe) (b052 已 disproven)

2. **`$ps_ratio` 同形态** — 与 PE 平行，但 PS 在中国 A 股反映 sales-quality 而非 earnings-quality，可能与 PE rank 几何独立

3. **PE / PB cross-ratio (相对估值)** — `Div($pe_ratio, $pb_ratio)`. 与 b052 C002 PE/turnover ratio 不同：PE/PB 是同 family 内部相对估值, 应避开 amount/turnover cluster anchor

4. **size-conditional 信号** —
   - `IfElse(Lt(CsRank($circ_market_cap), 0.3), CsRank(Std(body_ratio, 20)), 0)` — small-cap 子样本 OHLC higher-moment（与 finding F100 IfElse 建议合并）
   - 注意：不是直接 admit `Inv(market_cap)` (违反 mining constraint)，而是用 size 做条件 gate

5. **size × value joint rank** — `Mul(CsRank($pb_ratio), CsRank($circ_market_cap))` 或 `Sub(CsRank(Div($pb_ratio, $circ_market_cap)), CsRank(amount))` 等。利用 size + value 已知双因子结构。
