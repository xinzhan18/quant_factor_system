# F008 · Python residual + rolling 算子 csi1000 系统性 coverage<0.80 + REQUIRED_FIELDS 契约缺口

## Pattern

Python factor 路径在 csi1000 上有两个独立的数据契约层结构性边界，跨 3 方向 12+ 候选独立确认，是
当前系统级**最稳定的 hard_gate fail 模式**:

**(A) Python residual + rolling 系统性 coverage ≈ 0.71**:
- Pattern: 任何 Barra residual + 后续 rolling Std/Sum/EMA/Mean → coverage 0.685–0.725 范围 < 0.80 hard_gate
- 跨方向独立确认 3 次: amount_volatility b033 (5/5) / value_liquidity b034 (5/5) / barra_residual b054 (5/5)
- 关键洞察 (b054): F004 admit 时 coverage=0.999 (无 rolling) vs 本批 5 候选都 ~0.71 (有 rolling) → coverage
  暴跌 28pp 是 **rolling 算子+residual 复合**导致，与信号设计无关
- 信号本身常常健康 (b034 C004 alpha_surv=1.09 / b034 C005 alpha_surv=1.20 / b054 C005 alpha_surv=1.57 +
  style_r²=0.024) 仅 coverage gate KO

**(B) Python factor REQUIRED_FIELDS loader 缺口** (T003 二次跨方向复现):
- Pattern: data_bridge loader 默认列 (`$amount, $market_cap, $close, $volume, $open, $high, $low`)
  不包含 `$turnover_rate`，Python factor 声明 REQUIRED_FIELDS=["$close","$turnover_rate"] 触发
  `compute_error: market_df missing ['$turnover_rate']`
- 跨 batch_015 (missing $high/$low) → batch_054 (missing $turnover_rate) 9 批之后跨 direction 第二次相同失败
- 系统盲区: loader 不响应 candidate-declared REQUIRED_FIELDS, Phase 1 freeze 阶段也不 validate

两律影响: **方向 saturated 到 dead 的 false positive**——多个方向 (amount_volatility / value_liquidity /
barra_residual_alpha) 在 Python 复活路径上被这两个契约缺口提前关闭，元教训交付但实际 alpha 是否存在
未充分检验 (信号 magnitude 健康但 coverage KO)。
