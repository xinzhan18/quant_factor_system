# pattern_analyst/032 · rank-diff axis 跨域适用律精化 (5 batch 跨 4 方向实证)

## Pattern

rank-diff form `Sub(TsRank(X, N_long), TsRank(X, N_short))` 在 b091 amount/num_trades 域首次实证为真 escape 后, 跨 3 个 new direction 应用全部失败 — 但失败机制不同, 共同指向"rank-diff escape 域 ≠ 非 close-position 域"的关键反直觉. 真正决定 escape vs fail 的是 **LHS 字段族的 anchor 引力盆地密度** 与 **cross-section noise dispersion**. b091 amount/num_trades 域是"低 anchor 密度 + 高 noise dispersion" sweet spot; close-position / overnight / rate-form / raw atom / 多阶差全是"高 anchor 密度 + 低 noise dispersion" failure 域.

## 升格依据

5 batch 独立 + 跨 4 方向 + 15+ 候选 + 6 子机制 (close-position absorb / overnight anchor cancel / rate-form 共线 / raw atom / 多阶差 / dim-less ratio escape) + 1 PASS 域反例对照 (amount/num_trades) + 机制可解释 (anchor 引力盆地密度 + cross-section noise dispersion 决定 escape 可能性) + 实操可执行 (Phase 1 design-time 自检 LHS field family saturation). 满足 high severity + lessons 升格双门槛.

机理细化: rank-diff form 本质是 "双窗口 self-cancellation" — 把单 TsRank 的 cross-section ordering 拆解为 long-window vs short-window 时间尺度差. 在 anchor 密度低的 noisy field family (amount/num_trades), self-cancellation 留下 regime transition signal; 在 anchor 密度高的 saturated family, self-cancellation 把 regime signal 也一并 cancel.
