# pattern_analyst/018 · Cap-denominator 隐藏 vol_20d 嵌入路径 (frontier 部分失效)

## Pattern

`f(microstructure, $market_cap)` / `f(microstructure, $circ_market_cap)` /
`f(quality, Mean($amount, N))` 形态即使外层用 P008 frontier 路径 (TsRank≥
60d on ratio fields) 仍 vol_20d_exp 显著高于 OHLCV-only 同形候选 50%+ →
frontier 真生效部分失效。机理: cap-类字段 (size proxy) cross-section 上
与 vol_20d 共线; 用作分母 → 把 numerator 拉入 size × vol_20d 联合 basis;
finding/007 (TTM-quality / daily-aggregate-liquidity denominator) 是同律的
fundamental 端实证, 本 finding 是 microstructure 端实证 (P008 frontier 路径
内部的 cap-denominator 隐藏失效)。

## 证据链

- [[batches/batch_073|batch_073]] **C005** TsRank(turnover/market_cap, 60):
  vol_20d_exp=**17.4** + incr_ic=-0.036 (frontier 部分失效, cap 嵌入)
- [[batches/batch_074|batch_074]] **C004** TsRank(num_trades/circ_market_cap,
  60): vol_20d_exp=**19.1** + style_r²=0.150 borderline + sign decay +
  incr_ic=**-0.038** (重演 b073 C005, P016 升格)
- [[batches/batch_068|batch_068]] **C001** ROE / Mean(amount, 20):
  vol_20d_exp=**23.4** 整库顶级 (daily-aggregate liquidity denominator =
  vol_20d 隐性载体, finding/007 已 high-severity 升格)
- 对照: F024 (num_trades/volume) microstructure-only ratio: vol_20d_exp=
  12.6 (frontier 真生效)
