# pattern_analyst/007 · Daily-aggregate liquidity denominator 隐藏 vol_20d 路径律（fundamental TTM 跨族扩展）

## Pattern

在 P004 vol_20d 结构性吸收律此前 8 direction 复现基础上，b068 fundamental_quality_carry **first-batch all-reject** 揭露了一条**反直觉的 P004 隐藏迁移路径**：当候选 numerator 是从未触及的 TTM quality 字段族（ROE/ROA/ROIC/gross_margin/operating_margin/growth_ratio TTM）时，在直觉上"几何应与 OHLCV 完全独立"——但若 denominator 是 daily-aggregate liquidity（`Mean($amount, N)` / `Mean($turnover_rate, N)`），则 ratio 形式 **仍被 vol_20d 全幅吸收**。

机理：daily-aggregate liquidity 在 csi1000 cross-section 上 monotone-equivalent 到 vol_20d（小盘高波动股长期 cross-section 高 amount + 高 turnover），denominator 把 numerator 的几何位置 **拉入 vol_20d basis**，无视 numerator 字段族独立性。

**单批 5/5 PASS-hg 候选 dominant_style=vol_20d 三立完整**，vol_20d_exposure 整库历史最高（C005=31.1，C001=23.4），asr=0.12-0.30 catastrophic。

**对照组 F002 (PB/amount) 之所以 admit**：PB 自带 cross-section value Barra basis 抗衡 vol_20d；TTM quality（ROE/margins/growth/leverage）**没有同等 Barra basis**——它们是 single-stock fundamental ratio，cross-section 上无独立 risk factor 锚定。这把"TTM 与 OHLCV 几何独立"的 cockpit 假设**精细化为**："TTM × OHLCV ratio 仅当 numerator 自带 Barra value basis 时可绕开 vol_20d"。
