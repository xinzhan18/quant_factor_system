# pattern_analyst/007 · Rank-preserving 变换零增量 + "Barra-clean ≠ library-clean" 跨方向律

## Pattern

两条系统级判别律: 

**(A) Rank-preserving 变换零增量律** (跨 batch_031 + batch_046 双独立证据 + 4 处 lessons 引用):
DSL 层任何 monotonic transformation 作用在已 admit 因子上 → cross-section rank order 完全保留 →
IC / monotonicity / ls_t 几何性质保持但 max_corr ≈ 1.000 必为 near_duplicate。这是设计层最容易被忽略
的 "无信息增量" 候选——表面上 expression 不同实际数学等价。

**(B) "Barra-clean ≠ library-clean" 律** (跨 4 方向独立确认): CP04 alpha_survival 高 (>0.7) 不蕴含 CP05
library independence (max_corr@library < 0.30 + incremental_ic > 0.010)。一个候选可以 Barra
正交但 library 内某 anchor factor 已占据该几何位置——典型表现: `alpha_surv ≥ 0.8` + `max_corr ≥ 0.45@F_anchor`
+ `incr_ic ≤ 0.005`。该现象在 microstructure (b031 C003) / value-liquidity (b052 C004) / residual
(b054 C005) / + 早期 batches 反复出现，是 saturated 方向 anchor factor 形成 "factor-anchored cluster"
(F002 升格条目) 的同一现象的 CP04 / CP05 视角。

两律在 judge / calibration 层的应用: 错杀侦测 (over-rejection check) 必须**同时**满足 (a) max_corr<0.30 +
(b) incr_ic>0.010 + (c) mono>0.8 + (d) sign_consistency=1.0 才 flag——单维度强 (如 alpha_surv=0.96) 不
触发 retroactive admit (b052 C004, b053 C001 双例已 calibration check 通过)。
