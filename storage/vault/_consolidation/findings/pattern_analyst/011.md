# pattern_analyst/011 · alpha_survival ≥ 0.40 与 OOS sign-stability 解耦

## Pattern

Python OLS residualize-then-rank 工艺在 csi1000 daily TTM quality 字段
族上 6/6 候选 alpha_surv 全部 ≥ 0.93 PASS 红线但 6/6 OOS sign_flip。
alpha_survival 是"对线性 Barra basis 的剥离度"的几何度量, 不预测"OOS
上 alpha sign 是否 alive"。两者在 csi1000 daily TTM quality 字段族上
**结构性解耦**——alpha_survival 高 ≠ alpha 真存在。
