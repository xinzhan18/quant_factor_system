# pattern_analyst/005 · "看似强 alpha 但库减值" 陷阱跨方向 ≥5 次复现

## Pattern

跨 4 方向 5+ 批独立复现的 reject signature——候选在 mono_oos / ls_t / cum_mdd 等"alpha-side health"指标上看似 admit 候选 (mono=±1.0 完美 + ls_t > 3 strong)，但 incremental_ic < 0 (库减值) + alpha_survival < 0.30 (Barra 衍生)。机理：候选的 alpha 完全可由 Barra style + 已入库因子线性组合复现，cross-section monotone rank-order 是"vol_20d / 已 admit 因子的 monotone 变换"假象。该签名稳定到可作为 Phase 3 设计期的 hard pre-block——任何 LHS-RHS 组合预测出该签名 → 直接 self-prune，不消耗 CP3-CP6 计算预算。

诊断要件细化：alpha_survival 比 style_r² 更敏感——b056 C006 是经典案例，style_r²=0.21 仅 borderline 但 alpha_survival=0.0725 极端 poor，揭示 alpha 几乎完全被 style + 已入库 cluster 占走。
