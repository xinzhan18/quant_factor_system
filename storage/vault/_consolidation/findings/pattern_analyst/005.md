# pattern_analyst/005 · A 股 10% 涨跌幅约束 + OHLC algebraic mirror 双律（OHLC 几何 cluster 律）

## Pattern

A 股 csi1000 daily-bar OHLC 字段在 cross-section 几何上受两个独立但叠加的结构性约束:

**约束(1) 10% 涨跌幅**: A 股 daily 涨跌幅硬上限 ±10%，使得 cross-section 上 `(H-L)/C`、`|gap|/range`、
`gap/Std(ret,20)` 等"日内幅度归一"变量与"跨夜 gap" 量纲共动——本质上 H、L、prev_close 三个 reference
point 都被 10% 涨跌幅夹紧，相互之间存在 affine-like 共变。这导致 vwap_proxy_signals 5/5 sub-path 全部
79–89% 与 F014 cluster (b042) / gap_acceptance_structure 分母变体 corr=0.964@F003 (b035 C005) /
intraday rank-diff RHS Amihud-window-family corr=-0.69~-0.73 (b053 C003/C005)。

**约束(2) OHLC algebraic mirror**: O/H/L/C 四字段在 daily-bar 内有数学约束 (L ≤ O,C ≤ H)，使得多个
派生 ratio 之间存在 algebraic identity:
- `(H-C)/(H-L) ≡ 1 - (C-L)/(H-L)` → upper_shadow vs lower_shadow corr = -1
- `(O+H+L+C)/4 ≈ close` (csi1000 上四字段集中度高) → arithmetic-mean deviation ≈ 0
- `signed_range = sign(close-open) × (H-L)` 与 `upper_shadow` corr = 0.544 (b018 C004)

两律叠加：rank-diff geometry 即便满足 F002 的 7 条约束，在 OHLC 派生 LHS 上仍可能因 algebraic identity
形成 anti-anchor cluster——b053 F020 anti-anchor (LHS atomic 同源 → max_corr=-0.694) 是双律共同作用产物。
