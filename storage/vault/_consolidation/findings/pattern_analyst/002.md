# pattern_analyst/002 · 三 family 共证 higher-moment LHS regime sign-flip

## Pattern

`Std / Var / cumsum` 类二阶聚合算子作用于 **raw level (非 scale-free)** atomic 时，在 train→validation regime 边界系统性翻号。三 family 独立证伪：
1. **Fundamental** (b052)：`Std($pe,20)` 与 `Std(PB×turnover,60)` 双 sign_flip
2. **Intraday signed** (b053)：`Std((H-L)/prev_close,20)` 与 `Std((C-O)/close,20)` 同律 (mono_oos=-0.3 失稳 + IS over-fit)
3. **Residual_ret** (b054)：`Std(residual,20)` mono_sign_flip + `Sum(residual,5)` cumsum sign_flip

机理：raw level 字段在不同 regime 下绝对量纲漂移 → 二阶矩 cross-sectional rank 翻转。**反证**：scale-free ratio 单层 (F019 body_ratio Std / F020 gap_ret Std) 不属此律——自身已嵌入 cross-sectional 量纲归一。**衍生律 (compound moment)**：嵌套 smooth-then-std (b052 C006 `Std(Mean(PB,5),20)`) 在 IS=12.18 vs OOS=-0.13 戏剧崩塌——单层 vs 嵌套行为完全相反。
