# pattern_analyst/002 · rank-diff geometry 通用范式律 + 7 条硬约束（5 family admit + 3 family disprove）

## Pattern

rank-diff 范式是当前系统级最重要的设计发现——`Sub(CsRank(LHS_atomic), CsRank(RHS_basis))` 在 6 个 admit
跨 5 family 独立兑现 (F015–F020)，从 batch_046 (microstructure) → batch_051 (gap) 形成"5+1 跨家族
tipping point"，触发 Phase 5 consolidation。但范式不是万能：后续 3 批 (b052 value-liq / b053 intraday /
b054 residual) 在新 family 完整投放后全部失败，揭示了 rank-diff 几何的**边界**——通过对比 admit / fail
两组对照，可提取 7 条硬约束 (见 suggested_lesson_text)。

核心机制：CsRank 把 ordinal 化 + Sub 强制对称，让两个 scale-free 信号的相对位置成为 alpha 载体；但
(a) 任一端被 vol_20d / size 主导，CsRank 不能剥离 LHS 字段层固化的 style exposure (b053 vol_20d=53.6 仍 KO)；
(b) RHS basis 类目随 admit 累积"消耗"，dead RHS endpoints 持续增长 (overnight_5 → turnover_5 → amount_20 →
body_ratio_20 → price_vol_20)；(c) saturated 方向的 anchor factor (F002, F012, F020) 形成
factor-anchored cluster，新候选无法绕开。
