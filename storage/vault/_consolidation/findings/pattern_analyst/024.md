# pattern_analyst/024 · F001 vol_20d 律 first-moment N-day 累积形式扩展实证

## Pattern

lessons.md "F001 vol_20d 结构性吸收律" (finding/001) 历史实证全在 second-moment
+ higher-moment + quantile 形态 (Std/Var/Skew/Kurt/Quantile/RealizedVol).
b088 + b080 实证扩展到 **first-moment signed × Vol N-day 累积形式** + **同字段
不同窗口的代数差** 也被 vol_20d 吞噬:

- **b088 PVT(20)/PVT(60)**: signed daily_ret × Vol Sum 双窗 alpha_surv 0.11/
  0.16 << 0.40 floor + dom=vol_20d
- **b088 Chaikin EMA-差**: signed close-position × Vol 的 EMA(N1)-EMA(N2)
  形式 alpha_surv 1.35/1.57 但被 close-position cluster F008/F026 capture
- **b080 C005 Sub_inside_CsRank 加速度**: 同字段不同窗口的 Sub(Mean_5, Mean_20)
  alpha_surv=0.143 critical + dom=vol_20d

机理: PVT = Sum(daily_ret × Vol, N), daily_ret 与 vol_20d basis 计算同源
(vol_20d 是 daily ret Std); Chaikin EMA-差 cross-section 仍 vol-magnitude
主成分 (高 vol 股 EMA 振幅大); 短-长 Mean 加速度同律. **任何换聚合形式都
不破 P004**.
