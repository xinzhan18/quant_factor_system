# pattern_analyst/023 · Cov(X,Y,N) ≈ Mean(X*Y,N) zero-mean stationary equivalence (P028)

## Pattern

csi1000 个股 daily-bar return-pair (overnight ret / intraday body / close-to-close)
在 N ≥ 20d 窗口下 Mean(X, N) ≈ 0 数学近似零均值 stationary, 故
`Cov(X, Y, N) = E[XY] - E[X]E[Y] ≈ E[XY] = Mean(X*Y, N)`.

**当库内已 admit `Mean(X*Y, M)` (近窗口 M ≈ N), 任何 Cov(X, Y, N) candidate
自动 cross-section near_dup**. b087 首例铁证: Cov(overnight, intraday, 20)
vs [[F023]] Mean(overnight*intraday, 20) cross-section corr=**0.927** hard_block.

机理: 二阶项 `E[X]E[Y] ≈ 0` (csi1000 |Mean(20d)| < 0.001 占 >95% 股票-日),
Cov 退化为 Mean of product. **关键**: 不需要严格零均值, 仅需窗口尺度上 Mean
≈ 0; 仅适用于 daily return 与 return-derived 字段 (overnight / intraday body /
gap), 不适用于 price/range/turnover level (有持续 cross-section level).

## 证据链

- [[batches/batch_087|batch_087]] **C005** `Sub(CsRank(Cov(Sub($open,Ref($close,1)),
  Sub($close,$open),20)), CsRank(Mean($amount,120)))`: cross-section corr
  **0.927@F023** → hard_gate near_dup. F023 expression 为
  `Sub(CsRank(Mean(Mul((O-prevC),(C-O)),20)), CsRank(Mean($amount,60)))`,
  数学层是 Cov(o,i,20) 的 zero-mean approx
- [[batches/batch_059|batch_059]] **F023 admit** `Mean((O-prevC)*(C-O),20)`:
  T011 magnitude-weighted product 短窗 admit 路径 — 即"Mean of product"端
  已 admit, 后续 "Cov" 端按本 finding 律自动撞死
- [[batches/batch_088|batch_088]] **C003/C004** PVT(20)/PVT(60) `Sum((C-prevC)/prevC × Vol, N)`:
  alpha_surv 0.11/0.16 vol_20d-absorbed — PVT 是 ret × Vol Sum,
  数学上与 Mean(ret × Vol, N) 同律 (Sum = N × Mean), 与 F008 Cov(ret, Vol, 20)
  在 cross-section 上同源 (Cov ≈ E[ret×Vol] when E[ret]≈0). PVT 失败的
  另一同律证据: `Cov(daily_ret, Vol, N) ≈ Mean(daily_ret × Vol, N)` →
  PVT (which is Sum) 与 F008 几何同源, 都被 vol_20d 吸收
