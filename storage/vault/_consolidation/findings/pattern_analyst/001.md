# pattern_analyst/001 · vol_20d 结构性吸收 2nd-moment 空间

## Pattern

csi1000 daily-bar 的 cross-section 几何被 Barra `vol_20d` 强烈主导。任何作用于 return / range / amount / turnover / OHLC ratio 的 **magnitude / ratio / power-mean / Std / quantile / IQR** transformation，最终在 cross-section rank 上都 monotone-equivalent 到 vol_20d——alpha_survival 典型落在 0.08-0.30 死区。本律是 ≥9 方向独立确认的系统级 Structural Constraint，不是某个方向的偶发现象。`return_distribution_signals` 是最早的标杆（Q90-Q10 ls_t=-2.28 但 alpha_surv=0.008 灾难），其后 5+ 方向反复复现。
