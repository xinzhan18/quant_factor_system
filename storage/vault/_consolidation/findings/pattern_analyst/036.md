# pattern_analyst/036 · rank-diff axis ls_t 上限律 + "cluster-breaking ↔ alpha-cancellation" trade-off (4 batch 跨 3 方向实证)

## Pattern

rank-diff form 在 b091 amount/num_trades family 首次 PASS (alpha_surv=0.862 + max_corr=0.18 + incr_ic=+0.008) 但 ls_t=-2.20 weak 后, 跨 3 batch (b094 / b095 / b096) 7 个候选沿 6 个独立 sub-axis (RHS window 伸缩 / 跨字段 RHS swap / raw atom / HP-2nd-order / outer smoothing / LHS field swap) 全部 ls_t ∈ [-2.03, -2.60] cluster, 无一突破 3.0 admit floor. **核心律**: ls_t 上限不是噪音或 design 问题, 而是 rank-diff form 的 cross-section dispersion 自然上限 — rank-diff 输出 cross-section 分布在 [-1,1] bounded 范围内, 内在限制 ls_tstat 量级.

b094 C002 vs C006 直接控制对照: rank-diff form 与 single TsRank 在同一 LHS product 上 ic_oos 几乎相同 (0.0067 vs 0.0068, 差 1.5%), 但 max_corr 差 0.59 (form 决定 anchor cluster). 这是 "form determines cluster geometry, not alpha strength" 的清晰证据 — rank-diff 是 anchor-escape 工艺, 不是 alpha-amplification 工艺.
