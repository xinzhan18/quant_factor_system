# pattern_analyst/017 · Cross-product Mul wrapper 系统性塌缩律 (跨 4 方向 5+ 次)

## Pattern

`Mul(admit_atom_A, admit_atom_B)` 或 `Mul(CsRank(A_admit), CsRank(B_admit))`
形式在 csi1000 daily-bar cross-section 上 **从不产生独立新维度**, 仅出现两
失败模式:
1. **塌缩到强势一端** (b077 C004 max_corr=0.70@F025, F024×F025 = F025 复制)
2. **sign_flip catastrophic + alpha_surv collapse** (b074 C006 alpha_surv=
   0.068; b080 C001 decay=-5.16 + sign_flip)

机理: Mul 改变 cross-section moment structure → Barra style basis 在新形
态上重新捕捉 + sign 由联合分布 quartile 决定 → regime drift 触发 sign 翻号。
与 Sub 不对称: Sub 抵消共有 basis, Mul 放大共有 basis (与 finding/004 rank-
diff 7 律 #1 配对解释为何 Sub 形式有 6 admit 而 Mul cross-product 普遍失败)。
