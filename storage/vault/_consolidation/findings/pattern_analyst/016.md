# pattern_analyst/016 · Library saturation 单调律 + minor-path revival 系统性失败

## Pattern

reserve 在原 batch 时 max_corr 阻断由 1-2 个因子卡, 25-30 batches 后由 3-5
个 admit 因子同时阻断 + family-internal "absorbing prototype" 形成 (e.g.
F024 trade-density / F025 OHLC shape composition / F018 sign-frequency
liquidity)。**任何 minor 复活路径 (rhs_change 同 family / mean_centering /
window_sweep / retro_post_floor) 都无法破 admit 后 saturation 阻断**。三
独立失败机制: (a) 仿射 no-op (rank 不变); (b) reserve alpha 在 25 batches
后衰减消失; (c) cross-family RHS 切换才能突破共线 — 同 family 仿射、量纲
微调、窗口微扫不构成新维度。
