# pattern_analyst/004 · rate/delta/ratio 形式跨 5+ 方向结构性失败律 + Meta-pattern 机械迁移风险

## Pattern

"变化率/加速度/比值" 形式在 csi1000 上是**跨方向的结构性死区**——不是某一方向的局部失败，而是系统级设计反模式。
5 个独立方向首批即 dead 或全体 reserve，覆盖所有主要 rate 变体：

- **fundamental rate** (b022): PE/PB/PS 20d 变化率 ls_t=-1.22 ~ -1.81，C002 r²=0.811 catastrophic (rate ≈ vol)
- **price return rate** (b029): 5d-20d spread ls_t=-0.81 / 5d/20d ratio mono_sign_flip IS=+0.70→OOS=-0.70
- **asymmetric momentum** (b028): up-only / down-only / abs(down)/up 三角度 3/3 hard_gate sign_flip
- **return distribution** (b016): Q90-Q10 "rate" 形式 ls_t=-2.28 看似强但 alpha_surv=0.008 ≡ vol_20d
- **liquidity acceleration** (b023/b032): 5d/60d amount / volume / turnover ratio 3 条 base 全部 negative signed incr_ic — 真信号但被 F001 吸收

**对照组明确**: F010 hhi_vol_20 **level** 形式 ls_t=7.50 整库记录 / F002 PB/amount **level** 可用 / F013
log(abnormal amount) 非线性幅度变换 (log 压缩不是 rate 形式) → rate vs level 对比**决定性地**证明是 rate
形式本身的 structural failure。

**延伸律 Meta-pattern 机械迁移风险** (连续 3 批验证):
- b037 trend_quality_gated: paper CSI 300 CleanTrend (Channel 3) 迁移到 csi1000 + gated 形式 → 6/6 IC_OOS
  负 (-0.025 ~ -0.033)，signal 完全翻为 reversal
- b038 log_value_liquidity: F013 log-compression meta-pattern 从 gap sign×body 迁移到 value × liquidity →
  6/6 IC_OOS 负，mono ≈ 0 或负，承载 overnight 反转簇而非 value
- b039 pv_covariance: Cov(.,.,N) 形态 (未在库中的 family) → 6/6 IC_OOS 负，归簇 F001/F009/F012 反转载体

三者共性：**跨方向结构相同 ≠ 跨方向语义相同**。log-compression 在 sign×body 工作因 sign 已规整二值；
gate 在 CSI 300 大盘工作因 large-cap momentum drift 存在；Cov 在美股 trend family 工作因 vol 正 feedback。
**csi1000 小盘反转簇**把所有"量×方向复合"形态都吸收为同一载体。
