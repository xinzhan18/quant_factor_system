# pattern_analyst/021 · In-batch denominator family 等价性自检 (P024 系统级)

## Pattern

仅分母不同的候选, 在常态下数学等价 (差异 1-2%), 是 in-batch near-duplicate
浪费 Phase 2 计算预算。b077 首例铁证: TsRank((H-L)/(C+O), 60) 与
TsRank((H-L)/midprice, 60) IC daily corr=**0.9996** — 同 sty_r² OVER 0.12
+ 同 alpha_surv 边缘 + 同 max_corr@F022 + 同 ic_by_year 9/9 NEG, 重选规则
reject 一。

机理: A 股 OHLC 在 10% 涨跌幅约束下, midprice = (H+L)/2 与 (C+O)/2 在常态
日数学近似 (差异由日内 trend strength 决定, 但被 |Δclose| < 10% 约束限幅);
finding/006 (algebraic mirror trap) 是同律的 4-field arithmetic mean 形式
扩展, 本 finding 是 ratio 分母维度的扩展。
