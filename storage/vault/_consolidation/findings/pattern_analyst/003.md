# pattern_analyst/003 · rate/delta/ratio + Meta-pattern 机械迁移双律

## Pattern

两个紧密耦合的跨方向失败律：

**(A) Rate / delta / ratio / sign-conditional 形式结构性失效**——跨 6+ 方向独立确认。csi1000 cross-section 上任何"变化率 / 加速度 / 比值 / 拆分聚合"形态——无论作用于 fundamental / return / liquidity / volume×direction——最终都归簇到 F001 amount_cv / F009 overnight_spread / F012 amihud 三个反转载体。Level 形式（F010 ls_t=7.50, F002 PB/amount level, F013 log gap）才是稳定信号源。

**(B) Meta-pattern 机械迁移失败**——log-compression / paper transfer / gate 增益等"上一批成功 trick"复用到新方向时，连续 3+ 批 0 admit。结构相同 ≠ 语义相同：底层 raw signal 在 csi1000 是否 alive 才是决定性因素，包装方式无法翻号。

机理：csi1000 小盘 universe 的反转簇是结构性的——量×方向复合形态都被吸收为同一载体；上一批 trick 之所以成功是因为底层 sign-twin 信号本身就 alive (F013 sign×body)，而新方向往往底层信号已 dead (PE rank 在 csi1000 不携 value alpha)，trick 救不了 dead signal。
