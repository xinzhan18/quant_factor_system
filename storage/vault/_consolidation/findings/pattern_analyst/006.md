# pattern_analyst/006 · 表面正交化失败族 (rank-preserving + algebraic mirror + field-换 + Python residual coverage)

## Pattern

四条紧密耦合的"表面正交化"失败子律——它们共同的特征是：候选设计者**意图**通过某种变换 (排名 / 标准化 / 字段替换 / Python 残差化) 来剥离 vol_20d 或 anchor factor 暴露，但变换在 cross-section rank 空间上要么保序、要么搬家、要么撞硬闸。四子律 9 方向交叉证伪：

**(a) Rank-preserving family 零贡献律**：CsRank / CsZscore / SignedPower / Sigmoid / Tanh / Softmax / Scale 在 cross-section 排名空间上保序——max_corr=1.000 双独立证伪 (b031 C004 CsZscore + b046 C005 SignedPower)。

**(b) DSL Div(factor, proxy) 不是真 orthogonalization**：Div-based "去暴露" 要么保序 (CsRank 后)、要么 style 搬家 (vol-residualize 把 vol_20d exposure 5.9→32.6, b031 C002)、要么撞量纲 (cross-field Div, b031 C006)。

**(c) "换 field ≠ 换维度"**：Barra basis (vol_20d / turnover_20d / str_1m) 在日频 DSL 层同时覆盖 $amount 与 $turnover_rate (b004 5/5 dom=vol_20d)；anchor cluster (F002 / F012 / F020 / F022) 把含同 atom 字段的几何排列全部锁死。

**(d) Python residual + rolling 系统性 coverage ≈ 0.71 边界**：跨 amount_volatility (b033) + value_liquidity (b034) + barra_residual (b054) 3 方向 12+ 候选独立确认——residual base 覆盖率 99% 但 rolling Std/Sum/EMA 后因 (i) 残差 ~1% NaN 传播 + (ii) 上市日异质性 + (iii) min_periods≥10 复合，coverage 暴跌 28pp 至 0.71-0.73 < 0.80 hard_gate。**工程出口未通畅**——多个信号本身极佳的候选 (b054 C005 alpha_surv=1.57 + style_r²=0.024) 纯 coverage 单闸 KO。

延伸：**OHLC algebraic mirror 二阶律**——10% 涨跌幅 + cross-section 共动让 OHLC 派生量在 affine 上互相吸收 (b035 C005 Std(ret,20) 分母 0.964@F003；b053 C002 OHLC4_mean ≈ close 4-field 退化 noise)。
