# pattern_analyst/026 · Paper transferability 失败模式三件套 (sign-flip + library overlap + 量级衰减)

## Pattern

csi300/csi500 weekly / SPX 大盘 paper-vetted 因子在 csi1000 daily 上典型呈现
**三种独立失败模式组合**:
(1) **sign-flip** (paper 多头 → csi1000 反号);
(2) **library overlap** (反号被库内 cluster capture);
(3) **量级衰减 ~2-8x** (weekly→daily + 小盘 transfer 双 ~50% 衰减).

paper round 1-2 admit 兑现率结构性分布: **3×2 robust 子集 ~50%** (b085 F027/
F028) vs **5×5 tail-sensitivity 子集 ~0%** (b086 全 reject), 与 paper 自身
警告 "monthly aggregation 抹平 high-frequency dynamics" 一致.

机理: paper 大盘机构市 cross-section drift 反向于 csi1000 散户小盘 micro
structure → sign-flip 必然; daily 频率信号 noise-bound + 库内 close-position
cluster (F006-F008/F018/F022-F028) 已占据 ~50% paper-vetted niche → 反向
有效仍 capture; paper 不做 FDR 校正 17/168 = 10.1% naive 期望含 ~50% false
positive 在 transfer 后无效.
