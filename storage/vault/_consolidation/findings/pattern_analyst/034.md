# pattern_analyst/034 · "库 clean ≠ tradable alpha" 反向警示律 (6 batch 跨 5 方向独立复现)

## Pattern

跨 6 个独立 batch + 5 个 direction 独立复现同一悖论: 候选 max_corr 在整库内极 clean (<0.10, 通常 <0.05), 但同时 ic_oos 接近或低于 hard_gate floor 0.008 + alpha 在 Q1-Q5 mono 上破坏 + ls_t 极弱. 该模式提示**形式独立性 (CP05 library-clean) 是 necessary 但 NOT sufficient**, 极低 max_corr 反而可能是"信号已被 cancel 至 cross-section noise floor"的信号. 与 F004 / F025 (max_corr<0.30 + 真 alpha) 历史 admit 反例形成强对比.

- [[batches/batch_059/judge|batch_059]] (overnight_intraday_split T013): 某候选 max_corr 极低 + sign 离散化未脱 F022 cluster (背景证据, b059 是首例预警)
- [[batches/batch_066/candidates/C002|b066 C002]] intraday_autocorr × pe_60: max_corr=**0.13 库内最 clean** + 9/9 年 7 positive 但 alpha_surv=**0.06 critical** (vol_20d=5.77 + book_to_price=0.62 + ep_ratio=1.22 共吞噬) — 第二例
- [[batches/batch_087/candidates/C006|b087 C006]] `num_trades×|Δret|/amount` TsRank-60: max_corr=**0.13 库最 clean** + sign_flip catastrophic + OOS dead — 第三例

- [[batches/batch_094/candidates/C005|b094 C005]] `Sub(TsRank(Cov(overnight,$volume,60),60), TsRank(Cov,20))` Cov + double TsRank: max_corr=**0.035@F007 库最 clean** + ic_oos=0.0006 essentially zero hard_gate fail — 第五例

**反例 (admit 真 max_corr<0.30)** 与本律对照:
- F004 (b012 admit) — max_corr=0.30 + ic_oos=0.024 + alpha_surv=1.41 + incr_ic=0.032 ✓ 真新几何
- F025 (b076 admit) — shadow_asymmetry_midpoint TsRank-60 max_corr<0.30 + alpha_surv > 1.0 + 真新几何

**对比**: admit 反例 max_corr<0.30 同时 ic_oos≥0.024 + alpha_surv≥1.0 + incr_ic≥0.015; warning 案例 max_corr<0.10 同时 ic_oos<0.008 + alpha_surv<0.30 / 接近零. 两者在 max_corr 单一维度上看相似, 但 (ic_oos, alpha_surv) 维度上分布完全不同.

## 升格依据

6 batch 独立 + 跨 5 方向 + 6 个 candidates 同律复现 + 与 F004/F025 admit 反例形成清晰边界 + 机制可解释 (max_corr 单维不充分, 必须 (ic_oos, alpha_surv, max_corr) 三维联立判断) + 实操可执行 (judge.md CP05 评分新增反向条目). 满足 medium severity + lessons 升格门槛.

severity=medium 是因为该律不是"硬律"而是"反向警示律" — admit 仍可能在 max_corr<0.10 区间存在 (历史 F004/F025), 但需要其他维度强信号验证; 单边低 max_corr 不构成 reserve fire 充分条件.
