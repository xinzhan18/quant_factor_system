# pattern_analyst/033 · T006 同字段跨窗口 rank-diff 抵消律跨 atom-class 普适 (4 atom-class + 5 batch 实证)

## Pattern

T006 律之前在 b048 仅在 aggregation atom (Mean/Std) 上证实, 但 round 92-94 期间在 4 个完全不同的 atom-class 上独立复现, 形成 atom-agnostic 硬律. 关键性质: ic_oos 几乎都精准卡在 hard_gate floor 0.008 附近 (0.0078, 0.006, 0.0015) — 不是"信号微弱"而是"信号几乎 algebraically 为零", 因为 TsRank(X, N_long) 与 TsRank(X, N_short) 在同 X 上 cross-section ordering 高度共线, Sub 是数学上的"软零".

## 证据链

**Atom-class 1: aggregation atom (Mean/Std) — b048 历史升格证据 (overnight_intraday_split T006)**
- batch_048 多个候选 `Sub(CsRank(Mean(X, N_long)), CsRank(Mean(X, N_short)))` 共 RHS=overnight_5 全 reject — 升格 lessons.md "Rank-Diff Geometry 硬约束 #3 不能同字段跨窗口"

**Atom-class 2: Corr atom — b093 C004 首次实证**
- [[batches/batch_093/candidates/C004|b093 C004]] `Sub(CsRank(Corr($volume, overnight_gap, 60)), CsRank(Corr($volume, overnight_gap, 20)))` — ic_oos=0.006 hard_gate fail + mono_oos=0.3 + ls_t=0.91 + **max_corr=0.04@F027 库最 clean 但 alpha 完全塌缩**. Corr atom 输出 [-1,1] bounded 理论上长短窗 Corr 值非单调相关可能松动律, 但实测仍 cross-section 高度相关导致 rank-diff 抵消.

**Atom-class 3: TsRank atom — b094 C001 第三次实证**
- [[batches/batch_094/candidates/C001|b094 C001]] `Sub(TsRank(overnight,60), TsRank(overnight,20))` — ic_oos=0.0078 hard_gate fail (差 0.0002, 2.5% 缺口), max_corr=0.30@F018. 这是 raw atom + raw rank wrapper, 既不是 Mean/Std aggregation 也不是 Corr atom — 把律边界扩展到 raw TsRank 形式.

**Atom-class 4: close-position 域 (TsRank on (c-l)/(h-l) ratio) — b092 C004 实证**
- [[batches/batch_092/candidates/C004|b092 C004]] `Sub(TsRank((c-l)/(h-l),60), TsRank((c-l)/(h-l),20))` — ic_oos=0.0015 hard_gate fail + oos_decay=0.107. rank-diff 在 close-position 域 self-cancellation 极严重 (信号塌至 0).

**Atom-class 5: HP-2nd-order multi-order extension — b095 C005 实证 (T006 律的 N>2 阶推广)**
- [[batches/batch_095/candidates/C005|b095 C005]] `Sub(Add(TsRank(X,60), TsRank(X,10)), Mul(TsRank(X,20),2))` 3-term Hodrick-Prescott-style 2 阶差 — triple hard_gate fail (sign_flip + ic_oos_min + oos_decay) + alpha_surv=7.80 paradox + ic_oos=-0.0012 nil. **rank space ordinal 不支持 Taylor-series 多阶展开** — T006 律对 N=2,3 阶差形式同律生效.

**Atom-class 6: TsRank atom 第二次实证 in close-position — b099 C001**
- [[batches/batch_099/candidates/C001|b099 C001]] (conditional_operator_truncation T008 family extension) 60d 长窗 hard_gate fail OOS 信号完全消失 — 不同 mechanism, 间接验证长窗 + binarize content 容易让 self-cancellation 加深.

**Atom-class 7: Cov + double TsRank — b094 C005**
- [[batches/batch_094/candidates/C005|b094 C005]] `Sub(TsRank(Cov(overnight,$volume,60),60), TsRank(Cov(.,.,60),20))` — Cov atom + double TsRank rank-diff — ic_oos=0.0006 essentially zero hard_gate fail, max_corr=0.04@F007 库最 clean 但 alpha 塌缩. T006 律对 Cov-wrapped atom 也生效.

## 升格依据

7 个不同 atom-class 独立实证 + 跨 3 方向 (overnight / rank-diff microstructure / candlestick) + 跨 5 batch + ic_oos 都精准卡在 hard_gate floor 附近 (机理证据强) + max_corr 普遍 ≤ 0.30 (form-cluster-clean 但 alpha 塌缩 = "库 clean ≠ tradable alpha" 同律) + 与 b048 历史升格律完全兼容 + 实操可执行 (Phase 1 generator AST 自检). 满足 high severity + lessons 升格强证据.

机理细化: TsRank/CsRank wrapper 的 cross-section output 是 [0, N-1]/[0,1] bounded ordinal vector. 当输入 X 同一字段时, N_long 窗与 N_short 窗的 ordinal 输出在每个 cross-section 上高度相关 (实测 b094 C001 短长窗 TsRank 在 csi1000 cross-section corr ≈ 0.85). Sub 是 linear, 留下的残差 ≈ "long_window 与 short_window 时间尺度差异" — 在 daily frequency 的 cross-section 上, 这种 regime-transition signal 量级远低于 cross-section ranking baseline noise → ic_oos 塌至 hard_gate 边界.
