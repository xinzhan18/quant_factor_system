# pattern_analyst/019 · Geometric absorbing-factor 律 + 高阶 composition 逃离路径

## Pattern

admit factor 在其几何家族内自动成为 absorbing prototype, 同 family 后续
frontier 续探在 cross-section 上 max_corr ≥0.55 @ 该 factor。**4+ admit
factor 跨 6+ direction 独立证实**:
- F024 trade-density count ratio (b073 admit → b074 三轴 ablation 全 hard_
  gate near_dup)
- F025 OHLC shape composition (b076 admit → b077 三层续探全 max_corr ≥0.58)
- F018 overnight sign-aggregation (b078 C006 加深耦合)
- F021 upper_shadow disp/range compress (b081 C001 数学同构)

**机理**: admit 因子在 cross-section 几何上"占领" family prototype 位置,
后续同 family 候选 (同 atom × 不同 window / nested composition / cross-
product / 替换 form / 同字段跨窗) 在 cross-section ranking 上仍 monotone-
equivalent 到 prototype。

**逃离路径 (b076 F025 实证)**: 高阶 composition (ratio-of-derived-quantity)
— shadow_asymmetry 是 ratio of two derived shadow lengths, 不是 single-
atom ratio。cross-section 上分子分母同消 base scale + base volatility, 与
single-atom Mean shadow (F008) 几何独立 (C006 max_corr 0.29 vs C001/C005
single-atom 0.45-0.47)。与 finding/010 (TsRank ≥60d on ratio fields)
配对: 高阶 composition 是 dim-less ratio frontier 真红利第二阶。
