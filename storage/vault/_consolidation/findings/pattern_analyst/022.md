# pattern_analyst/022 · alpha_surv > 1.0 形式独立 ≠ library 充分条件 (跨 3 batch ≥6 例)

## Pattern

alpha_survival = barra_residual_IC / raw_IC > 1.0 表征"残差 IC 比 raw 还强"——
形式层 Barra basis 顶级独立证据。但**库内 admit factor 不在标准 7-style Barra
basis 内**, Barra-residual alive 与库 redundant 完全可以共存。**3 连续 batch
跨 3 方向 ≥6 例独立确认**: alpha_surv 1.21-1.59 顶级 + incr_ic 全负 / max_corr
0.40-0.70 borderline-high → 全部 reject (b086 C001/C005/C006, b088 C001/C005,
b087 C001 reserve borderline).

机理: csi1000 库内已 admit anchor (F008 upper_shadow / F026 close-position
TsRank / F027 multi-MA reversion / F018 sign-aggregation 等) 完全不在 Barra
7-style basis 内, 故 Barra-residual 仍可撞库 cluster — admit vs reject 差异
完全由 incremental_ic 与 max_lib_corr 决定, alpha_surv > 1.0 不参与决策.

**对照 admit 例 (b082 C006 F026)**: alpha_surv=1.13 + incr_ic > 0 PASS +
max_corr=0.27 LOW — 三件套同时合格才 admit; alpha_surv 单边不足.
