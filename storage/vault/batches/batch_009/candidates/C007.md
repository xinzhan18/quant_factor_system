## 表达式解读

`Sub(CsRank($turnover_rate), CsRank($pe_ratio))` 计算：
- 分子分母各自横截面 rank（Turnover rank 越高 → 越活越；PE rank 越高 → 越贵）
- 做多 (CsRank高 − CsRank低) = 高换手率 + 低PE = 价值实现（机构关注 + 估值便宜）
- 做空 (CsRank低 − CsRank高) = 低换手率 + 高PE = 价值陷阱（无人问津 + 估值昂贵）

这是 T001"Value × Liquidity 交互"的秩差路径，不同于之前被证伪的乘法/除法结构（DSL rank 可以消除量纲问题）。

## CP02 Mechanism Alignment · `aligned`

**机制**：C007 用横截面秩差结构做"流动性-估值"交互。高 Turnover rank + 低 PE rank 代表"机构关注 + 估值便宜"（价值实现）；低 Turnover rank + 高 PE rank 代表"无人问津 + 估值昂贵"（价值陷阱）。秩差结构消除了量纲问题（不同于被证伪的乘法结构）。

**与 hypothesis 一致性**：[[directions/value_liquidity_interaction#Hypothesis]] 假设基本面字段（PE）× 流动性交互能跳出 vol_20d 天花板；本候选引入 `$pe_ratio` 与 `$turnover_rate` 交互，符合 T001 方向。与前批次失败的乘法/除法结构不同，秩差结构是方向探索的新变体。

**持续性**：PE 是横截面排序（相对估值），不依赖价格水平；Turnover rank 反映短期资金流向。两者组合的 edge 在于"便宜 + 有买盘" vs "贵 + 无人买" 这种机构行为模式，理论上在财报季/行业轮动等场景中持续存在。

**失效场景**：市场极端散户化（2015 Q2 / 2024 Q3）时高 PE 小票高换手率，可能出现"贵 + 高流动性"的错误信号；停牌股/涨跌停板扭曲 rank；PE 为负（银行/券商/亏损股）时 rank 失去意义。

**与近邻差异**：[[factors/F002]] `Div($pb_ratio, Mean($amount, 20))` 是 PB 绝对值除以 amount 均值，分母是流动性代理，分子是 PB；C007 完全使用秩，无量纲问题，且 turn over_rate rank 直接捕捉资金流向而非 amount 代理。

→ **aligned**
