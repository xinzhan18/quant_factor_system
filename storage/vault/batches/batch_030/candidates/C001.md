## 表达式解读

`Abs(Div(Delta($close,1), Ref($close,1)))` 等于 `|daily_return|`；除以 `$amount` 得到**单日 Amihud illiquidity**（|收益| / 成交额），也即"单位成交额引发的价格冲击幅度"；`Mean(..., 20)` 再取 20 日均值。高值 = 同样收益需要更少成交额（流动性差、price-impact 大）；低值 = 深度好。Amihud (2002) 的经典 illiquidity 代理，DSL 原生实现。

## CP02 Mechanism Alignment · `aligned`

**机制**：`|daily_return| / $amount` 是 Amihud (2002) 经典 illiquidity 度量——"单位成交额拉动多少幅度的价格"。20 日均值让信号平滑，捕捉**横截面 illiquidity premium**：流动性差的股票因承担流动性风险，长期需要更高的 return 补偿。

**与 hypothesis 一致性**：[[directions/microstructure_illiquidity#Hypothesis]] 明确开宗明义——29 批历史从未触碰 `AmihudIlliq` 维度，本候选就是 T001 第一条 probe（20d, $amount 分母），与 hypothesis 线索 1 完全一致。

**持续性**：illiquidity premium 是 30+ 年跨市场稳健的 cross-sectional anomaly（Amihud 2002; Pastor-Stambaugh 2003），机制基于**投资者承担流动性风险的机会成本**——只要 A 股存在散户/机构流动性分层，该溢价就不会一次性套利掉。

**失效场景**：(a) 熊市极端流动性紧缩时，illiquidity 本身可能变为尾部风险而非溢价来源；(b) 涨跌停板 / 停牌日 |return| 被截断，Amihud 失真；(c) 高成交额股票（大盘股）分母极大导致 Amihud → 0，信号对小盘更敏感（small_cap_concentration=0.351 印证）；(d) 与 `vol_20d` Barra 风格高度耦合（|return| 在分子）时，alpha 会被风格因子吞噬（style_r²=0.472 印证这正在发生）。

**与近邻差异**：[[factors/F002]] = `Div($pb_ratio, Mean($amount, 20))`，是 **估值 × 1/liquidity level** 的交互项——pb 是分子，amount 反比；捕捉"低估值 + 低流动性"的联合 alpha。本候选分子是 |return|（不是估值），测的是 **price-impact per dollar**（不是估值错配）。二者共享 `1/amount` 结构导致 max_corr=0.754，但经济含义正交：F002 是 value trap，本候选是 pure liquidity premium。incremental_ic=0.034（>> 0.005）证明 Amihud 在 F002 之外仍有显著独立 alpha。

→ **aligned**
