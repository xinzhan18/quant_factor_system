## 表达式解读

表达式 `Mean( (VWAP - $low) / ($high - $low), 5 )`，其中 `VWAP = $amount/$volume` 是合成日平均成交价。内层 `(VWAP - low)/(high - low)` 是 VWAP 在当日 HLC range 内的相对位置，范围 [0, 1]：值接近 1 表示当日多数交易集中在区间上沿（买方拉抬后回落或高位成交），值接近 0 表示平均成交价靠近日低（卖盘主导 / 低位吸纳）。5 日均值把瞬时位置聚合成近期买卖压力锚点。

这是 T003 提出的 "HLC 位置锚" 假设：VWAP 在日内 range 的相对位置是否携带超出 F014（跨 session VWAP vs prev_close）之外的独立 alpha。和 batch_040 C006 "VWAP/close ratio 20d"（已 reject）不同，本候选用 HLC 范围作 normalizer 而非 close 标量，理论上捕捉日内 order-flow 倾向而非跨 session 位移。

## CP02 Mechanism Alignment · `mixed`

**机制**：`(VWAP-$low)/($high-$low)` 衡量 VWAP 在日内 HLC range 的归一化位置（0=靠低，1=靠高），5 日均值是近期"买卖压力锚点"的持久度指标。经济直觉：持续高位成交 → 买方主动抬价；持续低位成交 → 卖方主导。

**与 hypothesis 一致性**：[[directions/vwap_proxy_signals#Hypothesis]] 假设合成 VWAP 通道存在未被库利用的独立 alpha；但方向首批（batch_040）已明确 T002 `DISPROVEN` — "日内 VWAP/close 偏离没有 cross-section 可聚合持续性"。本候选形式上改用 HLC 归一化而非 close 标量，属于 T003 "HLC 位置锚" 子假设，但数据证伪（见下文 CP03/CP05）。

**持续性**：若买卖压力锚点真有持久性，OOS mono=0.70 方向正确。但 IS mono=0.10 意味着训练期几乎无单调——持久性假设在 IS/OOS 之间不一致，更像 OOS 偶然对齐而非稳健机制。

**失效场景**：小盘/低流动性股票 $volume 小、VWAP 方差大，HLC range 窄（涨跌停），分母不稳；震荡市 range 压缩时位置信号被 range 噪声主导。

**与近邻差异**：[[factors/F014]] 表达式 `(VWAP-Ref($close,1))/Ref($close,1)` 捕捉跨 session 平均成交价位移（含隔夜信息）；本候选用 HLC range 做 normalizer，理论上剔除跨 session 仅保留 intraday position，但实测 corr=0.8941 说明 HLC range 高度贴合 prev_close 尺度，**机制未真正解耦**。

→ **mixed**（机制叙事说得通，hypothesis 子假设 T003 对齐，但 IS monotonicity=0.10 暴露机制在训练期失效，只是 OOS 偶然被捕捉）
