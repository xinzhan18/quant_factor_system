## 表达式解读

`Div($amount, $volume)` 合成 daily VWAP（当日平均成交价）。`(VWAP - low) / (high - low)` 把 VWAP 映射到当日 HLC 范围的归一化位置 ∈ [0, 1]：0 = VWAP 紧贴 low（日内交易集中在低位），1 = VWAP 紧贴 high（日内交易集中在高位）。这是**日内成交重心位置**的一个代理，与 open/close 在 HLC 范围的位置（如 F007 open_position）同构，但用加权平均价而不是端点价。

经济含义：如果当日 VWAP 偏高（接近 high），说明更多股数在高位成交，可能反映放量追涨 / 尾盘拉升；VWAP 偏低反向。预期正向 IC：VWAP 位置高 → 下一期收益高（买盘持续性）。

## CP02 Mechanism Alignment · `mixed`

**机制**：VWAP 在 HLC 范围内的归一化位置 = 日内成交重心。捕捉日内 order-flow 的价格分布偏态（高位成交 vs 低位成交）。

**与 hypothesis 一致性**：[[directions/vwap_proxy_signals#Hypothesis]] 提出 "$amount/$volume ≈ daily VWAP 作为未被利用的合成通道"。本候选确实用了合成 VWAP，但形态是 **HLC 范围归一化位置**，不属于 hypothesis 原列的 4 类形态（VWAP-close / VWAP-open / VWAP-prevclose / VWAP-close ratio aggregation）。它对应 T003（active thread）中的 "HLC 位置" 探针。

**持续性**：日内成交重心位置反映当日大单 / 主动单的分布偏好，理论上可持续（不是算法交易易套利的信号）。但问题是：**它与 F014 (VWAP - prev_close)/prev_close 相关性高达 0.887**——两者都基于 VWAP，edge 来源可能共享（日内方向性的 overnight 延续）。持续性论证弱化。

**失效场景**：涨跌停日（VWAP 被截断）、低 volume 小盘股（VWAP 噪声大，见 feasibility.small_cap_concentration=0.294）、指数集中上涨日（所有股 VWAP 都偏高，cross-section 区分度降低）。

**与近邻差异**：[[factors/F014]] 的机制是 `(VWAP - prev_close)/prev_close` — 跨 session 的 VWAP-隔夜 spread，捕捉日内均价 vs 昨收的结构性 gap。C001 是**同 session 内部** VWAP 相对 HLC 范围的位置。理论上差异在"跨 session 方向 vs 日内分布"，但实证 corr=0.887 说明两者在数据分布上高度重叠——很可能是因为 high-low 范围与 |VWAP - prev_close| 的分布同源驱动。

→ **mixed**（机制答了 5 问但近邻差异实证上站不住；hypothesis fit 偏弱）
