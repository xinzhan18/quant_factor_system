# C003 — BarraResidual(ForwardReturn5d) — `(close.shift(-5)/close - 1)` ⊥ Barra7

## 表达式解读

`C003.py` 第 54–56 行：

```python
close = df["$close"].unstack("instrument")
# 5d forward cumulative return: (close[t+5] / close[t]) - 1
forward_5d = (close.shift(-HORIZON) / close - 1.0).stack("instrument")
```

然后对 `forward_5d` 做 Barra 截面回归、取残差，作为 t 时刻的**因子值**（而非 y）。

声称机制：测试不同 horizon 的 Barra residual alpha（1d → 5d），假设更长窗口吸收更多 idiosyncratic alpha。**但实现把 forward return 放到了因子侧**，而 evaluator 的 y 仍是 `returns_1d = close[t+1]/close[t] - 1`。

## Lookahead Leak 机制诊断

Evaluator 对齐：`IC(factor[t], returns_1d[t])`。

- **因子值** `forward_5d[t] = close[t+5]/close[t] - 1 = (r[t+1]+1)(r[t+2]+1)...(r[t+5]+1) - 1`
- **y** `returns_1d[t] = r[t+1]`（即 `close[t+1]/close[t] - 1`）

两者直接共享 `r[t+1]` 这一乘积项（在小收益线性近似下，`forward_5d ≈ r[t+1] + r[t+2] + ... + r[t+5]`），因此 `Cov(factor, y) ⊇ Var(r[t+1])`，rank-IC 被拉到 0.4 附近的数学必然值。

Barra residualize 只剥离**跨截面风格**，对这种时序上的"把 y 的一部分塞进 x"没有拦截能力——因此 residual_ic=0.390 同样偏高。

**对照 F004（batch_012 admit）为什么没这个问题**：F004 用 **非归一化的 `close` 价格**做 y，没有除法归一化分母，虽然也共享 `close[t+1]`，但因子值是**水平价格**而非**比率**；截面回归剔除 Barra 风格后剩下的是价格噪声的异质部分，不构成对 `returns_1d` 的线性预测。C003 的关键差异是 `/close` 归一化把水平变成了收益——**这一步就是 leak 的入口**。
