## 表达式解读

`Div($pb_ratio, Mean(Div(Abs(Div(Delta($close,1), Ref($close,1))), $amount), 20))` = PB / Amihud(20d)。分母即 F012 的 20 日 Amihud illiquidity（|return| / amount 的 20d 均值），分子是账面市值比。经济上等价于 **value × (1/illiquidity)** = 高 PB（"贵股"）× 高流动性 → "贵且好交易"得分高。由于 F012 IC 为正（高 illiquidity 获正 return premium），除以 F012 使信号符号整体翻转为负（分子 PB 不足以抵消），IC_OOS=-0.050。

这是 T004 thread "Amihud × value 交互（avoid Mul 量纲陷阱所以用 Div）"的首个探针。问题在于 `Div($pb, Amihud)` 代数上几乎等于 `-F012` 乘以温和的 PB 权重——而非真正"开启第三维"。

## CP02 Mechanism Alignment · `mixed`

**机制**：PB / Amihud = "账面市值比" 除以 "单位成交额引发的价格冲击"。高分意味着 PB 高（成长/贵）且 Amihud 低（流动性好）——即"贵且容易交易的股票"，预测低未来收益（IC 为负、monotonicity = -1.0）。这本质上是 **illiquidity premium 的反向表达 + PB 过滤**：流动性好的股票缺乏 Amihud premium，再叠加高 PB 贵价，双重利空。

**与 hypothesis 一致性**：[[directions/microstructure_illiquidity#T004]] 探的是 "Amihud × value 交互是否打开 illiquidity×value 第三维"。本候选机制可解释但**与 hypothesis 的独立性诉求相悖**——Div 运算让分母 F012 成为 IC 的主导因子，分子 PB 只承担轻微加权；CP05 max_corr=0.788 + signed incremental_ic=-0.0436 是该诊断的直接证据。非独立第三维，而是 F012 的 value-weighted 变体。

**持续性**：若 F012 持续（illiquidity premium 经典文献背书），则 C006 的负相关结构也持续。但其持续性来源与 F012 同源，不是独立 edge。

**失效场景**：与 F012 共享所有失效场景（低流动性小盘股集中时期、量价冲击成本上升时的 regime shift）。额外失效：PB 数据异常（负值、极端值）——feasibility.small_cap_concentration=0.326 提示样本偏中小盘，PB 分母稳定性需关注。

**与近邻差异**：[[factors/F012]] 是 `Mean(|return|/$amount, 20)` 纯 illiquidity；本候选在其上叠了 PB 除法。差异 = 一层 PB 权重——但 correlations 表里 F012 相关 -0.788，F002(pb×amount) 相关 -0.339，证明 Div 运算保留了 F012 结构特征。**机制上是 F012 的衍生子集，非独立轴**。

→ **mixed**（机制说得通，但与 hypothesis "独立第三维" 的诉求方向相反）
