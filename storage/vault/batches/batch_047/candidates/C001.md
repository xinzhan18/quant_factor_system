两端 scale-invariance 验证：
- Amihud: |return|/amount 是 per-dollar price impact (pct / ¥) 是 pct×¥⁻¹ 单位但在 cross-section 横截面上 CsRank 后无量纲。

- 两端 CsRank 后都是 [0,1] 截面位置 → 差值在 [−1,+1] 量纲对称。

## CP02 Mechanism Alignment · `aligned`

**机制**: 与 F015 同源 rank-diff 相对位置结构，但分母端 dispersion 测度从"成交金额波动"换成"换手率波动"。turnover_rate 相较 amount 的差异：turnover 按流通股归一（与市值无直接关系），amount 是绝对金额（与价格 level + 市值共变）。Rank 化后 amount_CV 与 turnover_CV 仍保留差异 → rank-diff 结构对分母选择敏感但不等价。

**与 hypothesis 一致性**: direction [[directions/microstructure_illiquidity#Hypothesis]] 下，illiquidity premium 的 disentangle 从 "vs amount-stability" 扩展到 "vs turnover-stability" — 高 illiq + 稳定换手率组合（冷门蓝筹典型）是 premium 真实载体，同构机制保留。

**与 F015 差异**: F015 是 "Amihud vs amount_CV 10d" 的 rank-diff；C001 是 "Amihud vs turnover_CV 20d"。max_corr=0.734 说明 54% 变异共享（两者都有 Amihud rank 端，共有 Amihud level 的主效应）；46% 独立变异来自分母端字段差异（amount-based CV vs turnover-based CV 在 csi1000 横截面 corr 不为 1）。

**T007 范式兑现**: 本候选直接测试 batch_046 升格教训 "rank-diff 结构两端 scale-free 即有效"。若 admit → T007 第一锤——"换分母字段 (amount → turnover_rate) rank-diff 仍产出独立 alpha"，证实 rank-diff 是 signal-family-组合 的几何性质，不限于特定字段对。

**失效场景**: amount 和 turnover 在某段时期同步（如流动性危机全市场放量）时 rank-diff 退化为 F015 近重复。

→ **aligned**（机制同源 + 字段替换合理 + 两端 scale-invariance 保持 + T007 直接测试 hypothesis fit）
