## 表达式解读

LHS=`Std((O-L)/(H-L), 20)`：(O-L)/(H-L) 是当日开盘价在日内 H-L 范围内的相对下半位置 (∈[0,1])，Std 二阶矩衡量该位置在过去 20 个交易日的 dispersion——直觉上 dispersion 高的股票"开盘价位置不稳定"（事件驱动 / 投机性强）vs dispersion 低的股票"开盘价位置稳定"（机构主导 / 流动性好）。

RHS=`Mean($amount/$volume, 60)`：$amount/$volume = 平均成交价 (VWAP proxy)，Mean 60d 是 60 日 VWAP magnitude——直觉上是个股长期价格水平的代理。

整体 rank-diff geometry：cross-section 上"开盘位置高不稳定 + 长期 VWAP 低"的股票排名靠前。

## CP02 Mechanism Alignment · `aligned`

**机制**：LHS 度量"开盘价在日内 range 中的下半位置"的 20 日 dispersion——是 [[directions/range_structure#T003|T003]] thread 的 intraday position dispersion family 第一条 open-anchored 路径（不同于 F021 close-anchored upper-shadow）。RHS 是长窗 VWAP magnitude，作为 normalization basis。

**与 hypothesis 一致性**：[[directions/range_structure#Hypothesis]] 假设 "(H-L)/close 的结构化 transformation 而非 magnitude 可逃离 vol_20d 吸收"。本候选 LHS 是 intraday position dispersion 而非 range magnitude，与 F021 (H-C)/(H-L) Std 几何 dual（open vs close anchored）；RHS VWAP 是 fundamental-liquidity 维度而非纯 OHLC，按 P005 跨字段族选基。

**为什么持续**：开盘价位置 dispersion 反映"开盘机制噪声"（开盘集合竞价 vs 连续竞价的过渡）；VWAP magnitude 是个股 "size-free" 长期价格水平。两者交互捕捉"开盘 noise 大且 VWAP 偏低"的微观结构异常——A 股小盘股开盘位置 dispersion 与 VWAP 长期负相关时通常是流动性或事件驱动信号，持续性来自微观市场结构稳定。

**失效场景**：(a) 涨跌停频繁的极端市场——开盘价被强约束在涨停板上 → dispersion 失真；(b) 大盘股 VWAP 长期稳定且开盘 dispersion 低 → 信号在 large-cap 域可能反转；(c) 行业事件日（停牌恢复 / 重大公告）。

**与近邻差异**：[[factors/F019]] 表达式 `Sub(CsRank(Std(|C-O|/(H-L),20)), CsRank(Mean(Std($close,5),20)))` 的 LHS 是 body_ratio dispersion (close-open spread per range)，本候选 LHS 是 open lower-position dispersion——atom 不同 (|C-O| vs O-L)；F019 RHS 是 5d 价格 vol 的 20d Mean (vol-of-vol)，本候选 RHS 是 60d VWAP magnitude——基础完全不同。max_corr=0.50 表明两者结构有部分重叠但各自独立信号。

→ **aligned**
