## 失败机制分析 (T004 first finding)

HP-style 2nd-order 3-term form `R60 + R10 − 2*R20` 是 Hodrick-Prescott-style smoothing 差分代理。失败机制：

1. **3-term 复合信号自我抵消**：
   - 单看 TsRank-60 ≈ b072/C006 (alpha_surv=0.447, ls_t=-7.54 strong)
   - 单看 TsRank-10 ≈ b091 hint 短窗信号 (C001 60/10 ls_t=-2.60)
   - 单看 TsRank-20 ≈ b091/C004 base RHS (b091/C004 60/20 ls_t=-2.20)
   - 三者复合 `R60 + R10 - 2*R20` → cross-section 信号方向矛盾, 平均后净信号 = OOS IC -0.00123 (几乎为零)
   - 反映"2 阶差表征 acceleration"假设在 cross-section rank space 上失效 — rank-diff 几何不支持 Taylor-series 多阶展开 (rank space 非线性, 二阶差不是 acceleration)

2. **rank space 二阶差 = noise**：
   - rank 是 ordinal 序数，非线性变换破坏导数链式法则
   - HP-style smoothing 假设输入是 cardinal 量化值；TsRank 输出 [0,1] 百分位不是 cardinal — 2 阶差自动变 noise dominant

3. **train regime IS IC 微正 (+0.002) 反 sign 不是机制信号**：
   - IS 极弱信号 (icir_is=0.036, ic_win_rate_is=0.530 近 50/50) → 几乎随机
   - val OOS 也极弱 (icir_oos=-0.019)
   - 不是 alpha 翻号, 是"无 alpha 噪声方向漂移"

4. **alpha_surv=7.80 paradox 极致案例**：
   - alpha_survival_ratio = 7.80 (>>1.0, P030 paradox guard 极致触发)
   - barra_residual_ic = +0.0096 vs raw_ic -0.0012 — sign flip 且量级翻 8× → 不是真 alpha 而是 noise 信号被 Barra residual 重新解读
   - 这是 lessons P030 律的 first-batch 极端案例: alpha_surv >> 1.0 但 IS/OOS sign_flip + ic_oos 弱 + raw ↔ Barra sign flip → 明显不是 alpha

5. **T004 disproven (HP-2nd-order 3-term)**: rank-diff form 不能向 N-阶差扩展; rank space 非线性破坏 acceleration 几何; T004 axis 该 form 路径封闭.
