## CP02 Mechanism Alignment · `aligned`

**机制**：60d 慢趋势 - 10d 快趋势 → "中期 institutional concentration 与近期方向背离" 检测器。当 60d rank 仍高 (机构集中度长期高) 但 10d rank 已下降 (近期机构资金转弱) 时 rank-diff 大正值 → forward reversal 下行；反之亦然。10d RHS 比 b091/C004 的 20d 更敏锐捕捉近期 regime transition。

**与 hypothesis 一致性**：[[directions/rank_diff_liquidity_microstructure#Hypothesis]] T001 假设"RHS window 伸缩放大 b091/C004 signal magnitude"；本候选直接验证该假设的短端方向 (10d)。

**持续性**：rank-diff form 是 self-normalized (每端都是 [0,1] 百分位)，跨 regime 应稳定；同字段双窗口对照不依赖外部基准。

**失效场景**：(a) 平稳期 60d 与 10d rank 同步 → 差值为 0，信号微弱；(b) 极端 regime change 时 10d 可能"过度反应"反而拉低 rank-diff 的 robustness。

**与近邻差异**：[[factors/F028]] = `dmi_down_ratio_12` (12d DMI down ratio) — 完全不同机制 (动量指标 vs trade-density rank-diff)；max_corr=0.18 的低相关佐证。库内 rank-diff cluster 的 [[factors/F015]]/[[factors/F016]] 是 cross-section CsRank-diff (Amihud + turnover_cv) 形式，与本候选 time-series TsRank-diff 是 cross-section vs time-series 对偶。

→ **aligned** (5 问全答 + hypothesis fit 清晰)
