## 表达式解读

`Div(Max($amount, 20), Mean($amount, 20))` = 过去 20 日单日最高成交额 / 过去 20 日平均成交额。数值恒 ≥ 1，反映近期资金流入的"尖峰"程度：

- 比值 ≈ 1 → 成交额均匀（每日资金参与稳定）
- 比值 远 > 1 → 存在一天巨额成交主导了总量（事件驱动 / 大单拉抬 / 天量换手）

与 C001/C002 的 CV 不同，本信号只看"最大单日" vs 均值，对高阶尾部更敏感；OOS 均值方向为**高比值 → 低收益**（ic_oos < 0，mono_oos = -1.0 完美单调），与 T002 假设"右偏 + 高峰度 → 资金异动具反转意义"一致。

## CP02 Mechanism Alignment · `aligned`

**机制**：捕捉"单日峰值成交额"相对均值的倍数，是 $amount 分布的右尾形状指标。高值 = 近 20 日里存在某天资金异动（巨额成交主导均值）；低值 = 资金流入均匀无异常峰。

**与 hypothesis 一致性**：[[directions/amount_volatility_signal#Hypothesis]] 线索 2 提出"右偏 + 高峰度 = 少数几天巨额交易主导均值，可能是信息驱动或技术性噪声"。本候选直接测量"峰值 / 均值"倍数，是该线索的最直接代理。OOS 的负 IC（高比值 → 低未来收益）支持"异常大单更像拉尾盘 / 抛压 / 情绪高点"而非信息先行——散户追涨型资金特征。

**持续性**：右尾异动反映的是微观结构断层（散户集中买入 / 大单拉抬后抛压），这是 A 股长期存在的交易行为特征，不是套利能快速抹平的价格错估；且因子基于 scale-invariant 比值而非水平值，规避了市值代理衰减。

**失效场景**：
1. 涨停板 / 停牌后复牌时 $amount 极端值会机械触发高比值，但其后收益未必反转（可能是真实利好）
2. 指数权重股在 ETF 再平衡日被动集中成交，产生假性峰值
3. 极端牛市普涨阶段，所有股票都放量，比值区分度下降

**与近邻差异**：首批无近邻（`max_lib_corr=0`）；与同方向 T001 的 CV 候选（C001/C002）互补——CV 是二阶矩的对称度量，本信号只对"上尾"敏感，区别于"整体分散度"。

→ **aligned**
