## 表达式解读

`Skew(Div(Sub($high, $low), $close), 60)` 对每只股票计算过去 60 个交易日的日内相对 range `(high - low) / close` 的三阶中心矩偏度。

- **正偏**（右尾厚）：大多数日子 range 较小，偶尔出现极端大 range 日（事件驱动、游资介入、新闻冲击）——这是"事件驱动型"波动模式
- **负偏**（左尾厚）：range 集中在较高水平，偶有特别安静的日子——"持续震荡型"
- **近零**：range 分布接近对称，无明显 event/quiet 区分

与 vol_20d（daily return std）的本质区别：vol_20d 衡量的是收益波动的二阶矩**幅度**；本候选是 range（完全不同的量，(high-low)/close 是日内路径测度）的**三阶矩形状**。即使 range magnitude 与 vol_20d 强相关，range 的偏度结构与 vol_20d 在数学上正交（shape vs magnitude）。

## CP02 Mechanism Alignment · `aligned`

**机制**：60 日窗口内 `(high-low)/close` 的三阶矩偏度，衡量 range 分布是否呈"少数极端日 + 多数平静日"（右偏）还是反之。这捕捉的是**事件集中度** / **range regime 的形状结构**，而非 range 的平均幅度（vol_20d 吸收）。csi1000 小盘受 10% 涨跌幅约束，真正的"游资进场"或"业绩雷"会在单日打满接近涨停的 range，而平时绝大多数日子 range 很窄——正偏度应当与后续正收益关联（事件股 → 持续关注 → 边际资金流入）。

**与 hypothesis 一致性**：[[directions/range_structure#Hypothesis]] 明确假设 range **shape**（skew / timing / frequency）可能逃离 vol_20d 的连续 std 空间。本候选直接测试其中 Skew 分支，与方向 hypothesis 完全对齐。T001 的 evidence trail 现在可以填入本候选结果。

**持续性**：小盘"事件日 vs 平静日"的二元结构由 A 股散户结构 + 游资脚印 + 小流通盘引发——是结构性现象而非套利机会窗口。偏度作为 shape statistic 对仓位 / 定价没有直接导数，不易被套利消除。ic_by_year 从 2015 到 2023 全年正号支持持续性（尽管 2021-2023 衰减）。

**失效场景**：
- 宽带横盘市（range 持续均匀）→ 偏度趋近 0，信号无力
- 涨跌停普遍打开时（2015/2018 极端市场）→ 10% 约束失效，偏度分布被压缩，信号失真
- 停牌恢复后 60 日内 → 样本不够，Skew 不稳定

**与近邻差异**：[[factors/F012]] 表达式为 `Mean(Div(Abs(Div(Delta($close, 1), Ref($close, 1))), $amount), 20)`（amihud 非流动性：|收益率| / amount），捕捉的是"单位成交金额带动的价格变动"——液性/冲击成本的一阶均值。本候选捕捉的是 range 分布的三阶矩形状，测度对象（range 而非 return/amount ratio）、统计阶矩（三阶而非一阶）、窗口（60 而非 20）三维度都不同。max_lib_corr=0.117 印证机制正交。

→ **aligned**
