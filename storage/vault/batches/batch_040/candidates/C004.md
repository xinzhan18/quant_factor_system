## 表达式解读

`(VWAP_proxy - prev_close) / prev_close` = 当日成交均价相对**昨日收盘**的归一偏离率，等于 "overnight gap 到平均成交价的累计涨跌幅"。它把隔夜 gap（open vs prev_close）和日内交易（VWAP vs open）两段信息合并成一个单值，但用前收作分母强制了"跨 session"视角，与 C001 的"日内"视角形成机制互补。正值 = 当日整体成交价跑赢昨收（资金流入主导），负值 = 跑输（流出主导）。

**机制**：跨 session 的 VWAP-prevclose 累计偏离 — 把 overnight gap 与日内成交均价合并为单一"今日相对昨日整体盈亏率"指标。前收作分母让信号天然包含 overnight 段，覆盖 C001（日内）和 F003（gap）之外的信息维度。

**与 hypothesis 一致性**：[[directions/vwap_proxy_signals#Hypothesis]] 明确列出 "VWAP gap：($amount/$volume) - Ref($close, 1) = 平均成交价 vs 昨收" 是首要候选；hypothesis 已预测 "包含隔夜信息 + 日内信息混合" — 本候选完全对齐。

**持续性**：跨 session order-flow 整合（隔夜情绪 + 日内续作）是 A 股结构性现象，T+1 交易制度下隔夜风险溢价稳定存在；mono_oos=0.60 强单调与之 mechanism 自洽。

**失效场景**：公告日（隔夜异常 gap 由信息驱动而非 flow）、停牌恢复首日、整体市场极端波动日（系统性 risk-off 抹平 cross-section）。
