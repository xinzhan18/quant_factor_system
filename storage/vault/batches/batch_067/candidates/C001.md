## 表达式解读

`Mul(Cov(Delta($close,1), Ref(Delta($close,1),1), 20), -1)` = -Cov(Δp_t, Δp_{t-1}, 20). Roll (1984) 推导: 在无信息流 + 双向订单流均匀的微观市场中, 观察到的价格变化 Δp_t 与下一期 Δp_{t-1} 应呈负相关 (买卖价反弹, bid-ask bounce). 取负号 → 高值 = 强 bid-ask bounce = 高 microstructure illiquidity. 这是 Amihud (2002) 价格冲击量 Mean(|ret|/$amount) 之外的另一独立 microstructure illiquidity proxy.

## CP02 Mechanism Alignment · `aligned`

**机制**：Roll (1984) 经典 effective-spread proxy. 测的是 high-frequency 价格反弹噪声而非低频价格冲击 (后者 F012 Amihud 已捕获).

**与 hypothesis 一致性**：[[directions/microstructure_illiquidity#Hypothesis]] 假设 Amihud (2002) 价格冲击 + HHI 集中度 + Entropy 分散度三轴. Roll-cov 是**第四轴 — bid-ask bounce 微观噪声轴**, 与 hypothesis 三轴互补 (Roll: 短时序反弹; Amihud: 价格冲击/dollar; HHI: 时序集中度).

**持续性**：双边市场流动性提供商在每个交易日提供 spread; 这个机制是 institutional/structural 的, 不会因 regime 切换消失. 9/9 年 sign_consistency=1.0 (尽管 magnitude 弱).

**失效场景**：(a) 涨跌停封板日 Δp=0 → cov 退化; (b) 高度 trending 股票 Δp 序列正自相关 (动量) 而非反相关 → Roll-cov 反向; (c) 信息事件日 Δp 主要由 informed trading 驱动而非 spread bounce.

**与近邻差异**：[[factors/F001]] (`Div(Std($amount,10), Mean($amount,10))`) 测 amount 时序集中度 (CV); 本候选测 return 序列反弹相关性 — 完全独立信号 (corr=-0.07).

→ **aligned**
