## 反思 — 设计阶段失误 (P025 升格 candidate)

**TsRank 是 rank-form 算子, 对 `x` 做单调仿射变换 `ax + b` (a>0) 不改变排序**. 因此 `TsRank(close_position - 0.5, 60)` 在数学上等价于 `TsRank(close_position, 60)` (减常数 0.5 是 a=1 b=-0.5 的仿射变换). 本候表达式与 b076/C001 是**完全等价的**, 所有 metric 一致是设计阶段 mean_centering 路径选择失误的直接结果.

**对 reserve revival 假设的明确证伪**: mean_centering 路径作为 "破 raw level 共线" 手段在 rank-form 因子上是 **no-op**. 真要破 close_position 与 F008 的耦合, 必须:

1. 用 cross-sectional residualize: `close_position - mean(close_position over peers)` — 这是 cross-section demean, 而不是 TsRank 内部减常数.
2. 用 Python residualize against F008 — 但这超出 DSL 表达, 需 F-residual python factor 路径.

**Phase 1 设计 checklist 升级 candidate**: 凡 rank-form (CsRank/TsRank) 内部做仿射变换, 自检阶段直接拒绝 — 这是数学等价 trivial path, 不应进入 batch.
