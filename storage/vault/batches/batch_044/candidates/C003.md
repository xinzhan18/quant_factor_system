## 表达式解读

`Sub(Quantile($amount, 60, 0.75), Quantile($amount, 60, 0.25))` = 过去 60 日成交额分布的四分位距（IQR）。本应是 rank-robust 的离散度 shape 信号——相对 Std($amount) 对极值免疫，相对 CV 不依赖 mean。经济直觉：IQR 大 = amount 分布宽（近期交易规模波动大，可能事件驱动或 regime 切换）；IQR 小 = amount 分布集中。

但在 csi1000 上，60d amount IQR 与 amount CV（F001）、amihud 流动性冲击（F012）、以及 Barra vol_20d 强共线——后文 CP04 证实风险暴露已将其完全吞噬。

## CP02 Mechanism Alignment · `misaligned`

1. **机制**：60 日 $amount 四分位距衡量成交额分布宽度。理论上是 shape 信号（rank-robust 离散度），与 CV（标准差/均值）相比对极值免疫，更多刻画"中间段"的离散度。方向低 IQR = amount 稳定 → 未来 return 高；方向高 IQR = amount 动荡 → 未来 return 低（IC 负）。

2. **hypothesis 对齐**：[[directions/quantile_shape_signals#Hypothesis]] 明确指出 "用 Quantile 算子在非 return 字段上测 rank-robust 分布形状，**逃离 vol_20d 的 2nd-moment 吸收**"；并在关键风险段直接点名 "turnover/amount IQR 已被 F001 amount CV 和 F012 amihud 部分覆盖——max_corr 关注"。本候选实测 max_lib_corr=0.7986@F012（amihud illiquidity）、style_exposures.vol_20d=22.47（本批最高之一）、alpha_survival=0.069 → **方向假设的核心目的（逃离 vol_20d）在本候选完全失败**。IQR 在 amount 字段上并非 rank-robust shape，而是 magnitude-scaled dispersion，仍落在 power-mean family 附近。

3. **为什么持续**：理论上 amount IQR 大的股票 = regime-unstable 或小盘事件驱动，未来 risk-adjusted return 低。但经济意义已被 vol_20d 吸收：Barra 残差 IC 仅 -0.003（原 IC -0.049 的 6.9% 存活），说明因子几乎不携带 orthogonal-to-style 信息。

4. **失效场景**：低波动期所有股票 IQR 都小、横截面区分度坍缩；涨跌停连续打开事件会人为放大 amount 波动。但更根本的问题是——本因子**不存在独立 edge**，"失效"已经是常态。

5. **近邻差异**：[[factors/F012]] = `Mean(Div(Abs(ret), $amount), 20)`（amihud illiquidity，低 amount 高 return abs 的股票）。本候选 amount IQR 与 F012 的 Spearman corr = -0.7986，机制上同源——都在捕捉 "amount 小 × 波动大" 的小盘流动性簇。IQR 只是换了 estimator，没有换空间。

→ **misaligned**（机制与方向去-vol_20d 假设正面冲突；CP04 + CP05 双重证实）
