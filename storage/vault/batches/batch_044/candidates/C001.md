## 表达式解读

`(H-L)/C` 是日内 range 归一化到收盘价（"日内波动强度"），对其取 60 日窗口的 P90 和 P50，再相减：即过去 3 个月内 range 分布的**上尾-中位差**，度量 range 分布**右尾厚度**（头部事件驱动程度）。

经济直觉：若 Q90-Q50 大，说明 60 日里少数几个高 range 日显著高于中位数（事件驱动、分布右偏）；若小，说明 range 均匀分布无尖峰。Hypothesis 是高 Q90-Q50 = 近期事件密集 = 不稳定 universe，下一期回报偏低；IC 应为负。

实测 ic_oos=-0.0524、mono_oos=-0.9 与该先验方向一致——事件右尾厚的股票未来跑输。

## CP02 Mechanism Alignment · `aligned`

**机制**：`Quantile((H-L)/C, 60, 0.9) - Quantile((H-L)/C, 60, 0.5)` 捕捉 range 归一化后分布的**上尾-中位差**——一个 rank-robust 的"右尾厚度"度量。高值 = 过去 3 个月 range 分布被少数事件日拖起（右偏）；低值 = range 均匀。

**与 hypothesis 一致性**：[[directions/quantile_shape_signals#Hypothesis]] 提出"Quantile 差在非 return 字段（range/turnover/amount）上可能产生独立于 vol_20d 的 cross-section 信号"，本候选正是第一条路径（range 上的 Q90-Q50）。IC 负号 + 强 monotonicity 证实了 hypothesis 里的经济叙事——事件驱动型 universe 下期报酬偏低。

**持续性**：range 右尾厚度编码**公司级事件密度 + 成交不稳定性**，这不同于纯 vol（二阶矩）。事件密集股的后续 return 漂移来自信息消化 / 流动性溢价回归，这是行为金融里的 post-news drift mean reversion，属结构性边缘，不是一次性。

**失效场景**：(1) 涨跌停板密集期（事件日 H-L 被人为截断）→ Q90 失真；(2) 全市场高波动 regime（如 2015Q3 / 2024Q1），所有股票都有高 range 日 → 差分被压缩；(3) 小盘 universe 下 liquidity_coverage=0.68，样本偏向中等流动性以上，小微盘不可投部分未覆盖。

**与近邻差异**：[[factors/F014]]（`Div(Sub(Div($amount,$volume), Ref($close,1)), Ref($close,1))`）捕捉的是**单日 vwap 代理 - 昨收**的 overnight+intraday 溢价（日度截面量价信号）；本候选捕捉**60 日 range 分布形状**（横跨多月的高阶分布特征）。机制完全不同源——F014 正向 alpha（均值回归反转），本候选负向 alpha（右尾厚 → 后续差）；max_corr 仅 0.215，两者可共存。

→ **aligned**
