## 表达式解读

`Med(Div(Sub($high,$low), $close), 5) / Med(Div(Sub($high,$low), $close), 60)` — 分子是近 5 日 normalized-range（(H-L)/C）的中位数，分母是近 60 日同样量的中位数。比值 >1 表示**近期 range 相对长期放大**（行情激活、可能短期加速），比值 <1 表示**近期压缩**（行情沉默、可能蓄势）。

负 IC 表示：比值大（近期 range 放大）→ 未来 1 日 return 低。经济解读：近期 range 膨胀常伴随已消化的短期事件驱动/消息公告，事件后的反转/均值回归；或近期高 range 本身是过热信号（过度交易）。

与 C005（Med(range, 60) 单边）不同，C006 是**比值形式**——去掉长期 range 水平（因子不随标的长期波动水平变化），只剩下"短期 vs 长期"的**相对形状变化**。

## CP02 Mechanism Alignment · `mixed`

**机制**：短期（5d）range 中位数 / 长期（60d）range 中位数——捕捉"近期 range 是否相对长期水平放大/压缩"的**相对变化率**。分子分母同尺度、同字段，天然除 away 个股长期波动水平，只剩形状/时序变化。

**与 hypothesis 一致性**：[[directions/quantile_shape_signals#Hypothesis]] 主张用 Quantile/Median 在非-return 字段上测 rank-robust shape 逃离 vol_20d。C006 使用 Median 而非 Quantile 差分，落在 hypothesis 的**广义 shape-ratio 支线**内，但技术上**不完全等价**于 "Q90-Q50" 或 "Q75-Q25" 这类百分位差 —— 比值形式隐含"分子分母分布形状不同时"才有信号，否则会被 vol 吸收。

**持续性**：短期 range 放大→未来 return 下降的机制，在 A 股小盘 universe 存在（事件驱动 → 消息过度反应 → 反转）。但比值形式的稳健性低于差分形式，因为分母（长期 range）也随 vol_20d 共变，比值的"独立性"被稀释。

**失效场景**：(1) 长期低波动期，分母接近零 → 比值爆炸 → 极值主导；(2) 涨跌停频繁标的（小盘情景），range 本身被 A 股 10% 涨跌幅约束截断（见 [[lessons#Data Facts]]）；(3) 长期持续上涨/下跌 trend 中，range 比值的"反转"解读失效。

**与近邻差异**：[[factors/F009]] 捕捉 `Mean(Sub(Div(Sub($open, Ref($close, 1)), Ref($close, 1)), Div(Sub($close, $open), $open)), 5)` ——5 日"隔夜 return 减日内 return"均值（pv-corr 式 timing 信号，捕捉隔夜 vs 日内的错配）。C006 捕捉 range 层面的时序比值，与 F009 在**字段层面不重合**（F009 用 open/close 差，C006 用 high-low 差），corr=-0.214 弱。

5 问答了 3-4 问，hypothesis 对齐"勉强说得通"（hand-waving 在"比值是否真正 shape 还是 vol 变化率"这个问题上）。→ **mixed**

→ **mixed**
