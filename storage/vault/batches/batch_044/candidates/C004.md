## 表达式解读

`Div(Sub($high,$low), $close)` 先算日内 range 的 close-normalized 比例（即日内相对波幅），再在 60 个交易日窗口内取 Q75 与 Q25 两个百分位之差。**这是一个 IQR（四分位距）形 shape estimator**，只看中段分布的宽窄，对尾部极值免疫：

- IQR 大 → 60 日内 range 分布宽，日间 range 差异显著，波动结构"起伏明显"
- IQR 小 → 分布窄，多数日 range 相近，波动结构"平稳"

IC 为负（IC_OOS=-0.056）意味着：**过去 60 日 range IQR 大的股票未来收益更差**，IQR 小的股票未来收益更好。经济上可解读为"近期波动结构杂乱 → 风险溢价不足以补偿"，或更简单地——这是 vol_20d 在 IQR 伪装下的另一面。

## CP02 Mechanism Alignment · `aligned`

**机制**：60 日 range/close 的 IQR（Q75−Q25）—— 捕捉"日内相对波幅"在中段分布的宽窄。IQR 大 = 过去 60 日 range 值差异显著（波动结构不均匀）；IQR 小 = 波动结构稳定。负 IC 意味着波动结构杂乱 → 未来收益偏差。

**与 hypothesis 一致性**：[[directions/quantile_shape_signals#Hypothesis]] 假设 Quantile 差分对尾部免疫、robust to outliers，可能逃离 vol_20d 2nd-moment 主轴。本候选以 `(H-L)/C` 的 60 日 Q75−Q25 直接实现该路径；**max_corr=0.234 低**说明逃离 F014（日频 intraday return proxy）成功，但 CP04 显示 **vol_20d 暴露 41.78**——hypothesis "逃离 vol 主轴"的断言在 style-space 层面**未达成**（虽然在 library-space 层面达成）。

**持续性**：60 日窗口涵盖约 3 个月横截面，IQR 是稳定的分布统计量（不易被单日突变主导），从 2015–2023 逐年 IC 单调变深（-0.014 → -0.058）来看 edge 在持续强化而非消退，说明是结构性截面效应。

**失效场景**：
- csi1000 小盘宽波动时段（2015-牛市、2020-Q1 疫情）IC 偏浅（2015: -0.014）
- 若未来市场波动极度压扁（全 universe 都低 IQR），信号离散度下降 → ls_spread 收窄
- 涨跌停板截断会系统性压缩 range Q75，影响 IQR 上尾稳定性

**与近邻差异**：[[factors/F014]] 捕捉 `(amount/volume − ref_close) / ref_close`，即 vwap_proxy_spread 的**方向性日频 return proxy**；本候选捕捉 **60 日 range 的中段 IQR**——一个是日频价量方向信号，一个是月度级 range 分布形状。两者机制正交（max_corr=0.234 印证），但同时被同一 style (vol_20d) 所 span。

→ **aligned**
