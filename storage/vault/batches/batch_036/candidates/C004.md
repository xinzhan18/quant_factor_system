## 表达式解读

`Sign($open - prev_close)` 是隔夜 gap 方向（+1 上跳 / -1 下跳）；`Sign($close - $open)` 是日内 body 方向（+1 收阳 / -1 收阴）。两者同号意味着市场"接受"了开盘 gap（pre-market 信息被日内确认），异号意味着 gap 被"拒绝"（开盘冲动被日内反转）。

C004 在前两个因子（C001/C002/C003 用 `Div($amount, Mean($amount, 20))` 直接线性加权）失效后，改用 `Log(Div($amount, Mean($amount, 20)))` 作为权重——log 压缩把异常放量日的极端权重削弱、把正常日（ratio ≈ 1）的 log ≈ 0 的部分也变成 ~0 不带 sign 影响，把负样本（缩量日，ratio < 1）真正变成负权——本质是把"放量接受"和"缩量接受"做了**对偶处理**。20 日均值聚合得到一个无单位的 acceptance × log-abnormal-amount 综合分。

机制叙事：信息论意义上，放量日的接受/拒绝信号信息量更高（市场参与者多 → 共识强），缩量日的同样信号信息量低（流动性枯竭 → 易被噪声主导），log 加权恰好提供了"信息量正相关"的非线性映射。

## CP02 Mechanism Alignment · `aligned`

**机制**：跨 session "接受/拒绝" 信号（gap_sign × body_sign）按 log 标准化异常成交额加权，20 日均值。捕捉"市场对 pre-market 决策的高信息量确认/反驳的持续偏差"。

**与 hypothesis 一致性**：[[directions/gap_acceptance_structure#Hypothesis]] 已在 batch_035 部分证伪（pure sign interaction 在 csi1000 regime 翻号），方向唯一生路是 T002 量能加权。本候选正是 T002 thread 的 log 变体——直接回应 batch_035 C004（线性 turnover_rate 加权）留下的"mono 仅 0.30 / Q1-Q4 平、Q5 独负"形状缺陷。结果：**mono_OOS 从 0.30 → 0.60**（rank-order 显著改善），quintile 梯度也从单极变成更接近单调（Q1=-0.000327 → Q3=+0.000122 → Q5=+0.000026，Q1<Q5<Q3），证明 log 压缩把权重的"异常值放大"问题修好了一大半。

**为什么持续**：A 股小盘股（csi1000）日频上 pre-market 信息源（隔夜美盘、政策、公告）天然有 1-2 周的扩散期，量能放大日的接受/拒绝信号是机构调仓行为的可观测代理。Log 权重保证了"放量+接受"的强信号不会被极端尾部主导，机制是行为金融而非单纯数据拟合。9 年 ic_by_year 中 2018-2023（除 2015 一年负）8/9 年同号正，且 2020-2023 近 4 年呈现 0.0095/0.0055/0.0083/0.0105 的稳定区间——说明 edge 没有被 quant crowding 吃掉。

**失效场景**：(1) 极端流动性事件（2015 股灾日）log_abnormal_amount 同时极大但接受/拒绝信号极不稳定 → 2015 IC=-0.0053 是唯一负年；(2) 全市场涨停/跌停日 body_sign 退化（close = open）；(3) 个股停牌恢复首日 gap 反映停牌期信息，与连续交易日 gap 性质不同；(4) 行业事件型同向波动会让 sign 同号率系统性升高，稀释 cross-section 区分度。

**与近邻差异**：[[factors/F010]] = `Mean(Div($open - prev_close, prev_close), 5)` 是 5 日 overnight return 持续性，**只用 gap 收益、不用 body**，5 日窗口；C004 用 **gap_sign × body_sign 二元接受性 × log_abnormal_amount 量能加权**，20 日窗口。F010 衡量"隔夜方向的时序持续"，C004 衡量"高量能日跨 session 接受/拒绝的累积偏差"——前者是动量类，后者是行为微结构类，机制根源不同；max_corr 实测 0.085 极低，证实正交。

→ **aligned**
