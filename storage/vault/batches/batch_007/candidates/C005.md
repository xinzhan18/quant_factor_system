## 表达式解读

`Div(Div(Delta($pe_ratio, 20), $pe_ratio), Div(Delta($turnover_rate, 20), $turnover_rate))` = **两个自归一化 20 日变化率之比**：分子 = PE 的 20 日变化率（估值相对变化），分母 = turnover_rate 的 20 日变化率（流动性相对变化）。

这个悖论的**机制含义**值得详细刻画 — 本候选因子**横截面值**（factor values 本身）在 Barra 7 style 上的回归 `R² = 0.016` 极度 clean（因子值本身与 Barra basis 几乎正交），**但**因子用于预测未来收益时，其 IC 的 `1 - alpha_survival = 0.903 = 90.3%` 与 Barra basis 对齐消失。

**三层几何解释**（从假设到推论）：

1. **因子值 ⊥ Barra basis** (style_r²=0.016)：因子值 `f = Div(PE_rate, turnover_rate_rate)` 的横截面空间与 Barra 7-因子子空间几乎正交 — 作为 cross-sectional **ranking 工具**，它捕捉的维度是 Barra basis 之外的。

2. **forward return 预测维度却 ⊂ Barra basis** (alpha_survival=0.097)：但因子对未来收益的 IC 预测方向，投影到 Barra basis 上保留 < 10%，即**因子 IC 的 90% 与 Barra basis 对齐**。意味着：因子 ranking 产出的 long-short portfolio weights 与 Barra factor portfolios 高度相关。

3. **几何含义**：因子值空间（N 股 × 因子标量）与因子 IC 空间（因子值 → 未来收益的回归斜率 = cross-sectional rank-based portfolio weights）**是不同的投影维度**。"因子值与 Barra 正交"（style_r²）刻画的是**静态因子形状的 basis 覆盖**；"alpha_survival"刻画的是**动态预测能力在 Barra 中的表达**。

   物理类比：两个向量 a 和 b 在空间 V 上**静态几乎正交**（内积 ≈ 0），但 a 在 V 上的**梯度方向**（\nabla a）几乎完全落在 V 的 span 内。本因子的 cross-sectional rank 产生的 "alpha 方向"（长短仓 portfolio）在 Barra factor portfolio span 内。

4. **为什么 C005 落入 C004_b6 同构陷阱**：两者共同结构 = **在 vol_20d 主导的股票 universe 里做 Barra-style orthogonal 的 ranking**。Vol_20d 作为 A 股最强 style 因子，其 cross-sectional variance 远高于其他 style，所有"用 PE 或 turnover 派生"的候选 rank-order 都落在 vol_20d + turnover_20d 的二维主平面附近。**自归一化（Div(Delta(X),X)）仅消除 level 量纲，并不消除 variance 量纲**（= vol_20d 暴露）。

**结论**：本候选**首次把方向 ls_t 推过 2**（rank-order 层 hypothesis 完成），但**精确复现 C004_b6 的 arbitrage-like 悖论机制** — 比 C004_b6 更极端，因为 C005 的 style_r² 只有 0.016（C004_b6 为 0.08），意味着因子值**更 barra-clean**，但 alpha_survival **比 C004_b6 稍好一点**（0.097 vs 0.0009）——这只是同一悖论曲线上的两个点。一句话总结"本因子 cross-sectional rank 空间与 Barra factor space 正交，但其预测的 L/S portfolio 几乎完全重合 Barra factor portfolio"，**下轮需在 Python 逃生口做 Barra residual orthogonalization**（不能在 DSL 内解决）。
