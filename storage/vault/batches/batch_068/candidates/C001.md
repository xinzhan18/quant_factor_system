## 表达式解读

`Div($return_on_equity_ttm, Mean($amount, 20))` — TTM 净资产收益率 / 20 日均成交额。
- Numerator: ROE TTM = 净利润 / 净资产，quality LEVEL signal，理论与 OHLCV 几何独立
- Denominator: 20-day mean amount = daily-aggregate liquidity proxy

**机制 (原假设)**: 高 ROE + 低 turnover = 被低估的高质量股 → cross-section 反 IC 反映 valuation correction。同 F002 (PB/amount) 套路把 fundamental 与 liquidity 结合。

## 反思

**核心反直觉**: 假设 daily-aggregate liquidity (amount mean) 是中性 normalizer，实际它是 vol_20d 的高 loading 字段。`Mean($amount,20) ∝ √vol_20d × size_avg` 经验律 (高 vol 股 amount 更高)，把 ROE numerator 拉进 vol_20d basis。

**与 F002 对比**: F002 同 (PB/amount) 套路 admit，因为 PB 是 value Barra basis 主成分，与 vol_20d 抗衡能力强。ROE 没有同等 Barra basis (quality 不是 6 维 Barra style 之一在 csi1000 上的强 axis)。

**复活路径**: Python OLS residualize ROE on (vol_20d, size, value)；或用 TTM denominator (e.g. inventory_turnover_ttm) 避开 daily liquidity 路径。
