## 表达式解读

`Div($pe_ratio, Mean($turnover_rate, 20))` = 当前 PE 除以近 20 日均换手率。结构上意味着：

- **高值股（做多端）**：PE 高 且 换手率低 → 高估值冷门股（机构冷遇、散户不热的"被忽视高估值"）
- **低值股（做空端）**：PE 低 且 换手率高 → 低估值热门股（热炒便宜货，典型散户拥挤）

此候选是 T001 除法路径在 batch_005 C005 `Div($pb, Mean($amount, 20))` 失败后的继承：分母换 `$amount → Mean($turnover_rate, 20)` 意在"去市值"（turnover_rate 已对市值归一化），分子换 `$pb → $pe` 盼跳到 `ep_ratio` 风格轴。

## CP02 Mechanism Alignment · `misaligned`

**机制**：PE 高 + 换手率低 = "被忽视的高估值"，PE 低 + 换手率高 = "热炒的便宜货"。做多前者做空后者，机制上押注"市场注意力滞后于基本面估值"。

**与 hypothesis 一致性**：[[directions/value_liquidity_interaction#Hypothesis]] 的核心是"基本面 × 流动性交互产生**跨风格空间** alpha"。本候选在**代数形式**上遵守（分子 `$pe_ratio`、分母 `Mean($turnover_rate, 20)`），但**风格暴露层完全反方向**：dominant=`vol_20d` (exposure=13.76) + `turnover_20d` (3.06) + `str_1m` (0.30) + `ep_ratio` (0.70)——vol_20d 占据绝对主导，与前两方向（`amount_volatility_signal` / `turnover_structural_signal`）教训完全重合。分母 `Mean($turnover_rate, 20)` 并未成功"去市值"，反而因 1/turnover 方向性再次把信号推入波动率 proxy 空间。

**持续性**：PE 与 turnover 在 A 股中稳定存在，IC 9 年 (2015-2023) 全正，量级 0.010-0.027，sign_consistency=1.0——IC 层 edge 持续性确实**真实存在**。

**失效场景**：极端行情（熊市 2018 / 流动性危机）中 Q1/Q5 收益会崩塌。更关键的是——**在任何 Barra 风险暴露下都失效**：alpha_survival=0.0009 意味着 99.91% 的 IC 都被 7 个 Barra style 解释掉，本因子**不具备独立 alpha 生成能力**。

**与近邻差异**：[[factors/F001]] 是 `Div(Std($amount, 10), Mean($amount, 10))` = amount CV，捕捉 amount 波动归一化。本候选 max_corr=0.049（几乎独立）、incremental_ic=+0.018（看似能贡献），但近邻独立不等于风格独立——IC 是独立但落在 Barra 子空间内独立方向。

→ **misaligned**（代数形式符合 direction 但 Barra 层完全重合 vol_20d/turnover_20d 教训，且 alpha_survival 反向）
