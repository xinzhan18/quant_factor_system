## 表达式解读

`CsRank($pe_ratio) × Log($turnover_rate / Mean($turnover_rate, 20))`：每个横截面对 PE 做百分位排名（高 PE = 排名靠 1），再乘以**当日 turnover 相对 20 日均值的对数偏差**。直觉：高 PE（昂贵）叠加当日换手异常放大 → 信号大正。T002 thread 设计意图：PE 是 earnings-yield 通道的价值轴，log 压缩 turnover 尾部抑制极端噪声。

**实际发现的机制**：高 PE × 异常大 turnover → **低未来收益**（IC 负 0.034）。这不是 value × liquidity 正向 edge，而是"高估值股遇到抢筹放量后的短期反转"——csi1000 overnight-intraday 反转簇的一种载体。

**与 hypothesis 一致性**：[[directions/log_value_liquidity#Hypothesis]] 假设 log-compression 把 `gap_acceptance_structure` 的反转元教训转嫁到 value × liquidity，"value 维度解锁 F002 之外的第 2 个 admit"。**本候选证伪该假设在 pe × turnover 方向**：信号本身是"反转簇 + 高波动吞噬"的综合载体，**value 维度的贡献是极小甚至负的**（style 表 `ep_ratio` 暴露仅 0.323，`book_to_price` 仅 0.166），主力是 vol_20d / str_1m。也即 csi1000 小盘池中的 pe × log(abnormal turnover) **不存在独立的 value × liquidity alpha**，只是换了个包装的反转/波动信号。

**失效场景**：不适用——方向不对，不是"会在 X 场景失效"而是"从来捕的不是宣称的 X 信号"。

**与近邻差异**：[[factors/F007]] 是 `Mean((open-low)/(high-low), 5)`（5 日 open 在日内相对位置均值，反转），corr=0.227；外加 F009（overnight-intraday 反转簇，corr=-0.226）、F006（-0.210）、F008（-0.189）——本候选与**反转簇整个家族**低度但系统性同向相关（负号 IC 方向相同），说明它是"反转簇 + 波动 + value 权重"的弱杂合载体，**不提供独立机制轴**。
