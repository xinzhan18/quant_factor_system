## CP02 Mechanism Alignment · `misaligned`

**机制**：`CsRank($pb_ratio)` 把 PB 横截面排序（高估值 → 高 rank），`Log(Div($amount, Mean($amount, 20)))` 给出相对于 20 日均值的对数异常成交额（正=放量、负=缩量）。两者相乘，再按 5 日均值平滑。理论上捕捉"高估值股票在放量日 → 次日回落"的 value × liquidity 反向结构。

**与 hypothesis 一致性**：[[directions/log_value_liquidity#Hypothesis]] 假设 log-compression 能在 csi1000 小盘把 value × liquidity 交互的 mono 拉上来（复制 batch_036 F013 从 0.30 → 0.60 的成功）。本候选 mono_OOS = 0.0——**完全平**，不仅没翻倍，连基线都没有。hypothesis 直接证伪。更进一步看近邻：`max_corr@F009 = 0.258`，且 F009 是 `Mean(overnight_return - intraday_return, 5)`（隔夜-日内反转）——本候选与 F009 共享"5 日平滑 + 反转方向"结构，说明 IC 主要来自**overnight-intraday 反转簇残迹**，不是 pb × 异常成交额的价值-流动性交互。

**持续性**：如果信号本质是反转簇载体，持续性依赖 F009 的 edge；本候选作为稀释版，随 F009 衰减而衰减，无独立持续性来源。

**失效场景**：牛市放量时，高 PB 股票放量 ≠ 次日回落（势能主导）；价值股补涨行情中，低 PB 股票反而在放量日被买入——本候选机制系数会漂移。更关键是：本候选的 IC_by_year 在 2021-2023 稳定在 -0.02 到 -0.03，说明反转簇 alpha 仍在工作，但这只是 overnight-intraday 的代理，不是独立发现。

**与近邻差异**：[[factors/F009]] 捕捉 `Mean(overnight_return − intraday_return, 5)`（隔夜卖、日内买的 5 日反转模式）；本候选"想"捕捉 value × log(abnormal liquidity)，但 all_correlations 显示它与 F006/F007/F009 (overnight_intraday 家族) 全都 −0.18 到 −0.26 的负相关，且 max_corr 打在 F009 上。差异**在表达式层面（pb + log amount vs open-close spreads）但不在机制层面**——两者都把 csi1000 的隔夜-日内反转结构作为 IC 主要来源。

→ **misaligned**（hypothesis 要求 value × log-liquidity 独立 alpha，实得 overnight-intraday 反转簇稀释版）
