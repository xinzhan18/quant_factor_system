## 表达式解读

`Mul(CsRank($pb_ratio), Log(Div($turnover_rate, Mean($turnover_rate, 20))))` = 截面 pb 分位 × log(当日换手率 / 20 日均换手率)。

本意：把线性 `pb / mean(turnover)` 换成 log-compressed 形态，借鉴 batch_036 `gap_acceptance_structure` 的 meta-pattern（log 压缩 csi1000 小盘噪声）。期望 log 压缩 abnormal turnover 的厚尾、与 F002 线性除法不构成 near_duplicate、承袭 value × liquidity 本质。

**实际上发生了什么**：pb 越高（贵）× 异常高换手 → q5 收益显著负。六个 cos 样本中 IC 全年同号为负（2015–2023 每年 -0.025 ~ -0.062），long-short 机制是 "pe/pb/ps 高的股票遇到短期放量就跌"，这不是 value × liquidity 的多头信号，而是 **short-term reversal + overextension** 的代理——与 hypothesis "value × log(abnormal liquidity) 解锁新的 positive-IC alpha" 方向相反。

## CP02 Mechanism Alignment · **`misaligned`**

**1. 机制是什么**：CsRank(pb) × log(abnormal turnover)——理论叙事是"贵估值股遇到流动性爆发（换手率突增）时，注意力套利/短期过度 extrapolation 推高再均值回归"；但实证 IC 持续为负 9 年 → 实际等价于"pb 高 × turnover 高 → 短期下跌"，即 **高估值 × 短期放量 → 未来差**。这在机制层面是 `overextension / reversal` 而不是 `value × liquidity interaction alpha`。

**2. 与 hypothesis 对齐**：[[directions/log_value_liquidity#Hypothesis]] 明言："pb_ratio × log(abnormal liquidity) 产生独立于 F002 (linear pb/amount-mean) 的 alpha"——假设的是 `value × liquidity` 结构带来 **新的 value 类 alpha**。本候选 IC 持续为负，意味着 value 维度（pb-rank）对信号贡献已退居从属；真正驱动收益的是 log(abnormal turnover) 和 str_1m/vol_20d 的反转 cluster。**hypothesis 被证伪**：log-compression meta-pattern 没有把 value × liquidity 变成正 IC，它只是把另一个反转簇换了层外衣。

**3. 为什么持续**：反转/过度反应本身是 csi1000 的永续 anomaly，但这条已经被库里 F009（`Mean(Sub(Div(Sub($open, Ref($close, 1)), Ref($close, 1)), Div(Sub($close, $open), $open)), 5)` = overnight-intraday gap mean reversal）和 vol_20d 类因子覆盖。C002 不是新机制，只是旧反转簇的 log × value 化包装。

**4. 失效场景**：熊市/尾部季（worst_quarter_ic=-0.074）信号强到 Q5 独桨；牛市/best_quarter_ic=0.005 近零失效——说明"反转"依赖下行惩罚式回撤结构，不是对称 alpha。

**5. 与近邻差异**：[[factors/F009]] 捕捉 open-close 与 overnight-gap 的反向关系（短期反转）；C002 走 pb × log(abnormal turnover) 路径。表面 DSL 差异大（max_corr=0.22），但 `all_correlations` 里 F006 (-0.22)、F007 (-0.22)、F008 (-0.20)、F009 (-0.22) 四个**反转/流动性反转**因子都显著负相关——即 C002 与整个反转簇 **反向捕捉同一簇信号**，单点 max_corr 低只是因为信号分散到 4 个存量兄弟上，集群冗余高。

→ **misaligned**（hypothesis 方向 value 类 positive-IC alpha ≠ 实证 reversal cluster carrier）
