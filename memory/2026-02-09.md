## 完整功能清单

### 1. Pipeline 模块 (Zipline 风格)

| 功能 | 说明 |
|------|------|
| Factor | 因子基类 (记忆化、窗口支持) |
| Pipeline | 管道引擎 (DAG 执行) |
| Filter | 过滤器基类 |
| CombinedFactor | 组合因子 |
| Returns | 收益率因子 |
| Momentum | 动量因子 |
| RSI | 相对强弱 |
| MovingAverage | 移动平均 |
| Volatility | 波动率 |

### 2. 评估模块 (Alphalens 风格)

| 功能 | 说明 |
|------|------|
| IC 分析 | IC, ICIR, IC decay |
| 分组回测 | 5组/10组分析 |
| 换手率分析 | 分组换手率 |
| 因子自相关 | Rank IC |

### 3. 风险指标 (QuantStats 风格)

| 功能 | 说明 |
|------|------|
| 夏普比率 | 滚动/历史 |
| 最大回撤 | 序列计算 |
| VaR/CVaR | 风险价值 |
| 索提诺比率 | 下行波动率 |
| 卡玛比率 | CAGR/MaxDD |

### 4. 可视化

| 功能 | 说明 |
|------|------|
| TearsheetBuilder | Tearsheet 报告 |
| MonteCarloSimulator | Monte Carlo 模拟 |
| extend_pandas() | Pandas 扩展 |

### 5. Dashboard 页面

| 页面 | 功能 |
|------|------|
| Home | 首页概览、最佳因子、IC 趋势 |
| factor_evaluation | 单因子评估 |
| factor_screening | 因子筛选 |
| factor_interaction | 相关性热力图、组合分析 |
| pipeline_editor | 可视化构建 Pipeline |
| stock_selection | 股票筛选 |
| backtest_history | 历史回测 |

## 快速使用

### 运行 Dashboard

```bash
cd quant_factor_system/dashboard
streamlit run Home.py
```

### Pipeline

```python
from quant_factor_system.pipeline import Pipeline, Momentum, RSI

pipe = Pipeline("MyPipeline")
pipe.add_factor('momentum', Momentum(window=20))
result = pipe.run(price_data)
```

### 评估

```python
from quant_factor_system.evaluation import EnhancedEvaluator

evaluator = EnhancedEvaluator()
result = evaluator.evaluate('Factor', factor_data, returns)
```
