## CSV 导入工具

### 新增文件

```
quant_factor_system/
└── data/
    ├── csv_importer.py          # CSV 导入脚本
    └── CSV_IMPORTER_GUIDE.md   # 使用指南
```

### 使用方式

```bash
# 初始化数据库
python csv_importer.py --init

# 导入日线数据
python csv_importer.py --daily /path/to/daily.csv

# 查看统计
python csv_importer.py --stats
```

### CSV 格式

**日线数据:**
```csv
code,date,open,high,low,close,volume
000001.XSHE,2024-01-02,10.50,10.80,10.30,10.60,5000000
```

**因子数据:**
```csv
code,date,momentum_20d,pe,roe
000001.XSHE,2024-01-02,0.05,8.5,0.15
```

### 数据存储位置

```
storage/database/market_data.db
├── stocks        # 股票列表
├── daily_data   # 日线数据 (OHLCV)
└── factor_data  # 因子数据
```

## 数据格式标准

### 日线数据 (MultiIndex)

| 字段 | 说明 |
|------|------|
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| volume | 成交量 |
| amount | 成交额 |
| turn | 换手率 |
| pct_chg | 涨跌幅 |

### 支持的平台

- 标准格式
- 米筐 (RiceQuant)
- 聚宽 (JoinQuant)
- Tushare
- Wind

## 因子列表
