# AlphaLens风格因子分析优化 Plan

## 📌 目前的状况

现有因子分析模块已有基础功能：
- `ICAnalyzer`: IC时间序列、分布、滚动IC统计
- `GroupReturnsAnalyzer`: 分组收益、累计收益、多空组合
- `FactorReportGenerator`: 整合报告生成

**但缺少 AlphaLens 核心功能：**
1. 每个分组的独立累计收益曲线（分层可视化）
2. 因子分层分析（行业、市值、风格）
3. 换手率分析
4. 完整的 Tear Sheet 报告
5. 因子自相关分析
6. 因子衰减分析

---

## ✅ 需要完成的需求

1. 实现 AlphaLens 风格的分组累计收益分层图
2. 增加因子分层分析（行业、市值、风格）
3. 增加换手率分析
4. 完善 Tear Sheet 报告输出

## 🎯 每个需求的独立任务

### 需求1: 分组累计收益分层图 (P0)

**目标**: 像 AlphaLens 一样，展示每个分组的独立累计收益曲线

- [ ] 任务1: 修改 `GroupReturnsAnalyzer.plot_cumulative_returns()` 支持同时显示所有分组
- [ ] 任务2: 添加分组颜色映射 (Q1=红色 -> Q5=绿色)
- [ ] 任务3: 添加多空组合 (Q5-Q1) 子图
- [ ] 任务4: 支持训练/测试集分界线
- [ ] 任务5: 生成示例图片测试

### 需求2: 行业分层IC分析 (P1)

**目标**: 分析因子在不同中信一级行业的IC表现

- [ ] 任务1: 添加行业数据获取接口
- [ ] 任务2: 实现 `compute_ic_by_industry()` 方法
- [ ] 任务3: 生成行业IC热力图
- [ ] 任务4: 按行业分组累计收益曲线

### 需求3: 市值分层IC分析 (P1)

**目标**: 分析因子在不同市值区间的表现

- [ ] 任务1: 添加市值数据获取
- [ ] 任务2: 实现 `compute_ic_by_marketcap()` 方法
- [ ] 任务3: 按市值分组累计收益曲线
- [ ] 任务4: 生成市值分层热力图

### 需求4: 换手率分析 (P2)

**目标**: 分析因子组合的调仓频率

- [ ] 任务1: 实现 `compute_turnover()` 方法
- [ ] 任务2: 绘制分组换手率柱状图
- [ ] 任务3: 绘制换手率时间序列

### 需求5: 因子自相关分析 (P2)

**目标**: 分析因子值的自相关性

- [ ] 任务1: 实现 `compute_factor_autocorr()` 方法
- [ ] 任务2: 绘制自相关系数图

### 需求6: 收益衰减分析优化 (P2)

**目标**: 更详细的收益衰减分析

- [ ] 任务1: 按分组计算不同持有期的收益
- [ ] 任务2: 生成热力图形式的衰减图
- [ ] 任务3: 添加N日累计收益计算

### 需求7: Tear Sheet 报告整合 (P1)

**目标**: 生成完整的因子评估报告

- [ ] 任务1: 整合所有分析模块到 `FactorReportGenerator`
- [ ] 任务2: 生成 HTML 格式 Tear Sheet
- [ ] 任务3: 支持一键生成所有图表
