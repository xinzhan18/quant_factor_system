# "情绪溢出"因子构建 Plan

## 📌 因子概述

**因子名称**: 情绪溢出因子 (RNBR_tov / Sentiment Overflow)
**类型**: 高频因子 - 成交分布类

---

## ✅ 因子构建逻辑

### 1. 核心公式

```
1. 按股票代码从小到大排序
2. 对每只股票 i:
   - 计算相邻 n 只股票过去 T 日的日均换手率
   - 等权合成为 NBR_tov(i)
3. 截面回归: NBR_tov(i) ~ 自身日均换手率
4. 残差 = RNBR_tov (情绪溢出因子)
```

### 2. 参数建议

| 参数 | 建议值 |
|------|--------|
| n (相邻股票数) | 10 |
| T (计算窗口) | 5~20 天 |

### 3. 因子含义

- 投资者注意力有限，行情软件按代码顺序展示
- 会关注到相邻股票 → "注意力溢出"
- 相邻股票间价格和交易情绪转移
- 与未来收益正相关
