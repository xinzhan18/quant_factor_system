## 📊 安全配置

| 参数 | 值 | 说明 |
|------|-----|------|
| 每日配额 | 1200万条 | 约800MB (1GB的80%) |
| 每批数量 | 500只 | 平衡速度和稳定性 |
| 请求间隔 | 1秒 | 避免触发限流 |

## ⚙️ 执行命令

### 方式1: 逐月拉取 (推荐)

```bash
# 拉取单月数据 (测试用)
python scripts/pull_1min_data.py --start-date 20260101 --end-date 20260131

# 拉取2025全年
python scripts/pull_1min_data.py --start-date 20250101 --end-date 20251231

# 拉取2024全年
python scripts/pull_1min_data.py --start-date 20240101 --end-date 20241231
```

### 方式2: 自动逐月 (脚本循环)

```bash
# 运行自动逐月拉取
python scripts/pull_1min_data.py --auto-pull --start-year 2025 --end-year 2015
```

### 方式3: Cron 定时

```bash
# 每天凌晨3点自动拉前一天的数据
0 3 * * * cd /path/to/quant_factor_system && python scripts/pull_1min_data.py --date yesterday
```

## 🛡️ 安全措施

1. **配额限制**: 每天1200万条自动停止
2. **请求间隔**: 每批1秒，避免限流
3. **增量更新**: 只拉取不存在的数据
4. **断点续传**: 中断后可继续
