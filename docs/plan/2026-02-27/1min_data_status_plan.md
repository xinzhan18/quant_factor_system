## 🎯 定时任务配置

### Job 1: 每日增量 (Daily)

- **用途**: 每天收盘后拉取当天数据
- **时间**: 每天 16:00 (A股收盘后)
- **命令**: 
  ```bash
  python scripts/pull_1min_data.py --date today
  ```
- **预计耗时**: ~5分钟/天

### Job 2: 历史补录 (Historical)

- **用途**: 补充缺失的历史数据
- **策略**: 每天凌晨运行，每次拉满配额
- **时间**: 每天 02:00
- **命令**:
  ```bash
  # 自动拉取缺失日期
  python scripts/pull_1min_data.py --auto-pull-missing
  ```
- **预计耗时**: ~7个月 (按每天1200万条)
