# 因子研究流程

本文档记录因子研究的标准流程。

---

## 1. 因子构建

### 1.1 日内动量因子 (Intraday Momentum)

**公式**:
```
-1 × delta((((close - low) - (high - close)) / (high - low)), 1)
```

**逻辑**:
1. `(close - low) - (high - close)`: 归一化的日内形态（多头 vs 空头）
2. `delta(..., 1)`: 1日变化率
3. `-1 ×`: 取负值

**数据要求**:
- 时间范围: 2015-01-01 ~ 2024-12-31
- 股票范围: 全量A股（约5,000只）
- 数据频率: 日线 (使用 high, low, close)

---

## 2. 因子分析

### 2.1 IC分析

使用 Spearman 相关系数计算因子与 T+1 收益率的 IC:

```python
from scipy import stats

# T+1 收益率
merged['return_1d'] = merged.groupby('symbol')['close'].pct_change().shift(-1)

# IC
ic, p_value = stats.spearmanr(factor_values, return_1d)
```

### 2.2 分组收益分析

按因子值分为5组 (Q1 ~ Q5):

```python
merged['group'] = pd.qcut(factor_values, 5, labels=['Q1','Q2','Q3','Q4','Q5'])
```

## 3. 注册因子到数据库

### 3.1 注册因子配置

```python
# 1. 创建因子配置表（首次）
cursor.execute('''
    CREATE TABLE IF NOT EXISTS factor_config (
        name VARCHAR(100) PRIMARY KEY,
        display_name VARCHAR(200),
        category VARCHAR(50),
        frequency VARCHAR(20),
        storage_type VARCHAR(20),
        description TEXT,
        unit VARCHAR(20)
    )
''')

# 2. 注册因子
cursor.execute('''
    INSERT INTO factor_config (name, display_name, category, frequency, storage_type, description, unit)
    VALUES (%s, %s, %s, %s, %s, %s, %s)
    ON CONFLICT (name) DO UPDATE SET ...
''', ('intraday_momentum', '日内动量因子', 'technical', 'daily', 'timeseries', '...', 'ratio'))
```

### 3.2 创建因子数据表

```python
# 创建因子数据表
cursor.execute('''
    CREATE TABLE IF NOT EXISTS factor_intraday_momentum (
        symbol VARCHAR(20),
        time TIMESTAMP,
        value DOUBLE PRECISION,
        PRIMARY KEY (symbol, time)
    )
''')

# 转换为 TimescaleDB 超表
cursor.execute('''
    SELECT create_hypertable('factor_intraday_momentum', 'time', if_not_exists => TRUE)
''')
```

### 3.3 导入因子数据

使用 COPY 命令批量导入:

```python
# 计算因子
df = compute_factor(price_df)

# 导出为 CSV
df.to_csv('factor_data.csv', index=False, header=False, sep='\t')

# 导入数据库
cursor.copy_from(open('factor_data.csv'), 'factor_intraday_momentum', 
                  columns=('symbol', 'time', 'value'), sep='\t')
```

## 5. 因子评估指标

| 指标 | 优秀 | 合格 | 较差 |
|------|------|------|------|
| IC 均值 | > 0.05 | 0.02~0.05 | < 0.02 |
| IC IR | > 0.5 | 0.3~0.5 | < 0.3 |
| IC > 0 占比 | > 60% | 50%~60% | < 50% |
| 多空年化 | > 15% | 5%~15% | < 5% |
