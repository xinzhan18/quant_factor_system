# Quant Factor Trading Platform - 项目概览

## 📦 项目简介

完整的量化因子研究与交易平台，从数据获取到因子分析，回测、实盘交易。

## 📁 目录结构

```
quant_factor_system/
├── data/              # 数据模块
├── factors/           # 因子模块
├── backtest/         # 回测模块
├── selector/          # 选股模块
├── position/         # 仓位模块
├── stoploss/         # 止损模块
├── dashboard/        # Web界面
└── docs/            # 文档
```
