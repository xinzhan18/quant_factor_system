🚀 飞书 API 经典调用案例

Feishu API Calling Examples with Dummy Data

📄 场景1: 飞书文档操作

✏️ 创建文档

feishu_doc({ action: "create", title: "2026年Q1项目计划", folder_token: "fol_xxx123" })

📖 读取文档

feishu_doc({ action: "read", doc_token: "docx_xxx456" })

📊 场景2: 飞书多维表格 Bitable

➕ 创建记录

feishu_bitable_create_record({ app_token: "app_xxx789", table_id: "tbl_abc123", fields: { "姓名": "张三", "部门": "技术部", "入职日期": "2026-01-15", "状态": "在职" } })

🔍 查询记录

feishu_bitable_list_records({ app_token: "app_xxx789", table_id: "tbl_abc123", page_size: 50 })

☁️ 场景3: 飞书云盘操作

📁 创建文件夹

feishu_drive({ action: "create_folder", name: "2026年项目资料", folder_token: "fol_root" })

📋 列出文件

feishu_drive({ action: "list", folder_token: "fol_root" })

📚 场景4: 飞书 Wiki 知识库

🔎 搜索节点

feishu_wiki({ action: "search", query: "API 开发文档" })

📄 获取节点

feishu_wiki({ action: "get", token: "wiki_xxx777" })

💬 场景5: 发送消息

📨 发送文本消息

message({ action: "send", target: "ou_xxx999", message: "项目已更新，请查看文档！" })

📊 发送富文本

message({ action: "send", target: "chat_xxx888", message: "📈 **Q1数据报告**\\n\\n已完成统计，请查阅附件。" })
